Circuit Switching

Coursebook: Chapter 14 · Communication and internet technologies, section 14.2 Circuit switching, packet switching

How a dedicated circuit is set up, used and released, its benefits and drawbacks and where it is used; animations, a call simulator and the real 9618 circuit switching questions.

This page in five sentences

Circuit switching sends data over a dedicated circuit that is set up between the two ends before any data is sent and kept for the whole of the communication. The whole bandwidth of that path is reserved, so the data flows as a continuous stream along the same route and arrives in the order it was sent. This makes it suitable for real-time communication such as voice calls, but the circuit cannot be used by anyone else while it is open, even when nothing is being sent, and if the route fails the call ends. The three phases are set up, transmit, release. The exam asks you to describe it, give benefits and drawbacks, and say where it is appropriate; comparing it with packet switching is on the next page.

1 · How circuit switching works

  1. Set up (establish) the circuit. A dedicated path is found through the network, through switches, from the sender to the receiver. This happens before transmission starts and takes some time.
  2. Transmit. Data travels in a continuous stream along the same route, using the whole bandwidth of the circuit. Transmission is usually bidirectional (both ends can send).
  3. Release. At the end the circuit is closed (released) and the resources can be used for another communication.

The classic example is a traditional telephone call: when you dial, a circuit is set up through the exchanges and kept for the whole call.

2 · Characteristics

  • A dedicated circuit / channel is required.
  • The circuit is established before the transmission begins and lasts for the whole transmission.
  • Data travels in a continuous stream along the same route; it arrives in order and does not need reassembling.
  • The data rate is fixed and the whole bandwidth is available.

3 · Benefits and drawbacks

BenefitsDrawbacks
The whole bandwidth is available: a steady, high data rateThe circuit cannot be used by anyone else while it is open, even if it is idle (bandwidth wasted)
Data arrives in the same order it was sent: no reordering or reassembling delayTime to set up the circuit before sending can begin
Suitable for real-time transmission and long continuous communicationNo alternative route if there is a fault: the transmission ends
Data is unlikely to be lost, since it all follows the same path; no waiting at switchesLess secure: all the data follows one route and can be intercepted. Not flexible and difficult to scale

4 · Where it is appropriate

UseWhy circuit switching suits it
Standard voice communication (a phone call)A dedicated path is needed for the whole call, with the data arriving in real time and in order
Live video or streamingA steady data rate with no delay for reordering
Private data networksThe whole bandwidth is reserved and the connection is predictable
Wording for "where and why""Circuit switching is used where a dedicated path needs to be sustained throughout the communication, or where the whole bandwidth or real-time communication is required, for example voice calls."

5 · Common ways to lose marks

  • Describing circuit switching as "a circuit with wires". It is a dedicated path set up before the data is sent and kept for the whole transmission.
  • Giving a benefit and a drawback that are the same point stated twice (for example "dedicated" for both).
  • Forgetting that a drawback is the unused bandwidth that cannot be shared.
  • Saying the data is split into packets. That is packet switching.
  • Writing "it is faster" without saying why: no packets to reorder and the whole bandwidth is reserved.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A traditional phone call

When you dial, a path is set up between the two phones and reserved until you hang up, even during silences.

Exam use: circuit switching: a dedicated circuit for the whole communication.

A live video link in a broadcast studio

A dedicated, steady connection delivers the pictures with no waiting for packets to be reordered, which a live broadcast cannot tolerate.

Exam use: suitable for real-time transmission with a fixed data rate.

A private line between two offices

A company leases a dedicated connection so the whole bandwidth is always available and the traffic follows a known route.

Exam use: dedicated bandwidth: predictable, but not shared.

A busy signal

In the old phone network, if every circuit between two exchanges was in use you got an engaged tone. No other call could use a circuit that was open.

Exam use: a drawback: the circuit cannot be shared while it is in use.

A call that drops

If a cable on the route is cut, the call ends, because there is no other route and the circuit has to be set up again.

Exam use: no alternative route if there is a fault.

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

Describe 3 marks Describe how a circuit is used when two people have a phone conversation using circuit switching.
ReminderSet up, use, release.

A dedicated circuit is set up between the two phones before the conversation starts. The voice travels as a continuous stream along the same route, in order, using the whole bandwidth. The circuit is released when the call ends.

Explain 2 marks Explain why circuit switching wastes bandwidth.
ReminderWhat happens in a silence?

The circuit is reserved for the whole call and cannot be used by anyone else. During pauses nothing is sent, but the unused bandwidth cannot be shared.

State 2 marks State two reasons why circuit switching is suitable for a live video call.
ReminderDelay and order.

The data arrives in the order it was sent, so there is no delay for reassembling. The whole bandwidth is reserved, giving a steady data rate.

Give 3 marks Give three drawbacks of circuit switching.
ReminderSetting up, sharing, faults.

It takes time to set up the circuit before sending can begin. The circuit cannot be shared, even when it is idle. If the route fails the transmission ends: there is no alternative route.

Identify 2 marks A caller hears an engaged tone because all the circuits between two exchanges are in use. Explain how this shows a feature of circuit switching.
ReminderDedicated, not shared.

Each call needs a whole dedicated circuit. While every circuit is in use, no other call can use any of them, so a new call is blocked.

Top tips

  • Three words: dedicated, before, whole. A dedicated circuit, set up before the data is sent, lasting the whole transmission.
  • Same route, same order. That is why no reassembly is needed.
  • Benefit with a reason. Whole bandwidth and no reordering, so a steady real-time stream.
  • Drawback with a reason. Cannot be shared when idle, set-up time, no alternative route.
  • Give an example. A telephone call, live video, a private data network.
  • Do not mention packets. Circuit switching sends a continuous stream.
