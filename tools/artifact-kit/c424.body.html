Compilers and Interpreters Compared

The advantages and disadvantages of compiling and interpreting, and when each is the right choice.

The big idea

Both compilers and interpreters turn a high-level program into machine code, but they suit different jobs. An interpreter is best while the program is being written and tested. A compiler is best for the finished program that users will run.

Why the difference?

During development

The programmer changes a line, runs it, sees an error, and changes it again, many times. An interpreter runs the code straight away and stops at the line with the error. A compiler would have to translate the whole program each time.

When the program is finished

Users want a program that runs quickly and does not need extra software. A compiler produces one executable file that is translated once and runs fast, with no translator installed.

Many IDEs provide both: the interpreter is often used for developing, and the compiler to produce the final version.
