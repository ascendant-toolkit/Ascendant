Constructors: Creating Objects

Coursebook: Chapter 20 · Further programming, section 20.1 Programming paradigms

What a constructor is, how it turns arguments into attributes, parameters against fixed starting values, and how it looks in Python and exam pseudocode; animations, labs and review questions.

This page in five sentences

A constructor is the method that runs once, automatically, when an object is created. Its job is to give the new object its starting values. In Python it is called __init__; in the exam pseudocode it is NEW. The values passed in when the object is created arrive as parameters, and the constructor stores them in the object's attributes. A constructor never returns a value and is never called by name afterwards.

1 · The constructor in code

The same class in both forms. Each line inside the constructor assigns one attribute.

Python

class Pet:    # PetName : STRING    # YearBorn : INTEGER    def __init__(self, NewName, NewYear):        self.__PetName = NewName        self.__YearBorn = NewYear

Pseudocode (exam style)

CLASS Pet  PRIVATE PetName : STRING  PRIVATE YearBorn : INTEGER  PUBLIC PROCEDURE NEW(NewName : STRING, NewYear : INTEGER)    PetName <- NewName    YearBorn <- NewYear  ENDPROCEDUREENDCLASS

2 · Creating an object calls the constructor

MyPet = Pet("Rex", 2021)       # PythonMyPet <- NEW Pet("Rex", 2021)  # pseudocode

You never write MyPet.__init__(...). Writing the class name with brackets is the call. The arguments in the brackets line up, in order, with the constructor's parameters after self.

4 · Not every attribute is a parameter

Read the question carefully. Some values are passed in; others are set to a fixed starting value inside the constructor. A vehicle that is created standing still does not need its speed passed in.

Python

class Vehicle:    # VehicleID : STRING    # MaxSpeed : INTEGER    # CurrentSpeed : INTEGER    # HorizontalPosition : INTEGER    def __init__(self, NewID, NewMax):        self.__VehicleID = NewID        self.__MaxSpeed = NewMax        self.__CurrentSpeed = 0        self.__HorizontalPosition = 0

Pseudocode (exam style)

CLASS Vehicle  PRIVATE VehicleID : STRING  PRIVATE MaxSpeed : INTEGER  PRIVATE CurrentSpeed : INTEGER  PRIVATE HorizontalPosition : INTEGER  PUBLIC PROCEDURE NEW(NewID : STRING, NewMax : INTEGER)    VehicleID <- NewID    MaxSpeed <- NewMax    CurrentSpeed <- 0    HorizontalPosition <- 0  ENDPROCEDUREENDCLASS

Two parameters, four attributes. Counting the parameters is a common one-mark question.

5 · Constructors in child classes

A child class has its own constructor. Its first job is to call the parent's constructor so the inherited attributes are set; then it sets its own. This is covered on the Inheritance page.

5 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A new game character

When a character appears it needs a name, a position and a health value. The constructor takes the name and start position and sets the health to 100.

Exam use: constructor with a mix of parameters and fixed values.

Opening a bank account

An account is created with the owner's name and starts with a balance of zero. Nothing else in the program can create an account in an invalid state.

Exam use: constructor sets a safe starting state.

A blank patient record

A new record starts with the ID and name supplied and an empty list of treatments. Later setters add the treatments.

Exam use: constructor then setters: create, then update.

A shop basket

A basket is made for a customer and starts empty. Each call to the class gives a separate basket, so two customers never share items.

Exam use: each object made by the constructor has its own values.

Top tips

  • Count the parameters. Only the values the question says are passed in. Everything else is set inside the constructor.
  • Always self first. def __init__(self, ...) in Python. A missing self is the commonest slip.
  • Every attribute needs self. self.__Name = NewName, not Name = NewName.
  • No return. A constructor sets values; it does not return anything.
  • Use the names from the question. Attribute names and data types are copied exactly into the comments.
