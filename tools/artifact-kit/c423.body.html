Translators

Compilers, interpreters and assemblers: what each translates, and what each produces.

The big idea

A computer can only run machine code. A program written in any other language must be turned into machine code first, by a translator. There are three types: compilers, interpreters and assemblers.

4.2.3 Translators

Compiler

Translates the whole high-level program into machine code in one go.

  • The original is the source code; the result is the object code
  • If there are errors, an error report is produced instead of a compiled program
  • An executable file is produced, so the program can be run again and again without recompiling, and without the compiler
  • One high-level statement can become several machine code instructions

Interpreter

Reads one statement of a high-level program, translates it, executes it, then moves to the next.

  • If there is an error, execution stops and an error message is shown, sometimes with a suggested correction
  • No executable file of machine code is produced
  • The program has to be interpreted again each time it is run, so it cannot run without the interpreter

Assembler

Translates a program written in assembly language into machine code.

  • An executable file is produced and can be used again without the assembler
  • One assembly statement usually becomes one machine code instruction
