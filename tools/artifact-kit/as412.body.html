CPU Performance and Ports

Coursebook: Chapter 4 · Processor fundamentals · section 4.1 Central Processing Unit architecture

Clock speed, cores, cache, RAM and bus width and their effect on performance, why more cores do not always double the speed, and the USB, HDMI and VGA ports, with animations, labs and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

The performance of a computer depends on several factors: clock speed (more fetch-execute cycles per second), number of cores (more instructions in parallel, but with overheads), cache memory (fast memory close to the CPU holding frequently used instructions and data), amount of RAM (more running programs held without using slower secondary storage) and bus width (a wider data bus moves more data at once; a wider address bus addresses more memory). Each exam answer needs the factor and its effect. Ports connect peripherals: USB is a universal serial bus that detects devices automatically and loads a driver, HDMI carries digital video and audio on one cable and VGA carries analogue video only. Multiple cores do not always double the speed.

1 · Performance factors

FactorEffect on performance
Clock speedA higher clock speed means more fetch-execute cycles per second (for example 4 GHz is 4 billion timing signals a second instead of 2.1 billion)
Number of coresEach core can carry out a process at the same time, so more instructions are performed in parallel
Cache memoryFast access memory close to the CPU that stores frequently used instructions and data, so they can be accessed faster than from RAM and the CPU waits less
RAMMore RAM means more running programs and data can be held without using virtual memory or fetching from slower secondary storage: less delay
Bus widthA wider data bus transfers more data at the same time; a wider address bus allows more memory locations to be addressed directly
Secondary storage typeA solid state drive has faster access than a magnetic hard disk

2 · Why two cores are not twice as fast

  • Multiple cores add overheads: the cores must communicate and share data, which adds latency.
  • Not all software is designed to use several cores, so some of the cores sit idle.
  • Memory access speed may not keep up with the cores, causing delays.
  • Possible deadlock, where one core waits for another that is waiting for the first, and more heat is generated.
  • The two computers may differ in other ways too (RAM, GPU).

3 · Ports

PortTransfersKey points
USB (Universal Serial Bus)Data, one bit at a time (serial); also powerUniversal standard; fast transfer; detects devices automatically; USB 3 is full duplex, earlier versions half duplex; can be synchronous or asynchronous
HDMI (High Definition Multimedia Interface)Digital video and audio togetherHigh bandwidth; one cable; uncompressed digital signals; no loss from converting to analogue and back; less prone to interference; supports high resolutions
VGA (Video Graphics Array)Analogue video onlyNeeds a separate sound cable; digital signal converted to analogue and back; more prone to interference; lower resolution

How USB connects automatically: plugging in the device causes a voltage change; the computer detects it; the device sends its code (identification) to the computer; the OS finds that code in its list of devices and loads the correct device driver.

Common ways to lose marks

  • Naming a factor with no effect, such as "more cores". Say that more instructions can be performed at the same time.
  • Saying more cores doubles the speed. The question usually asks why it does not always.
  • Saying a wider bus makes the bus "faster". It transfers more data at once, or addresses more memory.
  • Describing USB as "universal" with no mention of automatic detection and the device driver.
  • Saying HDMI is "better quality" with no reason (digital, single cable for audio and video, high bandwidth).

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Buying a gaming PC

More cores help if the game is written to use them; a faster clock helps almost every program; more RAM stops the game loading data from the drive.

Exam use: match the factor to the work.

A video call that stutters

If the processor is waiting for data from slow memory or storage, a bigger cache or more RAM reduces the delay.

Exam use: less waiting for data.

Plugging in a memory stick

It appears on screen within seconds with no software to install: the OS recognises the device and loads its driver.

Exam use: automatic detection.

A laptop to a TV

One HDMI cable carries both picture and sound at high resolution. An old VGA lead would need a separate audio cable.

Exam use: HDMI carries audio and video.

Why a 32-bit computer stops at 4 GB

Its address bus can only address 2^32 locations. A wider address bus is needed for more memory.

Exam use: address bus width.

Top tips

  • Factor plus effect. Two marks, one for each.
  • Cache: frequently used, close to the CPU. The CPU waits less.
  • Cores: parallel, with overheads. Idle cores, communication, software.
  • Data bus width: more data at once. Address bus width: more locations.
  • USB: voltage, code, driver. Say 'device driver'.
  • HDMI: digital, audio and video. One cable, high bandwidth.
