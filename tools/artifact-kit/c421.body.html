High-Level and Low-Level Languages

What separates a language written for people from one written for a machine, and the trade-offs of each.

The big idea

Computers only understand machine code. Programmers write in languages that are easier for people. High-level languages are written for the programmer and the problem. Low-level languages are tied to the architecture and hardware of one type of computer.

4.2.1 High-level languages and low-level languages

High-level languages

  • Let the programmer focus on the problem; no knowledge of the hardware or instruction set is needed
  • Often portable: the same program can run on different types of computer
  • Statements are closer to English
  • Easier to read, write, debug and maintain

Examples: Python, Java, Visual Basic, C++, Pascal, Delphi.

Sum := FirstNumber + SecondNumber

One statement adds two numbers.

Low-level languages

  • Relate to the specific architecture and hardware of one type of computer
  • Machine code: the binary instructions the computer understands, usually shown in hexadecimal
  • Assembly language: mnemonics that need translating into machine code

Programmers do not usually write in machine code. It is hard to understand and hard to manage data in.

0001 00010010
0100 00010011
0000 00011010

The same job as three machine code instructions.
