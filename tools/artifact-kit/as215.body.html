IP Addresses, URLs and DNS

Coursebook: Chapter 2 · Communication · section 2.1 Networks including the internet

IPv4 and IPv6, network and host IDs and subnetting, public and private and static and dynamic addresses, URLs and the Domain Name Service; animations, labs and the real Paper 1 questions from 2023 to 2026.

This page in five sentences

Every device on a network has an IP address so that packets can be sent to it. IPv4 addresses are 32 bits, written as four groups of 8-bit numbers (0 to 255) separated by full stops; IPv6 addresses are 128 bits, written as eight groups of four hexadecimal digits separated by colons. An IP address is made of a network ID and a host ID, and subnetting splits a network into smaller parts. A public IP address is visible on the internet; a private one is used only inside a LAN and is not reachable directly from outside, which helps security; a static address never changes while a dynamic one may change each time the device joins the network. People use a URL such as https://www.example.com/page.html, and the Domain Name Service (DNS) turns the domain name into the IP address of the web server.

256.0.0.A is not a valid IPv4 address: the maximum value of a group is 255 and A is not a number. It is not IPv6 either: it uses full stops and has too few groups.

How an IP address is linked to a device

An IP address is assigned to a device on a network (usually by the router using DHCP, or set by hand). It identifies where the device is on the network so that packets can be delivered. A device on several networks can have a different address on each.

2 · Subnetting

An IP address has two parts: a network ID (which network or subnetwork the device is on) and a host ID (which device within it). Every device in one subnetwork has the same network ID and a different host ID. Subnetting divides a network into logical segments:

  • splits a larger network into smaller, more manageable parts;
  • reduces congestion (and collisions), because traffic between devices on the same subnet stays within it;
  • improves security: a compromised device does not expose the whole network and not every device can reach every segment;
  • makes it easier to isolate faults, and to expand the network.

A static private IP address does not change and can only be seen or used within the LAN. A router has two addresses: a public one so it is visible to the internet, and a private one to identify it to computers inside the LAN.

4 · URLs and the Domain Name Service

A Uniform Resource Locator (URL) identifies a resource on the WWW. For https://www.example.com/shop/item.html: https is the protocol, www.example.com is the domain name of the web server, and /shop/item.html is the path to the page.

Computers route packets by IP address, not by name, so the browser needs the server's IP address. The DNS is a distributed directory of domain names and their IP addresses. How the browser uses a URL to get a page:

  1. The browser checks its cache for the URL or domain.
  2. It splits the URL into its parts (protocol, domain, path).
  3. It finds the IP address of the domain name by querying a DNS server, which sends back the matching IP address.
  4. The browser makes a connection to the web server at that IP address and sends a request for the resource.
  5. The server sends the page and the browser renders and displays it. The IP address is stored in the cache for future use.

5 · Common ways to lose marks

  • Writing IPv6 with full stops, or IPv4 with colons. IPv4 uses full stops and decimal; IPv6 uses colons and hexadecimal.
  • Saying a private IP address is "secret". It is used only within the LAN and cannot be reached directly from the internet.
  • Writing that DNS "finds the website". It converts the domain name into the IP address.
  • Giving subnetting benefits as "faster" alone. Say congestion is reduced, security improved, faults isolated.
  • Saying a static address is one that is "not used". It is one that does not change.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Your home network

Your router has one public address from your internet provider. Your phone and laptop have private addresses like 192.168.1.20, which only work inside your home.

Exam use: private addresses are used only within the LAN.

A website that never moves

A web server needs the same address every time, so it is given a static IP. Your phone gets a dynamic address that can change when you reconnect.

Exam use: static addresses suit servers.

Typing a website name

You type a name, not a number. A DNS server looks the name up, like finding a friend's number in a phone book.

Exam use: DNS gives the IP address for a domain name.

School network segments

A school splits its network into subnets, such as one for staff and one for students, so the traffic stays separate and a problem on one does not affect the other.

Exam use: subnetting reduces congestion and improves security.

Running out of addresses

IPv4 has about 4.3 billion addresses, which ran short as phones and gadgets joined the internet. IPv6 has far more.

Exam use: IPv6 uses 128 bits.

Top tips

  • IPv4: 32 bits, full stops, 0 to 255. IPv6: 128 bits, colons, hexadecimal.
  • Public: visible. Private: inside the LAN. Static: fixed. Dynamic: may change.
  • Network ID + host ID. Same network ID, different host ID in a subnet.
  • Subnet benefits. Less congestion, security, fault isolation, easier to grow.
  • DNS: name to IP address. The browser then contacts the web server.
  • URL: protocol, domain, path. https://www.example.com/page.
