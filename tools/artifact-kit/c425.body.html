Integrated Development Environments

The tools an IDE bundles for writing, running and debugging programs.

The big idea

An integrated development environment (IDE) is a program that gathers the tools a programmer needs into one place, to aid the writing and development of programs. Some IDEs support one language, others support several. Examples: PyCharm (Python), Visual Studio (Visual Basic), BlueJ (Java).

4.2.5 Integrated Development Environment (IDE)

Code editor

Write and edit the program without switching to a separate text editor. This speeds up development, as corrections and additions are made in the same place.

Translator

Most IDEs include a compiler and/or an interpreter, so the program can be run. The interpreter is often used while developing, and the compiler to produce the final version.

Runtime environment with a debugger

A debugger runs the program under development and lets the programmer:

  • single step: run it one line at a time
  • set a breakpoint: stop at a chosen line of source code
  • look at a report window showing the contents of variables and expressions at that point

This helps find logic errors and check the program works as intended.

Error diagnostics and auto-correction

Dynamic error checking finds possible errors as the code is typed, underlines them (often in red), alerts the programmer and suggests a correction. Many errors are fixed before the program is even run.

Auto-completion

The editor offers context-sensitive prompts that complete variable names and reserved words as the programmer types. It saves time and reduces typing mistakes.

Auto-documenter

Explains the function and purpose of programming code, for example what a command such as Console.WriteLine does.

Prettyprinting

The editor colour-codes the words in the program (for example, all strings in red) and lays the program out in a meaningful way, such as indenting. It makes the code easier to read.
