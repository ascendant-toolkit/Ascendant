Running of Applications

How a computer starts up and how hardware, firmware (the BIOS) and the operating system work together to run an application.

The big idea

An application cannot run on its own. It needs the hardware to do the work, the operating system to give it a platform, and firmware (the BIOS) to start the computer and link the OS to the hardware.

4.1.3 Running of applications

Booting up

When a computer starts, part of the operating system must first be loaded into RAM. This is called booting up the computer, done by a bootstrap loader.

  1. The motherboard's start-up is handled by the basic input/output system (BIOS).
  2. The BIOS tells the computer where the storage device holding the operating system can be found.
  3. It loads the part of the OS that is needed into RAM and executes it.
  4. The application then runs under the control of the OS, using system software such as device drivers. Parts of the OS may be loaded in and out of RAM as it runs.

Firmware

Firmware is a program that provides low-level control for devices. The BIOS is often called firmware. It acts as an interface between the operating system and the hardware.

Application software → Operating system → Firmware (BIOS) → Hardware

Where the BIOS and its settings are stored

The BIOS program: EEPROM

The BIOS is stored in a type of ROM called an EEPROM (electrically erasable programmable ROM). It is flash memory, so its contents remain when the power is off. It can also be rewritten or updated.

EEPROM detail goes beyond the syllabus. It is here to explain the BIOS.

The BIOS settings: CMOS

Settings such as the clock speed are stored on a CMOS chip (complementary metal oxide semiconductor). It is powered all the time by a rechargeable battery on the motherboard.

If the battery is removed, the settings reset to the factory defaults when power returns. The BIOS program itself is unaffected, as it is held in EEPROM.
