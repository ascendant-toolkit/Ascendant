Utility Software and Program Libraries

Coursebook: Chapter 5 · System software · section 5.1 Operating systems

Disk formatters, defragmentation, virus checkers, back-up and compression, and program libraries and DLLs with their benefits and drawbacks, with animations, a defragmentation lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

Utility software is system software that performs housekeeping and maintenance tasks to keep the computer running well; examples are the disk formatter, virus checker (anti-malware), defragmentation software, disk contents analysis/disk repair software, file compression software and back-up software. A program library is a set of pre-written, pre-compiled and pre-tested routines that can be imported or called by other programs. Using library routines saves programming and testing time and gives access to complex routines; a drawback is that a routine may not match the needs exactly or may not work with the current program. A Dynamic Link Library (DLL) file is loaded into memory only when a program needs it, is shared by several programs and can be updated without recompiling the main program. Every exam answer pairs a utility or a library benefit with its reason.

1 · Utility software

UtilityPurposeHow it helps
Disk formatterPrepares a disk for first use: initialises it, sets up a file system (file allocation table, directory structure), creates partitions, a boot sector, a volume label, and checks the disk for errors; erases all dataA new disk cannot store files until it has been formatted
DefragmentationRearranges the blocks of each file so that they are contiguous, and collects the free space togetherOver time saving and deleting files splits them into fragments. Contiguous files need less head movement, so the files are accessed faster (a magnetic hard disk benefit)
Virus checker (anti-malware)Scans for malicious program code and deletes or quarantines itProtects data; can free memory taken by replicating malware
Disk contents analysis / disk repairScans the disk for errors, marks bad sectors so they are not used, and corrects inconsistencies or restores corrupted filesPrevents data loss and improves reliability
File compressionReduces the size of filesSaves storage space and reduces transmission time and bandwidth
Back-upMakes copies of files at regular intervals, often automaticallyIf the data is lost or corrupted it can be restored

2 · Program libraries

A program library is a set of pre-written, pre-compiled (pre-tested) subroutines that can be called by other programs by installing or importing the library.

BenefitsDrawbacks
Saves development time because the code is already written; saves testing time because it is already tested and documented, so it is more likely to work; the programmer can use complex routines they could not write themselves; the source code is more readable (the routine is just called); team members can share and reuse routinesThe routine may not be compatible with the current program; it may not be thoroughly tested; it may not match the needs exactly, so it must be edited and tested; if someone else changes the library, unexpected errors may appear

3 · Dynamic Link Libraries (DLLs)

  • The DLL is separate from the program and is loaded into memory only when needed (and only once), so the program uses less memory and its executable file is smaller.
  • A single DLL file can be shared by several programs, which saves memory and disk space.
  • The DLL can be updated, fixed or improved independently: the calling program does not need to be recompiled, and all programs that use the DLL get the update.

Common ways to lose marks

  • Saying defragmentation "makes the computer faster" with no reason. Say the file is contiguous, so there is less head movement.
  • Describing a formatter as "deleting everything". It prepares a disk by creating a file system, partitions and a boot sector.
  • Saying a library "contains code". It contains pre-written, pre-tested routines that are imported.
  • Listing a DLL benefit that is really a library benefit. A DLL is separate, loaded when needed and updatable on its own.
  • Giving a drawback with no consequence, such as "might have bugs". Add "so it needs to be tested".

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

Explain 2 marks Explain why a user would run defragmentation software on a magnetic hard disk but not on an SSD.
ReminderMoving parts.

A magnetic disk has a read/write head that moves, so contiguous files reduce head movement An SSD has no moving parts, so fragmentation does not slow it

Describe 2 marks Describe how back-up software protects a school's data.
ReminderCopies, restore.

It makes copies of the data at regular intervals so that if the data is lost or corrupted it can be restored

State 2 marks State two benefits of file compression when emailing a large file.
ReminderTime, space.

The file takes less time to send It uses less storage space or bandwidth

Explain 3 marks Explain why a game that uses a DLL can be patched without reinstalling the whole game.
ReminderSeparate, independent update.

The DLL is a separate file from the main program so it can be replaced or updated independently and the main program does not need to be recompiled

Describe 2 marks Describe one drawback of using a library routine.
ReminderNot matching needs.

The routine may not match the needs exactly so it will need to be edited and tested, or may give unexpected results

Top tips

  • Utility plus reason. Defrag: contiguous, less head movement.
  • Formatter: prepare, file system, partitions. It also erases data.
  • Library: pre-written and pre-tested. Time saved on writing and on testing.
  • DLL: separate, loaded when needed, shared. Updated without recompiling.
  • Drawbacks need a consequence. Not matching needs, so it must be edited.
  • Describe means more than name. Always give what it does.
