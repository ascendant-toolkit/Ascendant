Artificial Intelligence (AI)

What AI is, its main characteristics, how expert systems work, and what machine learning is.

The big idea

Artificial intelligence simulates intelligent behaviour using data and rules, reasoning and sometimes learning. Expert systems follow rules written by people; machine learning adapts from examples.

6.3 Artificial intelligence (AI)

Artificial intelligence (AI) is a branch of computer science dealing with the simulation of intelligent behaviours by computers. The computer is not truly thinking; it is following programs and data that make it behave as if it were.

Main characteristics of AI

Data and rules

The collection of data and the rules for using that data.

Reasoning

The ability to reason: use the data and rules to reach a conclusion or make a decision.

Learning and adapting

It can include the ability to learn and adapt: to improve from experience without being reprogrammed.

Examples

Voice assistants, chess programs, spam filters, recommendation systems, medical diagnosis, driverless cars, face unlock.

Expert systems

An expert system imitates a human expert in one subject, such as medical diagnosis or finding a car fault. It has four components:

ComponentPurpose
Knowledge baseA large store of facts and information about the subject, collected from experts.
Rule baseA set of IF ... THEN rules that say how to use the facts to reach a conclusion.
Inference engineThe part that applies the rules to the knowledge base and the user's answers to reach a conclusion.
InterfaceHow the user enters information (answers to questions) and receives the result.
  1. The user answers questions through the interface.
  2. The inference engine uses the rule base to search the knowledge base for a match.
  3. The system shows its conclusion (often with a probability and an explanation).

Advantages

  • Available all day, and consistent
  • Holds the knowledge of many experts
  • Can give an answer quickly

Disadvantages

  • Expensive and slow to build
  • Only as good as its rules and data; no common sense
  • Must be updated by people as knowledge changes

Machine learning

Machine learning is when a program has the ability to automatically adapt its own processes and/or data. Instead of being given every rule by a programmer, it is shown a large number of examples (training data) and works out the patterns itself. The more data it sees, the more accurate it can become.

  • A spam filter is shown thousands of emails marked spam or not spam and learns which features suggest spam. When a user marks a wrong result, it adjusts.
  • A recommendation system learns your tastes from what you watch.
Expert systemMachine learning
Where do the rules come from?Written down by human expertsFound by the program from training data
Does it change itself?No, people must update itYes, it adapts as it receives more data
PartsKnowledge base, rule base, inference engine, interfaceA program, and a lot of data to learn from

Spam filters

An email service learns from messages users mark as spam and adapts to new tricks without a programmer writing a rule for each.

Exam use: machine learning: it adapts using examples.

A medical diagnosis helper

A doctor enters symptoms. The system applies rules built from experts' knowledge and suggests likely illnesses with probabilities.

Exam use: an expert system: knowledge base, rule base, inference engine and interface.

Voice assistants

They recognise speech, look up information and improve as they hear more voices.

Exam use: AI: data, rules, reasoning and learning.

Streaming recommendations

A service learns from what you watch and suggests similar programmes.

Exam use: machine learning: patterns found in data.

Chess programs

They store opening knowledge and rules, and search possible moves to choose the best one.

Exam use: AI simulating intelligent behaviour using data and rules.

Driverless cars

Cameras and sensors feed a system trained on huge numbers of examples to recognise road signs and pedestrians.

Exam use: AI and machine learning combined with sensors and actuators.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State what is meant by artificial intelligence.
ReminderBranch of CS, and what it simulates.
A branch of computer science dealing with the simulation of intelligent behaviour by computers.
Common mistakeSaying AI "thinks like a human". It simulates intelligent behaviour.
Q2 Describe 3 marks Describe the main characteristics of artificial intelligence.
ReminderData and rules, reasoning, learning.
It collects data and has rules for using that data. It has the ability to reason (reach conclusions from the data). It can include the ability to learn and adapt.
Common mistakeLeaving out the data and rules.
Q3 State 4 marks An expert system has four components. Name them and state the purpose of each.
ReminderKnowledge base, rule base, inference engine, interface.
Knowledge base: stores the facts and information about the subject. Rule base: a set of IF ... THEN rules for using the facts. Inference engine: applies the rules to the knowledge base to reach a conclusion. Interface: lets the user enter information and see the result.
Common mistakeMixing up the knowledge base (facts) and the rule base (rules).
Q4 Describe 4 marks Describe how an expert system is used to diagnose a fault in a car.
ReminderAnswers, rules, knowledge, conclusion.
The user answers questions about the car through the interface. The inference engine takes the answers. It uses the rule base to search the knowledge base for matches. The conclusion (the likely fault) is shown to the user through the interface.
Common mistakeDescribing a person making the diagnosis rather than the system.
Q5 Explain 3 marks Explain what is meant by machine learning.
ReminderAdapts, examples, improves.
Machine learning is when a program automatically adapts its own processes and/or data. It does this using examples (training data) rather than every rule being programmed. It can become more accurate as it receives more data.
Common mistakeSaying it "learns like a person" without saying it adapts using data.
Q6 Explain 3 marks Explain how a spam filter could use machine learning.
ReminderExamples, features, adjusts.
It is given many emails that have been labelled as spam or not spam. It finds patterns that suggest spam and uses them to classify new emails. When the user corrects a mistake, it adapts its data so that it improves.
Common mistakeWriting about writing rules by hand. That is an expert system.
Q7 Explain 3 marks Give one difference between an expert system and machine learning, and one advantage and one disadvantage of an expert system.
ReminderRules written by experts against rules learned.
Difference: the rules of an expert system are written by human experts; machine learning finds patterns in data itself (and adapts). Advantage: it can hold the knowledge of many experts and is available all day. Disadvantage: it is expensive to build and only as good as its rules and data (must be updated by people).
Common mistakeGiving two advantages and no disadvantage.

Top tips

  • AI simulates intelligent behaviour. It does not truly think.
  • Three characteristics: data and rules, reasoning, and (possibly) learning and adapting.
  • Expert system parts: knowledge base (facts), rule base (IF-THEN), inference engine (applies the rules), interface (user).
  • Machine learning adapts its own processes or data using training examples.
  • Expert system rules come from people; machine learning finds its own patterns.
