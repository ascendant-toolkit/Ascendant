Input, Output, Storage, Embedded Systems and Buffers

Coursebook: Chapter 3 · Hardware · section 3.1 Computers and their components

Input and output devices, primary memory and secondary and removable storage, embedded systems with their benefits and drawbacks, and how buffers cope with devices of different speeds; animations, a buffer lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

Every computer needs input devices to get data in, output devices to give results out, primary memory (RAM and ROM) that the processor can reach directly, and secondary storage for permanent, large-capacity storage, including removable storage that can be taken away. Primary memory is fast but limited and (RAM) loses its contents when the power goes off; secondary storage is slower, larger and keeps data without power. An embedded system is a microprocessor or microcontroller built into a larger device to do one dedicated task, such as a washing machine controller; it has benefits (cheap, reliable, small) and drawbacks (hard to update or repair). A buffer is a temporary store that holds data between two devices working at different speeds, so the faster one is not held up waiting for the slower.

Primary memory is needed because the processor can only work on data that it can reach quickly. Secondary storage is needed because RAM is volatile and too small to keep everything. Magnetic storage is cheaper per unit, long-lived under heavy read/write use and suits very large files such as continuous CCTV recordings; solid state storage has no moving parts, is faster and quieter and uses less power.

2 · Embedded systems

An embedded system is a microprocessor or microcontroller within a larger system that performs one specific task, for example the controller in a washing machine that runs the wash programs and does nothing else. Typical characteristics:

  • Dedicated to a single task, with a limited number of functions.
  • Built into a larger system (the washing machine, car lane-detection system, video doorbell).
  • Needs only a small amount of processing power, and has no general-purpose operating system.
  • Contains a processor, memory and input/output capability, with firmware in ROM that the owner cannot easily change.

In a washing machine ROM stores the start-up instructions (the program for the wash cycles) and RAM stores the choices the user has entered, the readings from the sensors and the time left in the programme.

BenefitsDrawbacks
Cheap to make and run; small; low power; reliable because it does one taskDifficult for the user to change or update the firmware; errors cannot be fixed easily and repair is a specialist task; functionality cannot be extended or adapted; faulty or outdated devices are often thrown away, leading to e-waste

3 · Buffers

A buffer is a temporary store of data held until the device is ready to receive it. It is needed where two components work at different speeds. For example, a computer sends a document to a printer much faster than the printer can print it:

  1. The computer sends the print data to the buffer at computer speed.
  2. The data is passed from the buffer to the printer at printer speed.
  3. The processor is free to carry on with other tasks instead of waiting for the slower printer.
  4. When the buffer is empty the printer sends an interrupt to ask for more data; when it is full the computer is told to stop sending.

Buffers are used with printers, 3D printers, hard disk drives, VR headsets, speakers (sound data stored until the player takes it) and in streaming video.

4 · Common ways to lose marks

  • Defining an embedded system as "a small computer". It is a dedicated microprocessor built into a larger system to do one task.
  • Writing that RAM "stores the operating system" for ROM, or mixing them up. ROM holds boot-up instructions; RAM holds what is running now.
  • Describing a buffer as storage "to make it faster". It stores data until the device can process it, to cope with a difference in speed.
  • Saying secondary storage is "slower RAM". It is non-volatile storage that the processor cannot access directly.
  • Writing one drawback of embedded systems without the reason, such as "they break". Say the firmware cannot be easily changed or repaired.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Printing a long document

Your computer sends the whole document to the printer's buffer in seconds, then you carry on while it prints page by page.

Exam use: a buffer frees the processor.

A microwave or a washing machine

A small chip runs the programs for one job. You cannot install new software on it, which is why it counts as an embedded system.

Exam use: dedicated task, firmware you cannot change.

Why your computer slows when RAM is full

RAM is fast but limited. If it fills, data has to be fetched from secondary storage, which is slower.

Exam use: primary memory is fast; secondary storage is slower.

A USB stick

You save a file on it and take it to another computer. It is removable secondary storage.

Exam use: removable storage.

Smart doorbells and car systems

A small dedicated computer inside the product does one job, such as detecting motion or keeping the car in its lane.

Exam use: embedded systems are built into larger systems.

Top tips

  • Embedded: dedicated, built in. A microprocessor performing one task inside a larger system.
  • RAM now, ROM start-up. RAM holds what is running; ROM holds the boot instructions.
  • Primary: direct. Secondary: permanent. Secondary data must be loaded into RAM first.
  • Buffer: temporary store. Different speeds; the faster device is not held up.
  • Interrupt when the buffer is empty. The device asks for more data.
  • Embedded drawbacks. Firmware hard to change; repair is specialist; e-waste.
