Sequence

Instructions that run one after another, in order: input, process, output, and why the order matters.

The big idea

A program is a list of instructions. Sequence means they run one after another in the order written. Get the order wrong, and the program may give the wrong answer or fail.

8.1.4 Sequence

Sequence means the instructions in a program run one after another, in the order they are written, from the top to the bottom. Nothing is skipped and nothing is repeated. Every program uses sequence, and selection and iteration are built on top of it.

Input, process, output

Most simple programs follow the same pattern. They take in data (input), work something out (process), then show the result (output). A value is stored with an assignment: the arrow ← means "store the value on the right in the variable on the left".

PartPseudocodeWhat it does
DeclareDECLARE Price : REALNames a variable and says what type of data it holds
InputINPUT PriceReads a value from the user into the variable

OutputOUTPUT "Total: ", TotalShows text and values to the user

The order matters

The computer cannot look ahead. A line can only use a variable that has already been given a value by an earlier line. Put the lines in the wrong order and the program gives an error or a wrong answer.

Order of the linesIf the process line came before the INPUT lines, Price and Quantity would have no values yet. The result would be an error, or a meaningless answer.

Swapping two values

A classic sequence problem. To swap A and B you cannot just write A ← B, because the old value of A is lost. Use a temporary variable to hold it, and get the three lines in the right order.

5 · Multiple choice

Descriptions are kept general. Check current details before quoting specifics.

A recipe

Beat the eggs, add the flour, then bake. Do the steps in a different order and you get a different result, or a mess.

Exam use: sequence is a set of steps carried out in order. Say what goes wrong if the order changes.

An ATM withdrawal

Insert the card, enter the PIN, choose an amount, take the cash. The machine will not let you take cash before the PIN is checked.

Exam use: the order of statements matters because later steps rely on earlier ones.

A calculator

You type the first number, the operator, then the second number. The calculator then works the answer out and displays it.

Exam use: input, then process, then output.

Swapping seats

Two students want to swap desks, but both desks are full. One has to put their bag down in a spare spot first.

Exam use: a temporary variable holds one value while the other is moved.

Top tips

  • Sequence = in order. One statement after another, top to bottom.
  • A variable needs a value before you use it. Inputs and assignments come first.
  • Input, process, output. Most simple programs follow this pattern.
  • ← stores a value. Read X ← Y + 1 as "X becomes Y + 1".
  • To swap two values you need a temporary variable.
  • When tracing, write down each variable's new value after every line.
