IGCSE Computer Science · 0478 · Exam technique

Logic Circuits, Truth Tables and Databases: Technique and Practice

How logic circuits, truth tables and single-table databases are marked in Paper 2: expressions, working columns, drawing circuits, SQL output, data types and primary keys, with eight real questions.

This part in five sentences

Logic gates, truth tables and a single-table database together made about 16 to 17 of the 75 marks in the Oct/Nov 2024 versions of Paper 2 that this review draws on, and almost every one of those marks is exact: a symbol is right or wrong, a truth table output is 0 or 1, an SQL output either matches the table or does not. For logic, you work one gate at a time: write an expression from a circuit by naming each gate's output, complete a truth table with a working column for each gate, and draw a circuit gate by gate without simplifying. A four-mark truth table is marked by the number of correct outputs, so one slip costs a mark rather than all of them, and the examiner reports say tables are usually answered well. For databases, know the words (field, record, primary key, data type), and read an SQL statement in the order the computer does: FROM, WHERE, ORDER BY, then SELECT. The output of a query is the selected columns of the matching rows, written without extra punctuation, in the order of the table or the ORDER BY.

1 · The six gates

Every gate except NOT has two inputs. The syllabus says logic circuits have a maximum of three inputs and one output, and that circuits must be drawn for the statement given, without simplification.

2 · Expressions: write one from a circuit

Work from the left. Name the output of each gate, then combine. The mark scheme for a three-input circuit gave one mark for each gate or part and one for the whole expression: for a circuit with a NOT gate, an XOR gate and an OR gate, the points were NOT X, Y XOR Z and NOT X OR (Y XOR Z).

3 · Truth tables

  • Rows in binary order: for three inputs, 000, 001, 010, 011, 100, 101, 110, 111. Eight rows.
  • Use the working space. Add a column for each gate in the order you worked it out. A slip is then easy to find.
  • Do the NAND or NOR last. The Feb/March 2025 report notes a common error: the final output column was the exact opposite of the correct answer. A missed final NOT in a NAND or NOR would cause exactly this, so work out the AND or OR first and then reverse it.

4 · Drawing a circuit from an expression

  1. Find the innermost brackets. In (NOT P OR Q) NAND (Q XOR R) there are three: NOT P, then OR with Q, then Q XOR R.
  2. Draw one gate for each operator. Three gates have two inputs; NOT has one. Each gate may have at most two inputs.
  3. Connect the outputs of the first gates to the final gate (NAND).
  4. Label the inputs and the output.
  5. Do not simplify. The Feb/March 2025 report says candidates who built the circuit directly from the expression, without changing any gates, generally achieved the best marks.

The mark scheme gives one mark for each correct gate with its correct inputs.

6 · Reading and writing SQL

The syllabus limits SQL to SELECT, FROM, WHERE, ORDER BY (ascending or descending), SUM, COUNT, AND and OR, in a single table.

KeywordWhat it does
SELECTLists the fields to display
FROMNames the table
WHEREGives the search condition
ORDER BYSorts the rows: ascending by default, or descending
SUM, COUNTAdds the values of a field, or counts the records

Giving the output of an SQL statement

  1. FROM: find the table.
  2. WHERE: mark the rows that meet the condition.
  3. ORDER BY: put those rows in order, if asked.
  4. SELECT: write only the fields listed, in the order listed.
  5. Copy the data exactly, with no punctuation added. The Oct/Nov 2024 report says punctuation should not be in the output of an SQL statement.

A 3-mark output question in Oct/Nov 2024 had one mark for data from the four correct columns (any rows, any order), one for the rows being in the order of the table, with at least two rows and two columns, and one for all the data correct with no extra content. The report says candidates who copied the data from the table in the same order as it appeared got all three marks.

Completing an SQL statement

A question asked for the names of the cheeses out of stock. The accepted answer was SELECT Name FROM CheeseStock WHERE NOT InStock, or InStock = FALSE or No, or WeightKg = 0.0. The follow-up part asked how one line could change to show the same information, and the mark scheme accepted checking either the Boolean field or the weight field, so name the other field and the value you would test. The report says a minority did so and some gave no reason.

Explaining what SQL does

For SUM(Minutes) FROM Songs WHERE Genre = "rock" and COUNT(Title) … the mark scheme gave one mark each for: finding the total number of minutes of music, finding the total number of songs, and "available for the genre rock". Say what is added or counted, and which records.

7 · Common ways to lose marks

  • Writing the NOT after the input, or simplifying the expression.
  • The last column opposite to the right answer, from missing the final NOT in NAND or NOR.
  • Adding extra gates to the circuit or giving a gate three inputs.
  • Counting the heading row as a record, or swapping fields and records.
  • Choosing a field with repeated values as the primary key.
  • Adding commas, brackets or the headings to the output of an SQL statement.
  • Writing the columns in the table's order instead of the SELECT order.
  • Changing the WHERE line without naming a field and a value when asked how it could be changed.

6 · Multiple choice

These come from the Principal Examiner Reports for Cambridge IGCSE Computer Science, which describe what candidates actually wrote. The wording is ours.

NOT written after the input

Oct/Nov 2024, paper 21: many candidates produced the correct Boolean expression, but some reversed the notation for NOT X as X NOT. The mark scheme gives marks for the NOT part and for the whole expression.

Exam use: write NOT first, then the input.

The final column the wrong way round

Feb/March 2025, paper 22: the majority of candidates scored at least one mark on the truth table and many scored high marks, but a common error was that the final output column was the exact opposite of the correct answer.

Exam use: after the last gate, check whether it is NAND or NOR and that its final NOT has been applied.

Building the circuit directly

Feb/March 2025, paper 22: candidates who drew the circuit straight from the given expression, without simplifying or altering any gate, generally scored best. The question says not to simplify.

Exam use: one gate for each operator, in the order of the brackets.

Fields and records the wrong way round

Oct/Nov 2024, paper 22: most candidates stated 11 fields and 15 records, but a small number reversed the two values.

Exam use: fields are the columns; records are the rows.

Punctuation in the SQL output

Oct/Nov 2024, papers 21 and 22: the most common error in giving the output of an SQL statement was extra data such as punctuation marks. Candidates who copied the data from the table in the same order scored all three marks.

Exam use: write the values as they appear in the table, one record per line.

Another field with no reason

Oct/Nov 2024, paper 21: a minority of candidates identified another field that could have been used in the WHERE line, and some gave no explanation. The mark scheme accepted the Boolean InStock field set to FALSE, or the weight field set to 0.0.

Exam use: name the field and the value, and say that it picks out the same records.

Based on Oct/Nov 2024 · 0478/23 · Q11 [7] The table MusicStock has fields ItemNo, Name, InStock (Yes or No), Weight, PricePerItem and Quantity, with these records: M1 Drum Yes 5 40.00 7; M2 Cymbal Yes 5 60.50 3; M3 Snare No 5 35.00 0; M4 Triangle Yes 1 12.00 20. (a) Write the output of SELECT ItemNo, Name FROM MusicStock WHERE Weight = 5 ORDER BY PricePerItem; (b) (i) Complete an SQL statement to display only the names of the items that are out of stock. (ii) Explain how another SQL statement using a different field could display the same information.
What the mark scheme wants
  • (a) Three marks: one for each correct line, maximum two, and one for the order of the lines. Weight 5 gives M1, M2 and M3; ordered by price, lowest first: M3 Snare; M1 Drum; M2 Cymbal
  • (b)(i) Two marks: SELECT Name; FROM MusicStock; WHERE NOT InStock (or InStock = No, or Quantity = 0)
  • (b)(ii) Two marks for either point: the WHERE clause can check the InStock field for FALSE or No (1) …
  • … or the WHERE clause can check the Quantity field (1) for 0 (1)
Plan

Order by the price, lowest first: 35.00, 40.00, 60.50. ORDER BY changes the order of the rows but SELECT still controls the columns. For (ii) name the other field and the value.

Top tips

  • Work one gate at a time. Name each gate's output.
  • NOT goes first. NOT X, never X NOT.
  • Add working columns. Do the NAND or NOR last.
  • Do not simplify. One gate per operator.
  • FROM, WHERE, ORDER BY, SELECT. That is the order to read a query.
  • Copy the data exactly. No punctuation, table order.
  • Rows are records, columns are fields. Do not count the heading.
