User-defined Types: Enumerated and Pointer

Coursebook: Chapter 13 · Data representation, section 13.1 User-defined data types

Why user-defined types are needed, composite against non-composite, enumerated and pointer types and how to declare them; animations, labs and the real 9618 questions from 2021 to 2026.

This page in five sentences

A user-defined data type is a type the programmer builds because the language does not already have one that fits the data. A non-composite type is defined without referring to another data type's structure: an enumerated type is an ordered list of every value the variable may take, and a pointer type stores the memory address of a variable of a stated type. A composite type (record, set, class) is built from other types and is covered on the next page. Declaring a type lets the compiler reject impossible values, makes code easier to read, and stores the data in the right amount of space. In the exam you write the TYPE statement, say what the type is, and give its characteristics.

1 · Why user-defined types are needed

  • The language only has a few built-in types (INTEGER, STRING, REAL, BOOLEAN, CHAR, DATE). A programmer may need a type that does not exist, such as "day of the school week".
  • A user-defined type matches the data exactly: a variable of type SchoolDay can only hold one of five values, so a typing mistake or an impossible value is rejected.
  • It makes the program easier to read: Today ← Wednesday is clearer than Today ← 3.
  • It lets several related items be grouped under a single identifier (composite types).

The mark scheme's answers: to create a new data type from existing ones; to allow types not available in the language to be constructed; to extend the flexibility of the language; to represent a particular group of data under a single identifier; to make the code easier to read.

3 · Enumerated types

An enumerated type is a user-defined non-composite type whose possible values are given as a list. Each value is a name, not a string: no quotation marks.

TYPE SchoolDay = (Monday, Tuesday, Wednesday, Thursday, Friday)TYPE WeekEnd = (Saturday, Sunday) DECLARE Today : SchoolDayToday ← Wednesday                    // a value from the list, no quotation marksIF Today < Friday THEN               // ordered, so < and > can be used   OUTPUT "Not the end of the week yet"ENDIF

Characteristics of the list (all are mark-scheme answers):

  • It contains all the possible values, and the list is fixed: values cannot be added after it is defined.
  • It is ordered (ordinal): the values have a position, so they can be compared and counted through. Wednesday comes after Tuesday.
  • The values are unique (no repeats) and all of the same kind.
  • A variable of the type can hold one value from the list.

Internally each value is stored as a small whole number (its ordinal position, starting at 0), which is why enumerated types take little space and are fast to compare.

from enum import Enum class SchoolDay(Enum):                # Python's equivalent of an enumerated type    MONDAY = 0    TUESDAY = 1    WEDNESDAY = 2    THURSDAY = 3    FRIDAY = 4 Today = SchoolDay.WEDNESDAYprint(Today.value)                    # 2print(Today.value < SchoolDay.FRIDAY.value)   # True

4 · Pointer types

A pointer type is a user-defined non-composite type that references a memory location. It stores an address, not a value, and the declaration says what type of data is stored at that address. The symbol ^ in the type declaration means "pointer to".

TYPE TIntPointer = ^INTEGER           // a pointer to an INTEGERTYPE Word = ^STRING                   // a pointer to a STRING DECLARE Score : INTEGERDECLARE P : TIntPointer Score ← 40P ← ^Score                            // P now holds the address of ScoreOUTPUT P^                             // P^ is the value stored at that address: 40P^ ← P^ + 2                           // changes the value at that addressOUTPUT Score                          // 42: Score has changed too
NotationMeaning
^INTEGER in a TYPEThe type is a pointer to an integer
P ← ^ScoreStore the address of Score in the pointer P
P^The value at the address held in P (following the pointer)

Pointers are used to build structures that link items by address, such as linked lists, and to pass big items around without copying them. Python hides addresses: a variable holding a list or object is already a reference to it.

5 · Writing the declarations

  1. Start with TYPE, then the new name, then =. Use only the equals sign: TYPE Animals = (Alpaca, Chicken, Donkey).
  2. For an enumerated type, put the values in brackets, in the order given, separated by commas, with no quotation marks and no extra punctuation.
  3. For a pointer type, write ^ and the type of the data: TYPE Word = ^STRING.
  4. Declare a variable of the type with DECLARE Name : TypeName.

6 · Common ways to lose marks

  • Putting quotation marks round enumerated values, or changing the order the question gives them.
  • Writing a pointer type without ^, or without the type it points to.
  • Saying a pointer "points to a value". It stores the address (memory location) of the value.
  • Saying an enumerated type "holds a list of values". A variable holds one value; the type defines the list of allowed ones.
  • Defining non-composite as "simple". Say it is defined without reference to another data type.
  • Leaving out the "ordered" characteristic of an enumerated list.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Days, months and menu choices

A calendar program has a Month type with twelve named values. A menu has a Choice type (Start, Options, Quit). A variable of these types cannot hold an impossible value, so mistakes are caught early.

Exam use: enumerated types make code clear and safe.

Traffic lights and game states

A traffic light has exactly three states, Red, Amber and Green, in a fixed order. A game has states such as Menu, Playing and GameOver. The program moves from one value to the next.

Exam use: an ordered list of all possible values.

Linked lists and trees

Each item in a linked list stores a pointer to the next item. The pointer holds the memory location of the next node, not the data itself.

Exam use: pointers store addresses and make it easy to link structures together.

Passing a large item to a subroutine

Rather than copying a huge record, a program can pass the address of it. The subroutine follows the pointer to read or change the original.

Exam use: a pointer references a memory location.

Days of the week in a database

A database stores 0 to 6 for the weekday instead of the words, because it takes less space. The program shows the names to the user.

Exam use: enumerated values are stored as ordinal numbers.

Distinguish 2 marks Distinguish between an enumerated type and a pointer type.
ReminderWhat does each store?

An enumerated type has an ordered list of all the possible values, and a variable holds one of them. A pointer type stores the address (memory location) of a variable of a stated data type.

Top tips

  • Copy the values exactly. Keep the order the question gives, with no quotation marks and no extra punctuation.
  • Use the type words. Enumerated: an ordered list of all possible values. Pointer: stores an address and says what type of data is there.
  • Say 'without referencing another type'. That is the mark for non-composite.
  • Give the reason for a type. A type the language does not have, tailored to the data, clearer code, fewer errors.
  • ^ means pointer. TYPE Word = ^STRING. P^ is the value at the address.
  • Check what the type should hold. Quarter1 holds three months, not twelve.
