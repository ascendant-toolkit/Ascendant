This page in five sentences

Data validation is an automatic check that data entered is reasonable and sensible, within specified bounds, in the right format: it protects the integrity of data but does not prove the data is correct (a valid date of birth can still be the wrong date). The checks you need are range, limit, length, type, presence, format, existence (look-up) and check digit. For each check you must say what it tests and apply it to the data in the question, for example a date of birth. Validation is different from verification (checking that data matches the original): validation checks the data is sensible, verification checks it is the same as the source. A check digit is calculated from the other digits, appended to the number, and recalculated on entry to detect errors.

2 · A check digit

In the method used in the exam, the check digit is the remainder when the sum of the digits is divided by 10. For 4162: 4 + 1 + 6 + 2 = 13, remainder 3, so the new number is 41623. On entry the computer recalculates the digit from the other digits and rejects the input if it does not match. This method detects single-digit errors: 41633 is rejected. It does not catch errors that keep the sum the same: two digits that swap, or changes whose effect cancel out.

3 · Validation does not mean correct

Validation checks that data is reasonable and within bounds; it does not check that accurate data was entered. Verification checks that the data matches what was given; it does not check that the original data was accurate. So data can still be wrong after validating and verifying, for example when the original document itself was wrong.

Common ways to lose marks

  • Describing a check without applying it to the data in the question. Say "the date of birth must be between 1900 and today", not "checks the range".
  • Mixing range and limit: range has two ends, limit has one.
  • Saying validation makes sure the data is correct. It makes sure it is sensible.
  • Confusing validation with verification: double entry and visual checks are verification.
  • Saying a check digit "makes sure the number is right". It detects most single-digit errors but not all errors.

The form refuses to continue if the email is blank (presence), has no @ (format) or the password is too short (length).

A bar code

The last digit of a bar code is a check digit; a scanner recalculates it and beeps if a digit was misread.

Exam use: check digit.

Entering a date of birth

Reminder(a) The first two digits must still sum to 5 (or 15). (b) Sum the digits, MOD 10, append.

(a) Number: any number where the first two digits sum to 5 or 15 and the last three digits are 623, for example 32623 Explanation: the remainder is the same, or the sum of the digits is the same

(b) One answer:

FUNCTION Generate(Number : INTEGER) RETURNS INTEGER   DECLARE Total, Index, CheckDigit : INTEGER   DECLARE NumString : STRING   Total ← 0   NumString ← NUM_TO_STR(Number)   FOR Index ← 1 TO LENGTH(NumString)      Total ← Total + STR_TO_NUM(MID(NumString, Index, 1))   NEXT Index   CheckDigit ← Total MOD 10   Number ← Number * 10 + CheckDigit   RETURN NumberENDFUNCTION

Function heading, parameter, return type and ending Initialise Total Convert Number to a string and loop for its length Attempt to sum the digits in a loop Completely correct sum of digits Calculate CheckDigit Add CheckDigit to the original number multiplied by 10 and return it

Top tips

  • Apply the check to the data. Not just 'checks the range'.
  • Range: two ends. Limit: one. Know which one you mean.
  • Validation: reasonable. Not correct.
  • Check digit: sum, MOD 10, append. Detects single-digit errors.
  • Existence: a list of values. Also called look-up.
  • Verification is a different mark. Double entry, visual check.
