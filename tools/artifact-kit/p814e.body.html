String Handling

Measuring, slicing, changing and joining text: LENGTH, SUBSTRING, UCASE, LCASE and concatenation.

The big idea

A string is a row of characters. Built-in functions can measure it (LENGTH), cut pieces from it (SUBSTRING), change its case (UCASE, LCASE) and join strings (&).

8.1.4 String handling

A string is text: a row of characters such as letters, digits, spaces and symbols. String handling means using built-in operations to measure, cut up, change and join strings. In Cambridge pseudocode the first character is position 1.

The four operations

OperationPseudocodeResult for "Computer"Python
LengthLENGTH(Word)8len(word)
Substring (start, how many)SUBSTRING(Word, 4, 3)"put"word[3:6]
Upper caseUCASE(Word)"COMPUTER"word.upper()
Lower caseLCASE(Word)"computer"word.lower()
Join (concatenate)Word & "s""Computers"word + "s"
Positions start at 1 in pseudocode, 0 in PythonSUBSTRING(Word, 1, 1) is the first letter. In Python the first letter is word[0]. The last letter is at position LENGTH(Word). Python slices word[start:end] stop before the end, so SUBSTRING(Word, 4, 3) is word[3:6].
  • Spaces count as characters. LENGTH("Good day") is 8.
  • The original string is not changed. UCASE(Word) gives a new value. To keep it, store it: Big ← UCASE(Word).
  • Strings are compared exactly. "a" and "A" are different. Convert both with UCASE or LCASE before comparing if case should not matter.

Looking at every character

Put SUBSTRING inside a FOR loop that runs from 1 to LENGTH(Word). Each repeat takes one character (SUBSTRING(Word, Index, 1)). You can then count letters with an IF, or build a new string.

Building a string

Start with an empty string "" and add to it with &. Joining each new character on the front reverses the string.

Top tips

  • Positions start at 1 in pseudocode. The last character is at LENGTH(Word).
  • SUBSTRING(Word, start, how many): say where to start, then how many characters.
  • Spaces are characters and count in LENGTH.
  • Use & to join strings. Start from "" when you build a string in a loop.
  • Strings compare exactly. "a" is not "A". Use UCASE or LCASE first if case should not matter.
  • To check every letter, loop FOR Index ← 1 TO LENGTH(Word) and take SUBSTRING(Word, Index, 1).
