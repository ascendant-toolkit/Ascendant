Procedures and Functions

Named blocks of code, parameters, returned values, and local and global variables.

The big idea

A procedure or function lets you write code once and use it many times. Parameters carry values in; a function returns a value out.

8.1.6 Procedures and functions

A procedure or function is a named block of code that does one job. You write it once, then call it by name whenever you need it. Together they are often called subroutines. They are defined at the start of the program.

Procedures

A procedure carries out a task. It is called with CALL, and the call is a complete statement on its own.

Parameters

A parameter is a variable in the routine's heading that receives a value when the routine is called. The actual value you pass in is called an argument. Parameters let one routine work with different data. At IGCSE a routine can have up to three.

Order mattersArguments are matched to parameters by position. CALL Greet("Mai", 2) gives Name "Mai" and Times 2. Swapping them is an error.

Functions

A function works like a procedure but returns one value to the place it was called. The heading states the data type with RETURNS, and RETURN sends the value back. A function is called inside an expression (assigned, output or compared) and never with CALL.

Local and global variables

The scope of a variable is the part of the program where it can be used. A global variable is declared outside all routines and can be used anywhere. A local variable is declared inside a routine, can only be used there, and exists only while that routine is running. Parameters behave like local variables.

Prefer localLocal variables cannot be changed by accident from elsewhere, the same name can safely be reused in different routines, and their memory is freed when the routine ends.
Python and globalsA variable assigned inside a Python def is local. To change a global one you must write global total first.

Why use subroutines?

Code is written once and reused. The program is shorter and split into manageable parts. Each part can be written and tested on its own, often by different people, and a fix is made in one place only.

A cash machine menu

Showing the balance, printing a receipt and ejecting the card are each separate routines called from the main program.

Exam use: procedures: each carries out a task and can be reused from several menu options.

A currency converter

Give it an amount and an exchange rate and it hands back the converted amount.

Exam use: a function with two parameters that returns a real value.

A game with many levels

One routine draws an enemy at any position. It is called hundreds of times with different coordinates.

Exam use: parameters let one routine work with different data, so code is not repeated.

A large team project

Programmers each write routines using their own local variables, then combine them.

Exam use: local variables avoid clashes between names; routines can be tested separately.

ReminderThink about returning and calling.
A function returns a value, a procedure does not A function is called as part of an expression, a procedure is called with CALL

Q2 State 2 marks Explain what is meant by a parameter.
ReminderWhere does its value come from?
A variable in the heading of a procedure / function that receives a value passed in when the routine is called
Common mistakeSaying it is the value the function returns.
Q3 Write 4 marks Write a procedure Stars that takes an integer parameter Number and outputs "*" that many times. Then call it to output 8 stars.
ReminderHeading, loop, end, call.
PROCEDURE Stars(Number : INTEGER) ... ENDPROCEDURE loop from 1 TO Number OUTPUT "*" inside the loop CALL Stars(8)
PROCEDURE Stars(Number : INTEGER)    DECLARE Count : INTEGER    FOR Count ← 1 TO Number        OUTPUT "*"    NEXT CountENDPROCEDURE CALL Stars(8)
Common mistakeAsking the user to INPUT Number inside the procedure. Its value arrives through the parameter.
Q4 Write 4 marks Write a function Larger that takes two integers and returns the larger one.
ReminderA function needs RETURNS and RETURN.
FUNCTION heading with two integer parameters RETURNS INTEGER IF comparing the two parameters RETURN the correct value in each branch, then ENDFUNCTION
FUNCTION Larger(A : INTEGER, B : INTEGER) RETURNS INTEGER    IF A > B      THEN        RETURN A      ELSE        RETURN B    ENDIFENDFUNCTION
Common mistakeUsing OUTPUT instead of RETURN, so nothing is sent back.
Q5 State 3 marks State the output of this program.
FUNCTION Double(N : INTEGER) RETURNS INTEGER    RETURN N * 2ENDFUNCTION OUTPUT Double(Double(4))
ReminderWork out each call, then the expression.
Double(4) returns 8 Double(8) returns 16 Output: 16
Common mistakeStopping after the first call. The inner call is worked out first, then its result is passed in again.
Q6 Explain 4 marks Explain the difference between a local and a global variable.
ReminderWhere is it declared, and where can it be used?
A global variable is declared outside any procedure / function (in the main program) and can be used anywhere in the program A local variable is declared inside a procedure / function and can only be used within that routine
Common mistakeWriting that local variables are "smaller" or "temporary files". Describe scope.
Q7 State 2 marks State the two values output by this program, in order.
DECLARE Number : INTEGER PROCEDURE Show    DECLARE Number : INTEGER    Number ← 7    OUTPUT NumberENDPROCEDURE Number ← 3CALL ShowOUTPUT Number
ReminderWhich Number does each OUTPUT use?
7 (the local Number) 3 (the global Number is unchanged)
Common mistakeOutputting 7 twice. The local variable does not change the global one.
Q8 Identify 3 marks Identify three errors in this pseudocode.
FUNCTION Half(N : INTEGER)    OUTPUT N / 2ENDFUNCTION CALL Half(10)
ReminderCheck the heading, the value sent back and the call.
RETURNS and the data type are missing from the heading OUTPUT used where RETURN is needed CALL must not be used to call a function (use it in an expression, e.g. OUTPUT Half(10))
Common mistakeReporting spelling or indentation instead of errors in the logic of a function.
Q9 Write 7 marks Write a function Grade that takes a mark and returns "Pass" if it is 50 or more, otherwise "Fail". Then write code that inputs 20 marks, uses the function for each, outputs the result and finally outputs how many passed.
ReminderDefine the function first, then the main program.
FUNCTION Grade(Mark : INTEGER) RETURNS STRING IF Mark >= 50 RETURN "Pass" ELSE RETURN "Fail" Passes ← 0 before the loop loop 20 times with INPUT inside function called in an expression and result output add 1 to Passes when the result is "Pass" OUTPUT Passes after the loop
FUNCTION Grade(Mark : INTEGER) RETURNS STRING    IF Mark >= 50      THEN        RETURN "Pass"      ELSE        RETURN "Fail"    ENDIFENDFUNCTION Passes ← 0FOR Count ← 1 TO 20    INPUT Mark    Result ← Grade(Mark)    OUTPUT Result    IF Result = "Pass"      THEN        Passes ← Passes + 1    ENDIFNEXT CountOUTPUT Passes
Common mistakeWriting CALL Grade(Mark).
Q10 Explain 3 marks Explain three benefits of using procedures and functions in a program.
ReminderReuse, testing, readability.
Code can be reused without writing it again, so the program is shorter Each routine can be written and tested separately (or by different programmers) The program is easier to read and maintain, because a change is made in one place
Common mistakeClaiming they always make the program run faster.

Top tips

  • Function = returns a value. Procedure = does a job.
  • CALL for procedures only. Use a function inside an expression.
  • Every function needs RETURNS (heading) and RETURN (body).
  • Give each parameter a data type in the heading, and pass arguments in the same order.
  • Do not INPUT a parameter. Its value is already there.
  • RETURN sends a value back. OUTPUT shows it on screen. They are not the same.
  • Local: inside one routine. Global: everywhere.
