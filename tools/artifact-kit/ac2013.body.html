Object-Oriented Programming: Writing Classes in Python

Coursebook: Chapter 20 · Further programming, section 20.1 Programming paradigms

Declaring classes with private attributes and constructors, getters and setters, a method with a limit, child classes that call the parent constructor and override a method, and containment; animations, labs and the real Paper 4 questions.

This page in five sentences

Paper 4 asks you to write the classes you designed as Python program code: a class with private attributes and a constructor, its getters and setters, a method that does a calculation, then a child class that inherits from it and overrides a method. In Python a class is declared with class, the constructor is __init__(self, ...), and an attribute is private when its name starts with two underscores. A child class is declared with the parent in brackets and calls the parent's constructor so the inherited attributes are set. Objects are created by calling the class like a function, and objects can hold other objects (containment). The mark schemes reward the same moves every time, so learn the pattern.

1 · A class in Python

Python does not declare attributes. They are created when the constructor assigns them, so the exam asks you to include attribute declarations using comments to show the name and data type. Double underscores make an attribute private.

class Pet:    # PetName : STRING    # YearBorn : INTEGER    def __init__(self, NewName, NewYear):        self.__PetName = NewName        # private attribute        self.__YearBorn = NewYear     def GetPetName(self):               # getter: no parameter, returns the value        return self.__PetName     def SetYearBorn(self, NewYear):     # setter: takes the new value        self.__YearBorn = NewYear MyPet = Pet("Rex", 2021)                # creates an object by calling the classprint(MyPet.GetPetName())               # Rex
  • self is the object the method is running on. It is the first parameter of every method, and every attribute is self.Name. You do not pass it when you call: MyPet.GetPetName().
  • __init__ is the constructor. It takes the starting values as parameters and assigns them to the attributes.
  • A private attribute (self.__PetName) cannot be reached from outside the class as MyPet.__PetName; use the getter.
  • Parameter names should differ from attribute names (NewName, not PetName) so it is clear which is which.

2 · Getters and setters

A getter returns a private attribute and takes no parameter. A setter assigns a parameter to the attribute and returns nothing. A setter can check the value first.

def GetHorizontalPosition(self):    return self.__HorizontalPosition def SetCurrentSpeed(self, CSP):    self.__CurrentSpeed = CSP def SetPriority(self, Urgency):    if Urgency >= 1 and Urgency <= 5:       # validate before storing        self.__Priority = Urgency

Write one getter for each attribute that must be readable and one setter for each that may change. Do not return from a setter, and do not print in a getter.

3 · A method that does work

The long Paper 4 questions add a method that changes the object's state with a limit, such as a speed that cannot exceed a maximum. Read the bullets and turn each into a line.

def IncreaseSpeed(self):    self.__CurrentSpeed = self.__CurrentSpeed + self.__IncreaseAmount    if self.__CurrentSpeed > self.__MaxSpeed:          # cannot exceed the maximum        self.__CurrentSpeed = self.__MaxSpeed    self.__HorizontalPosition = self.__HorizontalPosition + self.__CurrentSpeed   # in all cases

The mark scheme gives separate marks for: adding the increase, checking the limit and limiting the speed, and adding the updated speed to the position in every case, not only when the limit is reached.

4 · Inheritance in Python

Put the parent in brackets. In the child's constructor, call the parent's constructor so the inherited attributes are set, then set the child's own attributes.

class Animal:    def __init__(self, pName, pSound):        self.Name = pName        self.Sound = pSound class Parrot(Animal):                       # Parrot inherits from Animal    # WingSpan : INTEGER    def __init__(self, pName, pSound, pWingSpan):        super().__init__(pName, pSound)     # parent constructor sets Name and Sound        self.WingSpan = pWingSpan        self.NumberWords = 0     def ChangeNumberWords(self, Change):    # a method only Parrots have        self.NumberWords = self.NumberWords + Change

Animal.__init__(self, pName, pSound) does the same as super().__init__(pName, pSound); both are accepted. A child does not repeat the parent's attributes or methods.

Private and inheritanceA double-underscore attribute in the parent is not directly visible in the child class. To change it from the child, call the parent's methods (its setters, or its own method) instead of using self.__Attribute.

5 · Overriding and polymorphism

A child that defines a method with the same name as the parent's overrides it: Python looks in the child's class first. The parent's version can still be used with super().

class Animal:    def Description(self):        return "The animal's name is " + self.Name class Parrot(Animal):    def Description(self):                   # overrides Animal.Description        return super().Description() + ". It can say " + str(self.NumberWords) + " words." Zoo = [Animal("Teddy"), Parrot("Chewie")]for A in Zoo:    print(A.Description())                   # each object runs its own version: polymorphism

6 · Containment: objects inside objects

An attribute can be another object, or an array of objects. A Hand holding five Cards creates the Cards first and passes them to the Hand's constructor. The getter returns the object at a position.

class Hand:    # Cards : ARRAY[0:9] OF Card    # FirstCard : INTEGER    # NumberCards : INTEGER    def __init__(self, Card1, Card2, Card3, Card4, Card5):        self.__Cards = []        self.__Cards.append(Card1)        self.__Cards.append(Card2)        self.__Cards.append(Card3)        self.__Cards.append(Card4)        self.__Cards.append(Card5)        self.__FirstCard = 0        self.__NumberCards = 5     def GetCard(self, Position):        return self.__Cards[Position]

8 · Common ways to lose marks

  • Forgetting self in a method header or in front of an attribute.
  • Not calling the parent constructor, so the inherited attributes are never set.
  • A constructor with too few parameters: it must take every value the question says is passed in.
  • Returning in a setter or printing in a getter.
  • Writing MaxSpeed instead of self.__MaxSpeed inside a method.
  • Concatenating a number to a string without str().
  • Not shortening the "Description" string exactly as the format in the question, including spaces and units.
  • Leaving out the attribute-declaration comments when the question asks for them.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A game with different characters

Every character has a position and moves with a method. A bike character moves faster and a magic character has spells. They inherit the position and Move() from Character and override what is different.

Exam use: inheritance with overriding: write the common part once.

Cards, hands and a deck

A Hand holds Card objects and asks them for their number and colour through getters. The Hand never needs to know how a Card stores its data.

Exam use: containment and getters: objects work together through their methods.

A medical appointment system

Appointment objects are created with the patient, doctor and date. Treatments and medications are added later with setters, and reports read them with getters.

Exam use: constructor to create, setters to update, getters to report.

A linked list or a tree

A Node class holds the data and a pointer, and a LinkedList or Tree class holds the nodes. Many Paper 4 data structure questions are written as classes.

Exam use: the same class skills apply to data structures: Node, LinkedList, Tree.

A zoo of animals

A list of Animal, Parrot and Dog objects can all be asked for a Description(). Each prints its own version without the code checking which kind it is.

Exam use: polymorphism: the loop calls one method name and each object responds in its own way.

Top tips

  • Start every method with self. def GetName(self): and self.__Name inside. A missing self is the commonest slip.
  • Copy the attribute names exactly. The question gives the names. Use them with the same spelling and data type in the comments.
  • Count the constructor parameters. Every value the question says is passed in is a parameter; the others are set to 0 or empty.
  • Getters return, setters assign. No printing in a getter and no return in a setter.
  • Child classes: parent first. Put the parent in brackets, call its constructor, then set only the new attributes.
  • Join text and numbers with str(). Description() questions are mostly string concatenation. Match the format, spaces and units.
  • Use the bullets as a checklist. Each bullet in a method description is a mark: one line of code for each.
