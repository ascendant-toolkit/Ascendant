RAM and ROM, SRAM and DRAM, and PROM, EPROM and EEPROM compared, with animations, a DRAM refresh lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

RAM is volatile primary memory that holds the programs, data and part of the operating system currently in use; ROM is non-volatile primary memory that holds the start-up (boot) instructions or BIOS. RAM comes in two forms: SRAM (static: flip-flops, no refresh needed, faster, more expensive, lower density, used for cache) and DRAM (dynamic: one transistor and a capacitor per bit, must be refreshed constantly, slower, cheaper, higher density, used for main memory). ROM comes in three programmable forms: PROM (written once), EPROM (erased with ultraviolet light, after removing the chip, all at once) and EEPROM (erased electrically, in place, byte by byte). The exam asks for definitions, differences and justifications of which type suits a device.

EEPROM suits firmware that may need updating, for example in a VR headset: it can be changed many times, without removing the chip and without technical expertise, so the headset can take advantage of new features.

4 · Choosing a memory

  • Needs speed (cache): SRAM. Needs lots of memory cheaply (main memory, buffer): DRAM.
  • Fixed instructions that never change: ROM or PROM. Firmware that may be updated: EEPROM.

Common ways to lose marks

  • Saying DRAM is "faster" or "more expensive". It is slower and cheaper.
  • Saying SRAM needs refreshing. It does not, which is why it is faster.
  • Saying EEPROM is "electronic" and EPROM is not. Both are electronic: the difference is how they are erased.
  • Giving only the difference without a contrast: say what each type does.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Your CPU's cache

The small, very fast memory next to the processor is SRAM. It is too expensive for gigabytes, so main memory is cheaper DRAM.

Exam use: SRAM for speed, DRAM for size.

A phone's updates

The device firmware is stored in a rewritable memory so the maker can update it without opening the case: the same idea as EEPROM.

Exam use: in-place updates.

A new PC starting up

Before the operating system loads, a small program in ROM tests the hardware and finds the OS on the storage.

Exam use: boot instructions in ROM.

A printer's buffer

Many printers have 1 GB of DRAM to hold print jobs: it is cheap and dense, and extra speed is not needed.

Exam use: DRAM is cheaper and denser.

Old game cartridges

Games stored in ROM could not be changed; once the data was set, it could only be read.

Exam use: read only.

Top tips

  • SRAM: flip-flops, fast. No refresh, costly, lower density.
  • DRAM: capacitor, refresh. Cheaper, denser, slower.
  • EPROM: UV, removed, whole chip. EEPROM: electrical, in situ, partial.
  • PROM: once only. Do not call it rewritable.
  • RAM: running. ROM: start-up. Say which is volatile.
  • Write a pair. 'DRAM is cheaper' needs 'SRAM is dearer' to be a difference.
