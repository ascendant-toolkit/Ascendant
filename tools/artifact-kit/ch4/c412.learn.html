The big idea

The operating system (OS) sits between the user, the applications and the hardware. It gives applications a platform to run on, a usable interface for people, and hides the complexity of the hardware. Examples: Windows, macOS, Android and iOS. The OS is stored on an HDD or SSD (phones and tablets use a solid state device).

4.1.2 Operating systems

Nine functions to know: human computer interface (HCI), memory management, security management, hardware peripheral management, file management, interrupt handling, platform for running applications, multitasking, and management of user accounts. Interrupts are covered in 4.1.4 and running applications in 4.1.3.

Memory management

  • Manages RAM and moves data between RAM and the HDD/SSD while programs run
  • Keeps track of every memory location
  • Memory protection: two applications cannot use the same locations at the same time. Without it, data could be lost, results could be wrong, data could be exposed to other software, or the computer could crash

Security management

  • Applies OS and anti-virus updates
  • Works with a firewall to check traffic
  • User accounts, passwords and access rights keep users out of private areas
  • Data recovery and system restore
  • Helps prevent illegal intrusion

Aims: the integrity, confidentiality (privacy) and availability of data.

Hardware peripheral management

  • Talks to input and output devices through device drivers
  • Gives each resource a priority
  • Controls queues and buffers

Printing: the printer driver is found and loaded, the data goes to the printer buffer (or to a queue if the printer is busy or the job has low priority), control commands are sent, and errors and interrupts from the printer are handled.

File management

  • File naming (filename.extension)
  • Create, open, close, delete, rename, copy and move files
  • Maintains directory structures
  • Access control: access rights, passwords, locking a file
  • Loads a file from the HDD/SSD into memory

Multitasking

More than one task (process) at a time, sharing the hardware under OS control. The OS monitors every process. In pre-emptive multitasking:

  • a process gets resources for a time limit
  • it can be interrupted while running
  • it has a priority. A low-priority process can be starved of resources

Management of user accounts

Each user logs on with a user name and password, and keeps their own settings, folders and files, stored separately for security. An administrator creates, deletes and restricts accounts. Multi-access levels let a clerk order stationery but not see personal data.
