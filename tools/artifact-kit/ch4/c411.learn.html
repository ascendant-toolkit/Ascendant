The big idea

Hardware alone does nothing. System software runs and manages the hardware and gives other programs a platform to run on. Application software lets the user do a specific job, such as writing an essay or editing a photo.

4.1.1 System software and application software

System software

  • A set of programs that control and manage the computer hardware
  • Provides a platform on which other software can run
  • Provides the human computer interface (HCI)
  • Controls the allocation and use of hardware resources

Examples: operating system, utility programs, device drivers, compilers and linkers.

Application software

  • Lets the user do a specific task using the computer's resources
  • May be a single program (Notepad) or a suite (Microsoft Office)
  • The user runs it as and when they need it

Examples: word processor, spreadsheet, database, photo, video and graphics editing, control and measuring software, apps.

Utility programs

Utility programs are system software that help to manage, maintain and control computer resources. Most are started by the user, but some, such as the virus checker, run quietly in the background.

Anti-virus software

  • Checks software and files before they are run or loaded
  • Compares them with a database of known viruses
  • Heuristic checking: looks for behaviour that could mean a virus, so it can catch one not yet in the database
  • Infected files go into quarantine, then are deleted automatically or the user decides
  • Needs regular updates, plus a weekly full scan to find dormant viruses

A false positive is a clean file flagged as a virus. It is a drawback of anti-virus software.

Defragmentation

On a hard disk drive (HDD), deleting and extending files leaves each file's blocks scattered over the disk. The read-write head must make many movements, so access is slower.

A defragmenter rearranges the blocks so each file is stored in contiguous (next to each other) sectors. Access is faster because there are fewer head movements.

Not a problem for an SSD, which has no moving head.

Back-up software

  • Can follow a schedule
  • Can back up only files that have changed
  • Can restore data or the whole computer, or create a restore point

For total security keep three versions: the working copy on the internal drive, a local back-up (portable SSD) and a remote back-up stored away from the computer (cloud storage).

Security software

  • Manages access control and user accounts (IDs and passwords)
  • Links to virus and spyware checkers
  • Protects network connections, for example with a firewall
  • Uses encryption so intercepted data is meaningless
  • Checks that software updates come from a legitimate source

Screensavers

Originally made to stop "phosphor burn" on old CRT monitors. Now mostly customisation, but they are also used for security: after a period of inactivity the screensaver loads and the user is logged out or the computer is locked.

They can also start background tasks that only run while the computer is idle, such as virus scans.

Other utilities

  • Disk analysis and repair: checks the contents of a disk and fixes errors
  • File compression and file management

Device drivers

A device driver is software that communicates with the operating system and translates data into a format the hardware device understands. Every hardware device, such as a printer, mouse or memory stick, needs one. Without a driver, the screen shows a message such as "device not recognised".

When a USB device is plugged in, the operating system looks for its driver. USB drivers contain descriptors that tell the computer what the device is: a vendor ID (VID), a product ID (PID) and a unique serial number. If a device has no serial number, the operating system treats it as a new device every time it is plugged in.
