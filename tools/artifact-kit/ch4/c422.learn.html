The big idea

Assembly language is a low-level language that replaces binary with short, readable codes called mnemonics. A program called an assembler translates it into machine code, normally one assembly instruction to one machine code instruction.

4.2.2 Assembly languages

Fewer programmers write in assembly language. Those who do, do so:

  • to make use of special hardware
  • to make use of special machine-dependent instructions
  • to write code that does not take up much space in primary memory
  • to write code that performs a task very quickly

A typical program: add two numbers

LDA First
ADD Second
STO Sum
  • LDA: load the value of the variable (First) into the accumulator
  • ADD: add the value of the variable (Second) to the value in the accumulator
  • STO: store the value in the accumulator in the variable (Sum)

The accumulator

The accumulator is a register in the processor that holds the value being worked on. Every calculation passes through it: load, add, then store the result back to memory.

After the assembler has translated the program, the machine code (not the assembler) is what the computer runs.

The first four bits show the instruction. The next eight show the memory address of the variable.

Assembly language must be translated by an assembler before it can run. Once assembled, the machine code can be used again and again without re-assembly.
