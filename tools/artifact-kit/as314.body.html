Monitoring and Control Systems

Coursebook: Chapter 3 · Hardware · section 3.1 Computers and their components

Sensors, actuators and feedback, how to tell a monitoring system from a control system, with a control-loop animation, a fridge lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

A monitoring system uses sensors to collect data and records, displays or reports it, but takes no action that changes what the sensors measure. A control system uses sensors and a microprocessor to decide what to do and sends a signal to an actuator that changes the environment, so the sensor's next reading is affected: that loop is feedback. Sensors produce analogue signals, which an ADC converts to digital for the processor; a DAC converts the processor's output for actuators that need an analogue signal. Exam questions always ask you to identify the system (no mark) and justify it (the marks), so learn the justification phrases. Typical sensors: temperature, light, pressure, infra-red, moisture, humidity, sound, gas, pH, magnetic field and motion.

An actuator converts an electrical signal from the processor into a physical action, for example a motor, valve, heater or the arm that pushes an incorrectly weighted chocolate bar off the production line. In the exam: an actuator generates a signal or causes an action, converting electrical energy into a mechanical force.

2 · Monitoring system

  • Collects, stores, displays or transmits the sensor data.
  • The output (a light, an alarm, a display) does not affect the input to the sensors.
  • No actuator and no feedback: the warnings are just warnings.
  • Examples: a security system that sounds an alarm, a heart-rate monitor sending to a phone, a weather station.

3 · Control system

  • The processor acts independently (autonomously) on sensor data.
  • It sends a signal to an actuator, which changes the environment, so the next sensor input is different: feedback.
  • Feedback keeps the system operating within set limits, because its output affects its next input and conditions are adjusted automatically.
  • Examples: a fridge that switches the cooling on above 6 °C and off below 4 °C; automatic doors that open when a person is within 2 m and close when nobody is; a car that brakes harder as an object gets closer.

4 · Analogue to digital

Sensors give analogue readings; the microprocessor needs digital. An ADC converts them, and a DAC converts digital output to analogue for actuators such as a motor or speaker.

5 · Combining sensors with logic

Sensors often feed logic. For a security system with E = system switched on, A = daylight level low, C = person within 2 m, B and D = front and back doors open: floodlight X = E AND A AND C; audio alarm Y = E AND (B OR C OR D). This links to the logic gates page.

Common ways to lose marks

  • Writing "it is a control system because it controls the lights". You must refer to feedback and the effect on the input.
  • Saying a monitoring system "just monitors". Say that the output does not affect the sensor input and there is no actuator.
  • Calling a warning light an actuator in a monitoring system.
  • Forgetting that a sensor measures a physical quantity and the processor, not the sensor, makes the decision.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A home thermostat

It switches the boiler on when the room is too cold and off when it is warm enough. The heating changes the temperature the sensor reads: feedback.

Exam use: a control system.

A smartwatch

It measures your heart rate and shows it on your phone, but nothing it does changes your heart rate.

Exam use: a monitoring system.

A supermarket automatic door

An infra-red sensor detects you and a motor opens the door; when you have gone through the door closes.

Exam use: actuator and feedback.

Cruise control or automatic braking

A car measures distance and brakes harder as an object gets closer; braking changes the distance, which is then measured again.

Exam use: feedback loop.

A burglar alarm

It sounds a siren when the sensors are triggered but does not change the sensors' input.

Exam use: monitoring with warnings only.

O/N 2025 · 9618/12 · Q11 Identify / Justify 3 marks An automated system opens doors when a person is detected within 2 metres and closes them when there is no longer a person within 2 metres. Identify whether it is a monitoring system or a control system. Justify your choice.

M/J 2026 · 9618/12 · Q6(a)(b)(c) Explain / Tick / Describe 3 + 2 + 2 marks A health monitor attaches to a person's arm and measures key health information, such as heart rate, and transmits it to a smartphone, which analyses it and displays the results. (a) Explain the reasons why it is an embedded system. (b) Tick monitoring or control and justify. (c) The monitor contains RAM and ROM. Describe two differences between RAM and ROM.
Reminder(a) One function, dedicated hardware, firmware. (b) Monitoring: only records, no feedback, no actuator. (c) Read/write against read only; volatile against non-volatile; running data against boot-up.

(a) Any three: It only has one function, to monitor health All the hardware such as sensors and a microprocessor is dedicated to this task The firmware cannot be easily amended or updated because its function is preset

(b) No mark for the choice. Monitoring, any two: The system only records or transmits the data It does not use feedback or change the environment The output does not affect the next input It does not contain an actuator

(c) Any two (must refer to both): RAM can be read from and written to; ROM can only be read RAM is volatile; ROM is non-volatile RAM stores currently running data and instructions; ROM stores boot-up instructions or firmware

Top tips

  • No mark for the choice. The justification earns the marks.
  • Control: actuator, feedback. The output changes the next input.
  • Monitoring: no actuator, no feedback. Warnings do not change the input.
  • Name the sensor properly. Infra-red, light, pressure, temperature.
  • Actuator: converts electrical energy to a physical action. Give the action in the scenario.
  • Link to the scenario. Name the fridge, the door, the car.
