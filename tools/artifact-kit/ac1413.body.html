The TCP/IP Protocol Suite: Four Layers

Coursebook: Chapter 14 · Communication and internet technologies, section 14.1 Protocols

The Application, Transport, Internet and Link layers: what each does, which jobs belong to which layer, and how IP and MAC addresses behave on a journey; animations, labs and the real 9618 questions from 2022 to 2026.

This page in five sentences

The TCP/IP protocol suite has four layers, from the top Application, Transport, Internet and Link. The Application layer gives programs their services and defines the protocols they use; the Transport layer breaks data into numbered packets and delivers it from the source host to the destination host; the Internet layer adds IP addresses and routes each packet; the Link layer formats frames with MAC addresses and sends them over the physical medium. Match every job to its layer: sequence numbers and re-sending are Transport, IP addresses and routing are Internet, frames and MAC addresses are Link. A packet keeps the same IP addresses for the whole journey, but the MAC addresses change at every hop. For a tour of all four layers in real situations, see the resource The Four Layers in the Real World.

1 · The four layers

LayerPurpose and functionProtocols and examples
Application (top)Provides services and an interface to the user: the programs that exchange data (web browser, email client, file transfer). Defines the protocols applications use to exchange dataHTTP(S), FTP, SMTP, POP3, IMAP, BitTorrent

Order to learnFrom the user down: Application, Transport, Internet, Link: "All Tests Include Logic". Some books call the Link layer the Network Access or Data Link layer; the exam uses Link.

2 · The Application layer

  • Provides services and an interface for the user's programs, such as login, file transfer and email.
  • Defines the protocols that applications use to exchange data (HTTP, FTP, SMTP, POP3, IMAP, BitTorrent: see 14.1.4).
  • Can provide ways of securing communication, for example encryption and authentication.

3 · The Transport layer

  • Responsible for delivery from the source host to the destination host.
  • Breaks the data into packets and adds a sequence number (and port number) to the packet header.
  • Controls the flow of packets, checks for errors and asks for lost or damaged packets to be sent again.
  • At the destination it uses the sequence numbers to put the packets back in order.

4 · The Internet layer

  • Identifies the intended network and host.
  • Adds a header containing the source and destination IP addresses and forms datagrams (packets) ready for delivery.
  • Routes each packet independently by the best available route. Routers work at this layer.

5 · The Link layer

  • Transports data within the local network segment, from one device to the next (the next hop).
  • Formats the datagrams into frames, mapping the IP address to a MAC address.
  • Ensures the correct network protocols are followed and gives the upper layers access to the physical medium (cable, Wi-Fi).

8 · Common ways to lose marks

  • Putting the layers in the wrong order. The Application layer is the top, the Link layer the bottom.
  • Describing a layer by the function of another: routing and IP addresses are the Internet layer; sequence numbers, error checking and re-sending are the Transport layer.
  • Calling the Link layer the "Network" or "Physical" layer.
  • Writing "the Application layer is the application". It is the layer that provides services to applications and defines their protocols.
  • Describing only one function. A 5-mark question wants up to three points for each layer.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Loading a web page

Your browser (Application layer) asks for a page with HTTP. The Transport layer splits the reply into numbered packets, the Internet layer addresses each one, and the Link layer sends it over Wi-Fi to your router.

Exam use: each layer does its own job as the message passes down.

A lost packet

If a packet in a download is lost, the Transport layer notices a sequence number is missing and asks for it again, without the browser having to do anything.

Exam use: the Transport layer handles sequencing, flow and error recovery.

Finding the way

A router reads the destination IP address, which was added by the Internet layer, to decide where to send each packet next.

Exam use: routing and IP addresses belong to the Internet layer.

Your router's job at home

Your home router receives a frame over Wi-Fi, takes out the packet, reads the IP address, and sends it on in a new frame to your internet provider. The MAC addresses change; the IP addresses do not.

Exam use: MAC addresses are for the next hop, IP addresses for the whole journey.

Wi-Fi or Ethernet

Plug an Ethernet cable into a laptop and the web carries on working. Only the Link layer (the way the frames are sent) has changed.

Exam use: the Link layer deals with the physical medium.

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

Describe 3 marks A browser requests a web page. Describe what the Transport layer does to the reply before it is sent.
ReminderPackets, numbers, the header.

It breaks the reply into packets (segments). It adds a header containing a sequence number (and port number) to each. It passes the packets to the Internet layer, and later checks they arrive complete and in order.

Identify 2 marks Name the layer that (a) adds the source and destination IP addresses; (b) formats the data into frames with MAC addresses.
ReminderInternet adds the IP header. Link makes frames.

(a) Internet layer (b) Link layer

Describe 3 marks A packet travels from a laptop to a server through three routers. State what stays the same and what changes about its addresses.
ReminderIP end to end, MAC at each hop.

The source and destination IP addresses stay the same for the whole journey. The MAC addresses change at each hop. Because the Link layer only moves the frame across one local network segment at a time.

State 2 marks State what the Transport layer does with the sequence numbers when the packets arrive at the destination.
ReminderPackets can arrive out of order.

It uses the sequence numbers to put the packets back into the correct order. It detects that a packet is missing and asks for it to be sent again.

Top tips

  • Learn the order. Application, Transport, Internet, Link: top to bottom.
  • Match the job to the layer. Sequence numbers, packets, re-sending: Transport. IP addresses, routing: Internet. Frames, MAC addresses, the cable or Wi-Fi: Link. User services and protocols: Application.
  • Three points per layer. A 5-mark 'describe two layers' question rewards up to three points for each.
  • IP against MAC. IP addresses stay the same for the journey; MAC addresses change at every hop.
  • Use the exam's name for the bottom layer. Link, not Network or Physical.
