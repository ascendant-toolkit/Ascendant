Protocols and the TCP/IP Stack

Coursebook: Chapter 14 · Communication and internet technologies, section 14.1 Protocols

Why protocols are essential, the layered protocol stack and the four TCP/IP layers with their functions, how a message passes down and up the stack; animations, labs and the real 9618 questions from 2022 to 2026.

This page in five sentences

A protocol is a set of agreed rules for communication between computers: it sets the format of the data, the order of messages and what to do when something goes wrong, so that devices from different makers can talk to each other. The TCP/IP protocol suite is built as a stack of four layers, Application, Transport, Internet and Link, and each layer has its own job and only deals with the layer directly above and below it. When a message is sent it passes down the stack on the sending host, with each layer adding information to a header, across the network, and up the stack on the receiving host, where each layer removes its header. The Application layer is where the user and their programs interact, and the Link layer is the one that actually sends the data over the physical connection. The next page covers the protocols that live in the Application layer.

1 · Why a protocol is essential

  • A protocol is a standard set of rules for communication: how data is formatted, addressed, sent, acknowledged and checked.
  • It lets devices from different manufacturers and platforms communicate, because they follow the same rules.
  • It makes communication independent of the software and hardware in use.
  • Without it, two devices using different rules could not communicate properly: the data would not be understood.

2 · The stack idea

A protocol suite can be viewed as a stack of layers. Splitting the job into layers means each layer can be designed, improved and replaced on its own.

  • Each layer has its own functionality.
  • A layer can only accept input from the next higher or the next lower layer: the adjacent layers. The interface between adjacent layers is the only interaction between layers.
  • The interactions are carried out by installed software.
  • User interaction takes place at the top (Application) layer. Direct access to the hardware takes place at the bottom (Link) layer.
  • Data is added to the header as packets and frames pass down through the layers, and removed as they pass up.

3 · The four layers of TCP/IP

LayerPurpose and functionExamples
Application (top)Provides services and an interface to the user: the programs that exchange data (web browser, email client, file transfer). Defines the protocols applications use to exchange dataHTTP(S), FTP, SMTP, POP3, IMAP, BitTorrent
TransportDelivery from the source host to the destination host (end to end). Breaks data into packets / segments, adds a sequence number to the header, controls the flow, detects errors and requests re-sending of lost packets, and reassembles at the destination. Uses a port numberTCP, UDP
InternetIdentifies the intended network and host. Adds a header with the source and destination IP addresses, forms datagrams, and routes each packet independently by the best routeIP
Link (bottom)Transports data within the local network segment, formats datagrams into frames, maps IP addresses to MAC (physical) addresses, ensures the correct network protocols are followed, and sends and receives frames over the physical medium. Prepares the next hopEthernet, Wi-Fi
Order to learnFrom the user down: Application, Transport, Internet, Link: "All Tests Include Logic". The Link layer is also called the Network Access or Data Link layer in some books; the exam uses Link.

4 · A message through the stack

  1. Application layer (sender): the user's program, such as a browser, creates the message using a protocol like HTTP.
  2. Transport layer: breaks the message into packets, numbers them and adds a header (sequence number, port).
  3. Internet layer: adds the source and destination IP addresses.
  4. Link layer: puts the packet in a frame with MAC addresses and sends it onto the network.
  5. Routers pass it on. At the receiver the frame goes up the stack: the Link layer receives it, the Internet layer checks the address, the Transport layer puts the packets in order and checks them, and the Application layer gives the message to the program.
# data gains a header at each layer on the way down (encapsulation)message  = "GET /index.html"                       # Application layer: HTTP requestsegment  = {"seq": 1, "port": 80, "data": message}   # Transport layer: sequence number, portpacket   = {"src": "192.168.1.5", "dst": "93.184.216.34", "data": segment}   # Internet layer: IP addressesframe    = {"mac_src": "AA:01", "mac_dst": "BB:02", "data": packet}          # Link layer: MAC addresses# the receiver removes the headers in the opposite order, Link first, Application last

5 · Common ways to lose marks

  • Putting the layers in the wrong order. The Application layer is the top, the Link layer the bottom.
  • Describing the layers by the function of a different layer: routing and IP addresses are the Internet layer; sequence numbers, error checking and re-sending are the Transport layer.
  • Saying a protocol is "a program". It is a set of rules.
  • Writing that layers talk to every other layer. Only adjacent layers interact.
  • Describing the layers' functions when the question says not to (for example "describe how the suite is applied when a message is sent"): describe the stack, the direction down then up, and the interface.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Loading a web page

Your browser (Application layer) asks for a page with HTTP. The Transport layer splits the reply into numbered packets, the Internet layer addresses each one, and the Link layer sends it over Wi-Fi to your router.

Exam use: each layer does its own job, and the message passes down then up the stack.

Devices from different makers

A phone, a laptop and a games console from different companies all browse the same website because they all follow the TCP/IP protocols.

Exam use: a protocol is a standard that makes communication independent of the hardware and software.

Upgrading Wi-Fi

Moving from Wi-Fi 5 to Wi-Fi 6 changes the Link layer. The web page, the browser and the IP addresses are unchanged, because the layers are separate.

Exam use: layers can be improved independently, and only adjacent layers interact.

A lost packet

If a packet in a video call is lost, the Transport layer notices that a sequence number is missing and asks for it to be sent again, without the video app having to do anything.

Exam use: the Transport layer handles sequencing, flow and error recovery.

Finding the way

A router reads the destination IP address, which was added by the Internet layer, to decide where to send each packet next.

Exam use: routing and IP addresses belong to the Internet layer.

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

State 2 marks State two reasons why a layered protocol stack is used rather than one large protocol.
ReminderThink about changing one part.

Each layer has its own function and can be designed, tested and improved on its own. A layer can be replaced (for example a new Link layer for Wi-Fi) without changing the other layers.

Describe 3 marks A browser requests a web page. Describe what the Transport layer does to the reply before it is sent.
ReminderPackets, numbers, the header.

It breaks the reply into packets (segments). It adds a header containing a sequence number (and port number) to each. It passes the packets to the Internet layer, and later checks they arrive complete and in order.

Identify 2 marks Name the layer that (a) adds the source and destination IP addresses; (b) formats the data into frames for the physical network.
ReminderInternet, then Link.

(a) Internet layer (b) Link layer

Explain 3 marks Explain what is meant by saying that a layer can only interact with the adjacent layers.
ReminderWhich layers can the Transport layer deal with?

A layer only takes input from the layer directly above it or directly below it. The Transport layer deals only with the Application and Internet layers. The interface between two adjacent layers is the only interaction between them.

Complete 3 marks Describe how a message travels through the TCP/IP stack from a sender to a receiver. Do not describe the individual functions of the layers.
ReminderDown, across, up.

The message is created at the Application layer and passes down through the layers to the Link layer, with data added to the header at each. The Link layer sends it over the network. At the receiver it passes up from the Link layer to the Application layer and the headers are removed.

Top tips

  • Learn the order. Application, Transport, Internet, Link: top to bottom.
  • Match the job to the layer. Sequence numbers, packets, re-sending: Transport. IP addresses, routing: Internet. Frames, MAC addresses, the cable or Wi-Fi: Link. User services: Application.
  • Say 'adjacent'. A layer interacts only with the layer above and the layer below.
  • Say 'down then up'. Sending goes top to bottom, receiving bottom to top.
  • Use the exam's wording for a protocol. A standard set of rules enabling communication between devices from different manufacturers.
  • Read what is excluded. If the question says not to describe the functions of the layers, describe how the stack is used instead.
