Why Protocols Are Essential

Coursebook: Chapter 14 · Communication and internet technologies, section 14.1 Protocols

What a protocol is, what it sets, and why devices from different manufacturers and platforms need a shared standard; animations, labs and the real 9618 questions from 2022 to 2025.

This page in five sentences

A protocol is a standard set of rules for communication between devices: it fixes the format of the data, how devices are addressed, the order of the messages and what to do when something goes wrong. Protocols are essential because they let devices from different manufacturers and platforms communicate, and they make communication independent of the hardware and software in use. If two devices followed different rules, the data would arrive but would not be understood. A protocol is a set of rules, not a program, although software is what carries the rules out. The next page shows how protocols are organised into a stack of layers.

1 · What a protocol is

  • A protocol is an agreed set of rules that two or more devices follow when they communicate.
  • It is a standard: published and shared, so anyone can build a device that follows it.
  • It is not a piece of hardware and not a single program. Software on each device implements the rules.

2 · What a protocol sets

3 · Why a protocol is essential

  1. It sets a standard for communication, so both ends know what to expect.
  2. It lets devices from different manufacturers and platforms communicate: a Windows laptop and an Android phone can use the same website.
  3. It makes communication independent of the hardware and software used.
  4. Without it, devices using different rules could not communicate: the receiver would not understand the data.
Exam wording"A protocol is a standard set of rules that allows communication between devices. It lets devices on different platforms or from different manufacturers communicate, because they follow the same rules."

5 · Common ways to lose marks

  • Writing that a protocol "makes data faster" or "makes it secure". It makes communication possible and consistent; some protocols add security, but that is not why protocols are essential.
  • Saying "so devices can communicate" and stopping. Add why: they follow the same standard rules, so different manufacturers and platforms can understand each other.
  • Calling a protocol a program or a piece of hardware. It is a set of rules.
  • Describing one named protocol when the question asks why protocols in general are needed.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

The airport

Pilots and air traffic controllers all over the world use English phrases from an agreed list. A pilot from one country and a controller from another understand each other because they follow the same rules, not because they share a native language.

Exam use: a protocol is a standard that lets people or devices from different backgrounds communicate.

USB-C chargers

A phone, tablet and laptop from different companies can use the same charger and cable because the connector shape, voltages and signalling follow one standard.

Exam use: devices from different manufacturers work together when they follow the same standard.

Any phone, any website

An iPhone, an Android phone and a games console all load the same web page. The website does not know or care which device it is talking to, because both ends follow the same protocols.

Exam use: communication is independent of the hardware and software in use.

Bluetooth headphones

Headphones from one company pair with a phone from another. If each maker invented a private way of pairing, you could only buy a matching set.

Exam use: without a shared protocol, devices from different makers could not communicate.

A letter with the wrong address layout

A letter with the postcode first and no street name may be rejected by sorting machines that expect the usual order. The letter exists but the machine cannot interpret it.

Exam use: data that does not follow the agreed format is not understood by the receiver.

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

State 2 marks State two things that a protocol sets for communication between two computers.
ReminderThink of the rules table: format, addressing, order, timing, errors.

Any two: The format of the data How devices are addressed The order of the messages The speed / timing of transmission How errors are detected and handled

Explain 3 marks A laptop from one manufacturer is connected to a printer from another. Explain why they can work together.
ReminderUse the word standard and say what it allows.

Both follow the same protocol / standard set of rules. So each device understands the data and commands that the other sends. The protocol makes communication independent of the manufacturer, hardware and software.

Describe 2 marks Describe what could happen if two devices used different protocols to communicate.
ReminderThink about what the receiver does with the data.

The data would not be understood / interpreted correctly by the receiving device. The devices would be unable to communicate (or the data would be lost or misread).

Explain 2 marks Ten manufacturers each make devices that must connect to all of the others. Explain why one shared protocol is better than each pair of makers agreeing its own rules.
ReminderCount the pairs: 10 × 9 ÷ 2.

Without a standard there would be 45 separate sets of rules; with one protocol each maker builds to a single standard. That is simpler, cheaper and means any new device works with all the others.

Top tips

  • Give two points. A standard set of rules, and what it allows (devices from different manufacturers or platforms can communicate).
  • Say 'standard'. It is the word the mark scheme looks for.
  • Say what happens without one. The devices would not be able to communicate because the data would not be understood.
  • Do not call it a program. A protocol is a set of rules. Software carries them out.
  • Do not say it makes things faster or secure. Those are not the reason protocols are essential.
