Logic Circuits

Drawing logic circuits from logic expressions and problem statements, and tracing signals through them.

The big idea

A logic circuit joins gates so one gate's output feeds the next. Draw it from the expression or statement, without simplifying, with inputs on the left and the output on the right.

10.2 Logic circuits

A logic circuit joins several gates so that the output of one gate becomes the input of another. A circuit has inputs (A, B, C: up to three), gates, wires and one output (X). Each circuit can be written as a logic expression, such as X = (A AND B) OR NOT C.

Drawing a circuit from a logic expression

  1. Find the operators. Every AND, OR, NOT, NAND, NOR or XOR is one gate. Each NOT is its own gate.
  2. Work from the brackets outward. Brackets are drawn first, and their results feed the gates outside.
  3. Draw the gates from left to right, inputs on the left and the output X on the right.
  4. Join each gate's output to the input of the next gate with a wire.

For X = (A AND B) OR NOT C: draw an AND gate for A and B; draw a NOT gate for C; feed both into an OR gate. That is three gates. Circuits are drawn exactly as the expression is written, without simplifying.

Drawing a circuit from a problem statement

First turn the words into an expression, then draw it. Look for these key phrases:

Words in the statementExpressionGate
"A and B", "both A and B"A AND BAND
"A or B", "either... or", "at least one"A OR BOR
"not A", "A is off"NOT ANOT
"not both A and B"NOT (A AND B)NAND
"neither A nor B"NOT (A OR B)NOR
"A or B but not both", "exactly one"A XOR BXOR

Example

"An alarm (X) sounds if the door sensor (A) is on and either the window sensor (B) or the motion sensor (C) is on."

Expression: X = A AND (B OR C). The OR is in brackets because the "either...or" is one part that is then ANDed with A.

Watch the bracketsA AND (B OR C) is not the same as (A AND B) OR C. The brackets decide which gate comes first, so the circuit and the truth table are different.

Drawing a circuit from a truth table

For a truth table, write the expression first: for each row where the output is 1, AND together the inputs (using NOT for an input that is 0), then OR the rows together. Then draw it as above. This is explained fully in 10.3.

Tracing a circuit

To find the output for given inputs, follow the signals left to right and work out the output of each gate in turn, writing the value on each wire.

ReminderOR with an AND inside.
L = A OR (B AND C) An AND gate with inputs B and C An OR gate with inputs A and the AND output The output labelled L

Q6 State 2 marks The inputs for X = (A AND B) OR NOT C are A = 1, B = 0, C = 1. State the output.
ReminderWork out each gate.
A AND B = 0 and NOT C = 0 0 OR 0: X = 0
Common mistakeReading NOT C as C.
Q7 Explain 2 marks Explain why X = A AND (B OR C) and X = (A AND B) OR C are different circuits.
ReminderBrackets change the order.
The brackets change which gate is evaluated first (which inputs each gate combines). For example with A = 0, B = 1 and C = 1 the first gives 0 and the second gives 1.
Common mistakeSaying they are "the same because they use the same letters".

Top tips

  • Every operator is one gate, including each NOT.
  • Brackets first. Draw bracketed gates first, then feed them into the next gate.
  • Inputs on the left, output on the right, and label every input and the output.
  • Do not simplify. Draw the circuit for the statement exactly as written.
  • Key words: and = AND, or/either = OR, not = NOT, neither...nor = NOR, not both = NAND, but not both = XOR.
