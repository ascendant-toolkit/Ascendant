Data types, identifiers and identifier tables, operators, built-in functions, evaluating expressions and spotting errors, with animations, labs and the real Paper 2 questions from 2021 to 2026.

This page in five sentences

A program stores data in variables and constants, each with an identifier (a meaningful name) and a data type: INTEGER, REAL, CHAR, STRING, BOOLEAN or DATE. An identifier table lists each identifier with its type, purpose and an example value. Operators (arithmetic, comparison, logical, string &) and built-in functions (LENGTH, LEFT, RIGHT, MID, INT, NUM_TO_STR, STR_TO_NUM, IS_NUM, MONTH ...) are used to build expressions, and each operator and function needs operands of the right type. Evaluating an expression means working out its value step by step, in the correct order. Many exam marks come from either evaluating an expression or spotting the type error in one.

1 · Data types

TypeStoresExample
INTEGERA whole number29, -4

STRINGZero or more characters (double quotes)"Wong", "18/04/2021"
BOOLEANTRUE or FALSETRUE
DATEA date19/02/1983

The data type is decided by how the value is used, not how it looks: a phone number or a date written in quotes is a STRING, and an exam question such as "number of items" is an INTEGER. A value that can have only two states (a flag, whether a customer is new) is BOOLEAN.

2 · Identifiers, variables and constants

  • Choose a meaningful name (MemberName, NumItems, NewCustomer, Deposit) and declare it with its type: DECLARE Points : INTEGER.
  • A variable can change while the program runs; a constant is set once (CONSTANT VATRate ← 0.2) and makes the program easier to read and to change.
  • An identifier table gives the name, data type, a description of its purpose and often an example value. Other things it may include: the number of elements of an array or the length of a string, the value of a constant, and the scope (local or global).
  • Assignment: Total ← 0. A value must match the variable's type.

3 · Operators

GroupOperatorsResult type
Arithmetic+ - * / ^ DIV MODnumber (/ gives REAL)
Comparison= <> < > <= >=BOOLEAN
LogicalAND OR NOTBOOLEAN (operands must be BOOLEAN)
String join&STRING (operands must be strings or chars)
  • DIV is integer division: 17 DIV 5 = 3. MOD is the remainder: 17 MOD 5 = 2. / gives a real: 17 / 5 = 3.4.
  • Order: brackets, then ^, then * / DIV MOD, then + −, then comparisons, then NOT, AND, OR. Use brackets to be sure.
  • Common errors: & on numbers, + on a string and a number, x = 3 OR 4 (each side of OR must be a complete comparison: x = 3 OR x = 4), and AND with a value that is not BOOLEAN.

Each function wants a particular type: IS_NUM needs a string (not a number), LCASE works on a character (or string), INT needs a number, and NUM_TO_STR needs a number, so NUM_TO_STR(Index + "33") is an error (a number plus a string).

5 · Evaluating an expression

Work out the innermost brackets or functions first, write each intermediate value, and give a final answer of the right type: strings in quotes, REAL results with their decimals (249.50), BOOLEAN as TRUE or FALSE. If a part is invalid, the answer is ERROR.

// Total = 124.00, DepRate = 2.00, Description = "AB12345:Cleaning Brush (small)"(Total * DepRate) + 1.5                    // 249.50RIGHT(Description, 7)                      // "(small)"(LENGTH(Description) - 8) > 16             // 30 - 8 = 22 > 16, TRUENUM_TO_STR(INT(DepRate * 10)) & '%'        // INT(20.0) = 20, so "20%"

Common ways to lose marks

  • Variable names such as X or Data1, or a type that does not match the example value.
  • Quoting a number, or dropping the quotes from a string or character answer.
  • Writing "error" for a statement that is valid, or the other way round: read each operator and each function's parameter type.
  • Starting MID at position 0 (the first character is position 1).

Top tips

  • Type from the value. Quoted means STRING. A decimal means REAL.
  • Meaningful names. MemberName, not X.
  • Inside out. Evaluate the innermost function first and write down each step.
  • Check the operand types. & strings only; AND/OR BOOLEAN only.
  • Format the answer. Strings in quotes, 249.50 with its decimals, TRUE not true.
  • Position 1. MID and LEFT start counting at 1.
