Programming Concepts

Variables, constants and data types, input and output, selection and iteration, string handling, operators, nested statements, procedures and functions, local and global variables, library routines and maintainable programs.

The big idea

Every program is built from the same pieces: variables and data types, selection and iteration, and procedures and functions. Written clearly in pseudocode, they make a program that works and that others can maintain.

8.1 Programming concepts

In the exam, solutions are written in pseudocode (Python is shown here as well so you can run the ideas). Use the Cambridge style: upper-case keywords, ← for assignment, four-space indentation.

Variables and constants

A variable is a named store whose value can change while the program runs. A constant is a named value that does not change. Both are declared, and named with meaningful identifiers (Pascal case, such as TotalToPay).

Input and output

INPUT reads a value from the user into a variable. OUTPUT displays one or more values, separated by commas. A prompt is usually output first.

Sequence, selection and iteration

Sequence means the statements run one after another, in order. Selection chooses which statements run. Iteration repeats statements.

Selection: IF and CASE

Use an IF statement for a condition (with or without ELSE). Use a CASE statement to choose between several values of one variable. Cases are tested in order, and OTHERWISE (last) covers everything else.

Iteration: three kinds of loop

LoopWhen to use itCondition testedRuns at least once?
FOR ... NEXT (count-controlled)You know how many times to repeatCounts from a start to an end valueOnly if start ≤ end
WHILE ... ENDWHILE (pre-condition)Repeat while a condition is true, number of times unknownBefore each passNo, if the condition is false at the start
REPEAT ... UNTIL (post-condition)Repeat until a condition becomes trueAfter each passYes

A FOR loop can have a STEP, which can be negative: FOR Count ← 10 TO 1 STEP -1. WHILE repeats while the condition is TRUE; REPEAT stops when its condition is TRUE.

Totalling and counting

Totalling keeps a running total (Total ← Total + Value, starting at 0). Counting adds 1 each time something happens (Count ← Count + 1, starting at 0). See 7.3 for worked examples.

String handling

Strings can be examined and changed with library routines. The first character of a string can be at position zero or one (the exam tells you, and pseudocode generally uses 1).

Nested statements

A statement can contain another: an IF inside a FOR, a loop inside a loop. You will not need more than three levels. Indent each level.

Procedures and functions

A procedure is a named block of code that does a task. A function is the same, but it also returns one value. Both can have up to three parameters: values passed in when they are called. They are defined at the start of the program.

ProcedureFunction
Returns a value?NoYes (RETURN, with RETURNS type)

Local and global variables

A global variable can be used anywhere in the program. A local variable is declared inside a procedure or function and can only be used there; it exists only while that routine runs. Local variables stop routines interfering with each other.

Library routines

A library routine is a ready-made routine, such as MOD, DIV, ROUND(value, places) (rounds to a number of decimal places) and RANDOM() (a random number from 0 to 1). Using them saves time and avoids errors.

Writing maintainable programs

  • Use meaningful identifiers for variables, constants, arrays, procedures and functions (TotalPrice, not x).
  • Add comments (// in pseudocode, # in Python) to explain what the code does and why.
  • Split the program into procedures and functions, so each part is easy to understand, test and reuse.
  • Indent the code to show its structure.

A shopping basket

A variable holds the running total. A constant holds the delivery charge. A loop adds up each item, and a function calculates the discount.

Exam use: variables, constants, iteration, and a function with a returned value.

An ATM PIN check

The machine repeats the question until the PIN is right (or three attempts are used). The check happens at least once.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 3 marks Give the most suitable data type for (a) the number of students in a class, (b) a person's height in metres, (c) whether a door is open.
ReminderINTEGER, REAL, BOOLEAN.
(a) INTEGER (b) REAL (c) BOOLEAN
Common mistakeUsing STRING for numbers. Numbers you calculate with are INTEGER or REAL.
Q2 Explain 2 marks Explain the difference between a variable and a constant.
ReminderCan it change?
A variable can change its value while the program runs. A constant keeps the same value throughout the program (it cannot be changed).
Common mistakeGiving only examples.
Q3 Explain 3 marks Explain the difference between a WHILE loop and a REPEAT loop.
ReminderWhere the condition is tested.
A WHILE loop tests its condition before the statements are run. A REPEAT loop tests its condition after the statements, so it always runs at least once. A WHILE loop may never run (if the condition is false at the start).
Common mistakeSaying "WHILE is for numbers".
Q4 Write 4 marks Write pseudocode to ask the user to enter a password and repeat until "Secret" is entered.
ReminderREPEAT with INPUT and UNTIL.
REPEAT OUTPUT a prompt and INPUT Password inside the loop UNTIL Password = "Secret" (Alternative: a correct WHILE loop with the input repeated inside)
Common mistakeUsing UNTIL Password <> "Secret" (the wrong way round).
Q5 Describe 3 marks Describe the differences between a procedure and a function.
ReminderReturn, call, parameters.
A function returns a value; a procedure does not. A function is called as part of an expression (the returned value is used). A procedure is called with CALL (both can use parameters).
Common mistakeSaying a function "does more".
Q6 Explain 3 marks Explain the difference between local and global variables, and why local variables are useful.
ReminderScope.
A global variable can be used anywhere in the program. A local variable can only be used within the procedure or function where it is declared. Local variables stop different parts of the program changing each other's data by accident (and free memory when the routine ends).
Common mistakeNot saying where each can be used.
Q7 Write 3 marks Write pseudocode for a function Cube that returns the cube (the number multiplied by itself twice) of an integer.
ReminderFUNCTION ... RETURNS ... RETURN ... ENDFUNCTION.
FUNCTION Cube(Number : INTEGER) RETURNS INTEGER RETURN Number * Number * Number ENDFUNCTION
Common mistakeForgetting RETURNS INTEGER or ENDFUNCTION.
Q8 State 4 marks State the result of (a) DIV(17, 5), (b) MOD(17, 5), (c) LENGTH("Computer"), (d) SUBSTRING("Computer", 1, 3).
ReminderWork each out.
(a) 3 (b) 2 (c) 8 (d) "Com"
Common mistakeMixing up DIV and MOD.
Q9 Describe 3 marks Describe three ways to make a program easier to maintain.
ReminderIdentifiers, comments, procedures.
Use meaningful identifiers for variables, constants, arrays and routines. Add comments to explain the code. Use procedures and functions to split the program into parts (and indent the code).
Common mistake"Write it neatly" without saying how.
Q10 Write 5 marks Write pseudocode that inputs 10 numbers and outputs how many of them are greater than 100.
ReminderCount starts at 0, FOR loop, IF.
Count ← 0 FOR Index ← 1 TO 10 INPUT Number IF Number > 100 THEN Count ← Count + 1 ENDIF OUTPUT Count after the loop
Common mistakeOUTPUT inside the loop.

Top tips

  • Data types: INTEGER (whole), REAL (decimal), CHAR (single quotes), STRING (double quotes), BOOLEAN.
  • WHILE tests first; REPEAT tests last and always runs once. REPEAT ends when the condition is TRUE.
  • Know DIV and MOD: DIV = quotient, MOD = remainder.
  • A function RETURNS a value; a procedure does not. Call a function inside an expression.
  • Local variables only exist inside their routine; global ones can be used anywhere.
  • Maintainable code: meaningful names, comments, procedures and functions, indentation.
  • Write answers in pseudocode in the exam, with precise keywords.
