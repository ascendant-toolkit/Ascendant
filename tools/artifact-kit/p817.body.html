Library Routines

MOD, DIV, ROUND and RANDOM: ready-made tools you can call in any program.

The big idea

A library routine is code somebody else has already written and tested. You just call it. DIV and MOD split numbers, ROUND tidies decimals and RANDOM makes results unpredictable.

8.1.7 Library routines

A library routine is a ready-written, tested procedure or function that comes with the programming language. You call it by name and give it the values it needs. You need to know four: MOD, DIV, ROUND and RANDOM.

Why use them?They save time, they have already been tested (so fewer errors), programmers do not need to know how they work inside, and they make code shorter and easier to read.

DIV and MOD

17 ÷ 5 is 3 remainder 2: DIV gives the 3 and MOD gives the 2. You met these as operators in 8.1.4, where they are written 17 DIV 5 and 17 MOD 5. Both ways of writing them mean the same thing.

JobCode
Is N even?MOD(N, 2) = 0
Is N a multiple of 5?MOD(N, 5) = 0
Last digit of NMOD(N, 10)
Remove the last digitDIV(N, 10)
Full boxes of 12, and items leftDIV(N, 12) and MOD(N, 12)

ROUND

The second value is the number of decimal places. Look at the next digit: 5 or more rounds up, 4 or less rounds down. ROUND(X, 0) gives a whole number.

Python differencePython's round() sends an exact half to the nearest even number, so round(2.5) is 2. In the exam, round halves up.

RANDOM

RANDOM() gives a decimal between 0 and 1. To get a whole number in a range, multiply to stretch it, ROUND to make it whole, then add to move the start.

WantedExpression
0 to 10ROUND(RANDOM() * 10, 0)
1 to 6ROUND(RANDOM() * 5, 0) + 1
50 to 100ROUND(RANDOM() * 50, 0) + 50
Low to HighROUND(RANDOM() * (High − Low), 0) + Low

With this method the two end values come up about half as often as the others. That is fine for the exam. In Python, random.randint(1, 6) gives each whole number from 1 to 6 equally, and needs import random.

Top tips

  • DIV = how many whole times. MOD = what is left.
  • MOD(N, X) = 0 means N divides exactly by X.
  • ROUND needs two values: what to round, and how many decimal places.
  • RANDOM range: ROUND(RANDOM() * (High − Low), 0) + Low. Check both ends.
  • A library routine returns a value, so store it, output it or use it in a condition.
  • In Python, import random first.
