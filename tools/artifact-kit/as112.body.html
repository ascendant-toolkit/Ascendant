Selection with IF and CASE, count-controlled and condition-controlled loops, counting and totalling and run-time errors, with animations, labs and the real Paper 2 questions from 2021 to 2026.

This page in five sentences

Every program is built from three constructs: sequence (statements in order), selection (choosing: IF or CASE) and iteration (repeating: FOR, WHILE or REPEAT). Assignment (←) stores a value, and a subroutine call is a construct too. A count-controlled loop (FOR) repeats a set number of times, a pre-condition loop (WHILE) tests first and may never run, and a post-condition loop (REPEAT ... UNTIL) tests last and always runs at least once. Choose the loop that fits what you know: a known count, or a condition that ends it. A loop whose end condition can never become true runs for ever and the program stops responding.

1 · Selection

IF Mark > 74 THEN   Grade ← 'A'ELSE   IF Mark > 59 THEN      Grade ← 'B'   ELSE      Grade ← 'C'   ENDIFENDIF CASE OF MySwitch   1 : ThisChar ← 'a'   2 : ThisChar ← 'y'   3 : ThisChar ← '7'   OTHERWISE : ThisChar ← '*'ENDCASE
  • Use IF for one or two conditions or ranges of values; use CASE to choose between several exact values of one variable. A CASE clause can also be a range (1 TO 5 : ...), and OTHERWISE covers everything else.
  • A CASE can always be rewritten as nested IF ... ELSE ... ENDIF, and an IF on one variable with two outcomes needs a single IF ... THEN ... ELSE ... ENDIF.
  • Two clauses that differ only by a number can be merged: 1 TO 2 : Index ← Index + CaseVar.

2 · Iteration

  • The loop to use when the number of iterations is not known is a conditional (pre- or post-condition) loop; the exam answer "the number of iterations is not known, or the loop ends after a particular input" is a standard justification.
  • A count starts at 0 and adds 1; a total starts at 0 and adds a value. Always initialise before the loop.
  • A conditional loop that never ends is a run-time error (the program freezes): the terminating condition is never satisfied.

Common ways to lose marks

  • Ticking only one construct in a row where a statement does more than one job (an IF containing a FOR is both selection and iteration; a call inside a loop is iteration and subroutine).
  • Not initialising a count or total before the loop.
  • Using WHILE when the loop must run once, or REPEAT when it might not.
  • Testing the wrong bound: FOR ThisInt ← 100 TO 200 includes both 100 and 200.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A login screen

It repeats the password prompt until it is right or the attempts run out: a loop that must run at least once.

Exam use: REPEAT ... UNTIL.

A cash machine menu

A menu item is chosen with a CASE: balance, withdraw, deposit or quit, and an invalid key falls through to OTHERWISE.

Exam use: CASE.

A grade calculator

A mark above a boundary gives a grade: nested IF statements test the boundaries in order.

Exam use: IF.

A stopwatch

A loop adds one every tenth of a second, repeating until the stop button is pressed.

Exam use: conditional loop.

A game that freezes

A bug in the loop's end condition means it never finishes and the game stops responding.

Exam use: infinite loop.

Top tips

  • Match the loop to the question. Known count: FOR. Might be zero: WHILE. At least once: REPEAT.
  • Initialise first. Set count and total to 0 before the loop.
  • Tick every construct. Read the whole row; an IF inside a FOR is both.
  • Calls are subroutines. A function used in a condition counts.
  • CASE needs OTHERWISE. Or the equivalent final ELSE.
  • Check both ends. 100 TO 200 includes 100 and 200.
