The Four Layers in the Real World

Coursebook: Chapter 14 · Communication and internet technologies, section 14.1 Protocols

Follow a web page, an email, a video call, an FTP upload, a film and a BitTorrent download through Application, Transport, Internet and Link, with a postal analogy, a fault finder and practice.

This page in five sentences

Every time you load a page, send a message or join a call, the data goes down the four TCP/IP layers on your device, across the network and up the same four layers on the other device. The Application layer is the program you use and the protocol it speaks, the Transport layer cuts the data into numbered packets and makes sure they all arrive, the Internet layer puts the IP addresses on and routes each packet, and the Link layer sends the frames over Wi-Fi, a cable or mobile data to the next device. The layers are not separate machines: they are separate jobs, done by software on your device, by routers on the way, and by the network hardware. This page follows real situations through the layers so you can see each job happen. The exam questions are covered in 14.1.2 and 14.1.3.

1 · The postal system as a four-layer stack

LayerIn the postOn the network
ApplicationYou write a letter in a language the reader understands and decide what to sayA browser or email client creates a message in a protocol such as HTTP or SMTP
TransportThe letter is too big for one envelope, so it is split into numbered parcels so the reader can put them back in order and spot a missing oneThe message is split into packets with sequence numbers; lost ones are sent again
InternetEach parcel is labelled with the full postal address of the sender and the receiver, and sorting offices decide the routeSource and destination IP addresses are added; routers choose the route
LinkA van carries the parcel to the next depot, then another van to the next; each van knows only its own stretch of roadFrames carry the packet across one network segment at a time, using MAC addresses for the next hop

2 · Who does each job

LayerWhere you will find it
ApplicationThe program: Chrome, Outlook, a video call app, an FTP client
TransportThe network software in the operating system of the two end devices (the source host and the destination host)
InternetThe operating system on the two end devices, and every router on the way
LinkThe network card or Wi-Fi chip and its driver, the cable or radio link, and each device that passes frames on, such as a switch or a router

Beyond the syllabusTransport protocols include TCP, which re-sends lost packets, and UDP, which does not and is faster. Video calls and games often use UDP because an old frame is no use by the time it is re-sent. The exam asks only about the functions of the layer, not TCP against UDP.

4 · What to take from the examples

  • The layers do the same four jobs in every situation. Only the Application protocol and the Link technology change.
  • The IP addresses stay the same from your device to the server; the MAC addresses change at every hop.
  • When something goes wrong, the symptom usually points to one layer, which is why layering makes faults easier to find.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Your home router

It receives a Wi-Fi frame from your laptop, takes the packet out, reads the destination IP address and sends it on to your internet provider in a new frame. Each router on the route does the same.

Exam use: routers work at the Internet layer, and the Link layer builds a new frame for every hop.

A smart doorbell

The doorbell's video goes to a company's server. Its program is the Application layer, its Wi-Fi chip does the Link layer, and the packets use IP addresses like any other traffic. A small gadget needs all four layers too.

Exam use: every networked device implements the same stack, however simple it is.

Online banking

The bank's website uses HTTPS. The Application layer is where the secure web protocol lives; the layers below carry the encrypted data without needing to read it.

Exam use: the Application layer defines the protocol and can secure the communication, and the layers below do not change.

School Wi-Fi

Hundreds of students share one wireless network. The Link layer decides who sends when and addresses each frame to a device. The same packets then continue across the school's wired network to the internet.

Exam use: the Link layer moves frames within the local network segment.

A slow download

If packets are lost, the Transport layer asks for them again, which makes the download take longer even though the browser and the website are working perfectly.

Exam use: re-sending of lost packets is a Transport layer job.

Explain 4 marks Maya opens a school website on her laptop. Explain what the Transport layer and the Internet layer each do to the data that her browser sends.
ReminderTwo points for each layer.

Transport (max 2): It breaks the data into packets. It adds a sequence number to the header of each packet so that they can be put back in order (and lost packets re-sent). Internet (max 2): It adds a header with the source (her laptop) and destination (the web server) IP addresses. It routes the packets by the best route.

Explain 2 marks A home router receives a frame over Wi-Fi and sends the packet to the internet provider. Explain why the router builds a new frame.
ReminderThink about MAC addresses.

The Link layer frame only carries the packet across one local network segment, from one device to the next. The MAC addresses are for the next hop, so a new frame with new MAC addresses is needed at each hop; the IP addresses stay the same.

Describe 3 marks A video starts to freeze while streaming because packets are being lost. Describe what the Transport layer could do about it.
ReminderSequence numbers show what is missing.

It notices from the sequence numbers that a packet is missing. It asks for that packet to be sent again. It puts the packets in order before passing the data up to the Application layer.

Identify 2 marks A user's laptop shows that it is not connected to any Wi-Fi network. Name the layer most likely to be involved and give a reason.
ReminderNo connection means no physical medium.

The Link layer. It is the layer that gives access to the physical medium and sends and receives the frames.

Describe 3 marks Describe how the TCP/IP layers are used when an email is sent from one person to another. Do not describe the functions of the individual layers.
ReminderDirection of travel, interfaces and headers, not the jobs.

The message is created at the top (Application) layer of the sender and passes down through the layers. Each layer only passes data to the adjacent layer, adding data to the header on the way down. It is sent over the network and passes up the layers on the receiving device, with headers removed, until the email program receives it.

Top tips

  • Use the situation. In a scenario question, name the layer and say what it does for that situation, for example 'the Transport layer numbers the packets of the web page'.
  • One symptom, one layer. Not connected: Link. Wrong or clashing address, no route: Internet. Missing or out-of-order packets: Transport. Error from the website or mail server: Application.
  • IP stays, MAC changes. A very common mix-up in 'describe a journey' answers.
  • Routers are Internet layer devices. They also use the Link layer on each side to receive and send frames.
  • Same stack everywhere. Phones, doorbells, servers and routers all follow the same four layers.
