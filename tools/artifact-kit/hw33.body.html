3.3 Data Storage

Primary and secondary storage, RAM and ROM, magnetic, optical and solid-state storage, virtual memory and cloud storage.

The big idea

Primary storage (RAM and ROM) is the memory the CPU uses directly. Secondary storage keeps data permanently. Virtual memory stretches RAM onto the drive, and cloud storage moves storage to remote servers.

3.3 Data storage

Primary storage

Primary storage is directly accessed by the CPU. It is RAM and ROM.

RAM (random access memory)ROM (read only memory)
ContentsPrograms, data and parts of the operating system currently in useStart-up instructions (the bootstrap) and other fixed firmware
Read and writeCan be read and writtenRead only
Volatile?Volatile: contents are lost when power is offNon-volatile: contents stay without power

A computer needs both: ROM holds the instructions that start the computer when RAM is empty, and RAM gives fast, changeable space for the programs and data in use.

Secondary storage

Secondary storage is not directly accessed by the CPU. It is non-volatile and used for the permanent storage of programs and files. Its capacity is much larger than RAM and it is slower.

Virtual memory

When RAM is full, the operating system uses part of secondary storage as virtual memory, an extension of RAM. Data is split into pages. Pages that are not needed right now are moved from RAM to virtual memory, and moved back when they are needed. It is necessary so that more programs can run than fit in RAM, but it is slower than RAM, so too much swapping makes a computer sluggish.

Cloud storage

Cloud storage keeps data on remote physical servers run by a provider, accessed over the internet, instead of on your own device.

Advantages of cloud

  • Access from anywhere, on any device
  • No need to buy or maintain your own hardware; capacity can grow as needed
  • Provider usually keeps backups of the data
  • Easy to share files

Disadvantages of cloud

  • Needs an internet connection
  • Ongoing subscription cost for larger amounts
  • You rely on the provider's security; data could be hacked
  • Large files are slower to open than local files

Local storage has the opposite profile: it works offline, you control it, and it is quicker, but capacity is limited, you must make your own backups, and it can be lost, stolen or damaged.

5 · Multiple choice

Descriptions are kept general. Check current details before quoting specifics.

Photos in the cloud

A phone can upload photos to a provider's data centres. You can view them from any device, and you still have them if the phone is lost, but you need an internet connection and you trust the provider with your data.

Exam use: a ready example for advantages and disadvantages of cloud against local storage.

A laptop slowing down

When too many programs are open on a computer with little RAM, it starts moving pages to virtual memory on the drive, and everything slows down. Closing programs or adding RAM fixes it.

Exam use: a clear reason why virtual memory is needed and why it is slower than RAM.

SSD against HDD

Replacing a laptop's hard disk with an SSD often makes it start and open files much faster, uses less power and survives knocks, because there are no spinning platters. The cost per GB is higher.

Exam use: compare magnetic and solid-state storage: moving parts, speed, durability, cost.

Films on Blu-ray

A Blu-ray disc holds far more than a DVD because its laser has a shorter wavelength, so the pits can be smaller and closer together.

Exam use: optical storage uses a laser and pits and lands; different discs have different capacities.

USB drive for homework

A flash drive is small, needs no power cable and has no moving parts, so it can be carried in a bag and used on a school computer.

Exam use: an example of solid-state storage that is portable.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 Explain 4 marks Explain why a computer needs both RAM and ROM.
ReminderROM: start-up and non-volatile. RAM: working space and changeable.
ROM is non-volatile, so its contents are kept when the power is off. It holds the start-up (bootstrap) instructions, needed because RAM is empty when the computer is switched on. RAM can be read and written, so it holds the programs and data currently in use. RAM is volatile, so it loses its contents when the power is off.
Common mistakeSwapping them over. RAM is the one that loses data when the power is off.
Q2 Describe 4 marks Describe how data is stored on and read from an optical disc, and how a solid-state drive stores data.
ReminderOptical: laser, pits and lands. Solid-state: transistors, floating gate.
A laser burns pits (and lands) into a spiral track on the disc. To read, a laser is shone on the disc; light reflects differently from a pit and a land, which gives 0s and 1s. A solid-state drive uses flash memory (NAND or NOR) made of transistors. Control gates and floating gates trap electrical charge to represent a 0 or 1; there are no moving parts.
Common mistakeUsing "magnets" for optical or solid-state. Electromagnets are magnetic (HDD) storage.
Q3 Explain 3 marks Explain what virtual memory is and why it is needed.
ReminderWhere it is, how it works, why.
Virtual memory is part of secondary storage used as an extension of RAM. When RAM is full, pages of data that are not currently needed are moved from RAM to virtual memory (and moved back when needed). It is needed so that more programs can run (or larger programs) than would fit in RAM alone.
Common mistakeSaying virtual memory is "extra RAM chips". It is space on the drive, which is slower than RAM.
Q4 Discuss 4 marks A photographer is deciding between storing photos on the cloud or on a local external drive. Give two advantages and two disadvantages of using the cloud.
ReminderTwo of each. Compare with local, and link to photos if you can.
Advantage: photos can be accessed from anywhere on any device with internet. Advantage: no need to buy or maintain hardware; the provider keeps backups; capacity can grow. Disadvantage: needs an internet connection (and large photo files can be slow to upload or open). Disadvantage: ongoing subscription cost, and the data could be hacked or lost if the provider is attacked or fails.
Common mistakeListing "it is safer" or "it is cheaper" without saying why, or listing the same point twice in different words.

Top tips

  • RAM is volatile, ROM is not. Use both words and give each one's job.
  • Primary is accessed directly by the CPU; secondary is not.
  • Describe the method: HDD = platters, tracks, sectors and electromagnets. Optical = laser, pits and lands. Flash = transistors with floating gates.
  • Virtual memory is on the drive, it is used when RAM is full, and it is slower.
  • Cloud: give two advantages and two disadvantages and link to the scenario.
