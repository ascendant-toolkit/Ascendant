The Protocol Stack

Coursebook: Chapter 14 · Communication and internet technologies, section 14.1 Protocols

How protocol implementation is viewed as a stack of layers: own functionality, adjacent layers, interfaces, headers, and the path down and up the stack; animations, labs and the real 9618 questions from 2023 to 2026.

This page in five sentences

A protocol suite is built as a stack of layers, and each layer has its own functionality. A layer can only accept input from the next higher or the next lower layer, and the interface between adjacent layers is the only interaction between layers. User interaction happens at the top of the stack and direct access to the hardware happens at the bottom. When a message is sent it passes down the stack on the sender, with each layer adding data to the header, and up the stack on the receiver, where each layer removes its header. Layering makes the system easier to build, test and improve, because one layer can change without the others having to change.

1 · The stack idea

  • Protocol implementation can be viewed as a stack: layers one on top of another.
  • Each layer has its own job. The whole job of communicating is divided into smaller jobs.
  • The layers are put in order. The layer at the top is nearest the user, the layer at the bottom is nearest the hardware.

2 · The rules of the stack

RuleWhat it means
Own functionalityEach layer does one specific job and no other
Adjacent layers onlyA layer accepts input only from the layer above or the layer below. It never skips a layer
InterfaceThe point where two adjacent layers meet. It is the only interaction between those layers
Installed softwareThe interactions between layers are carried out by software installed on the device
Top and bottomUser interaction takes place at the top. Direct access to the hardware takes place at the bottom
HeadersData is added to the header as packets and frames pass down the layers, and removed as they pass up

3 · Down the stack, across, up the stack

  1. The message starts in a program at the top layer of the sending device.
  2. It passes down, one layer at a time. Each layer treats what it receives as its data and adds its own header in front.
  3. At the bottom the data is sent over the physical medium, through any routers, to the receiving device.
  4. On the receiving device it passes up, one layer at a time. Each layer reads and removes its own header, then hands the rest to the layer above.
  5. The program at the top receives the original message.

4 · Why use layers

  • Each layer can be designed, tested and improved on its own.
  • A layer can be replaced (a new Wi-Fi standard, say) without changing the other layers.
  • Different teams or manufacturers can work on different layers, as long as the interfaces stay the same.
  • It is easier to find faults: you can tell which layer is not doing its job.
Which stack?The TCP/IP suite is the stack the exam uses. It has four layers: Application, Transport, Internet and Link. This page is about how any stack works; the next page covers what each of those four layers does.

5 · Common ways to lose marks

  • Writing that a layer talks to every other layer. Only adjacent layers interact.
  • Describing what each layer does when the question says not to (for example "describe how the suite is applied when a message is sent"). Describe the stack, the direction down then up, and the interface.
  • Getting the top and bottom the wrong way round. The user is at the top; the hardware is at the bottom.
  • Forgetting the header. Say that data is added to the header on the way down and removed on the way up.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Upgrading Wi-Fi

Moving from Wi-Fi 5 to Wi-Fi 6 changes the bottom layer only. The browser, the web page and the IP addresses are unchanged, because the layers are separate.

Exam use: layers can be improved independently, and only adjacent layers interact.

Changing from Wi-Fi to mobile data

A phone moves out of Wi-Fi range and switches to mobile data. Apps keep working, because only the bottom layer has changed; the layers above are the same.

Exam use: a layer can be replaced without changing the others.

The post office

You write a letter (top). The post office puts it in a bag with a sorting code (middle). A van takes the bag to the next depot (bottom). The writer never drives the van, and the driver never reads the letter: each does their own job at their own level.

Exam use: each layer has its own functionality and talks only to its neighbours.

An operating system

The network part of Windows, macOS, Android and Linux is installed software that implements the stack. Programs call it, and it calls the network card's driver.

Exam use: the interactions between layers are carried out by installed software.

Finding a fault

If a web page will not load but other devices on the same Wi-Fi work, an engineer can check the layers in turn: is the Wi-Fi connected, does the device have an IP address, does the browser's request get a reply?

Exam use: layering makes faults easier to isolate.

ReminderInternet, then Link.

Explain 3 marks Explain what is meant by saying that a layer can only interact with the adjacent layers.
ReminderWhich layers can the Transport layer deal with?

A layer only takes input from the layer directly above it or directly below it. The Transport layer deals only with the Application and Internet layers. The interface between two adjacent layers is the only interaction between them.

Describe 4 marks Describe what happens to a message as it passes up the protocol stack on the receiving device.
ReminderWhich direction, what each layer removes, who gets the message.

The message enters at the bottom layer from the physical medium. Each layer reads its own header and removes it. The remaining data is passed to the next higher (adjacent) layer. At the top layer the original message is passed to the program / user.

Top tips

  • Say 'adjacent'. A layer interacts only with the layer above and the layer below, through the interface between them.
  • Say 'down then up'. Sending goes top to bottom, receiving bottom to top.
  • Headers. Data is added to the header on the way down and removed on the way up.
  • Top and bottom. User interaction at the top, direct access to the hardware at the bottom.
  • Read what is excluded. If the question says not to describe the functions of the layers, describe how the stack is used instead.
