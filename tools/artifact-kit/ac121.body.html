Graphics: Bitmap Images and Vector Graphics

Coursebook: Chapter 1 · Information representation, section 1.2 Multimedia (graphics)

How a bitmap is encoded, resolution and colour depth, estimating file sizes, how changes affect quality and size, vector drawing lists, choosing between bitmap and vector, and thirteen questions from the 2021 to 2026 papers.

This page in five sentences

A bitmap image is a grid of pixels, each with one colour stored as a binary code, and the codes are stored in sequence along with a file header that says how to read them. The image resolution (pixels wide × pixels high) and the colour depth (bits per pixel) decide both the quality and the file size, which you estimate as width × height × bit depth. A vector graphic stores a drawing list of drawing objects, each with properties such as fill colour and line weight, so it can be enlarged without pixelation and often has a small file. Bitmaps suit photographs and fine detail, vectors suit logos, diagrams and anything that must be resized. Marks in this topic come from the terms, from file size calculations with the working shown, and from a justified choice between bitmap and vector.

1 · How a bitmap image is encoded

  1. The image is divided into a grid of pixels, the smallest element of an image that can be one colour.
  2. Each pixel has one colour.
  3. Each colour has a unique binary code. The number of bits for each code is the colour depth.
  4. The code for each pixel is stored in sequence, usually row by row from the top left.
  5. A file header is stored with the data so the computer knows how to read it.
TermMeaning
PixelThe smallest element of a bitmap image; one square of one colour.
Image resolutionThe number of pixels wide × the number of pixels high that make up the image, for example 1024 × 512.
Screen resolutionThe number of pixels wide × high that a screen can display (sometimes quoted as dots per inch). The image resolution can be changed; the screen has a physical limit.
Colour depth / bit depthThe number of bits used to represent the colour of each pixel.
File headerData about the image file stored with the pixel data, such as the file type, image resolution, colour depth, file size, compression type and where the pixel data starts.

2 · Colour depth and the number of colours

With n bits per pixel there are 2n different codes, so 2n colours.

Bits per pixel12481624
Colours241625665 53616 777 216

To find the smallest bit depth for an image with a given number of colours, find the smallest n where 2n is at least that number. An image that uses 3 colours needs 2 bits; one that uses 256 colours needs 8 bits; one that uses 5 colours needs 3 bits.

3 · Estimating the file size

file size (bits) = image width × image height × colour depth
  1. Multiply the width by the height to get the number of pixels.
  2. Multiply by the bits per pixel.
  3. Divide by 8 for bytes, by 1024 for kibibytes, by 1024 again for mebibytes. If the question asks for MB or kB, use 1000.
QuestionWorkingAnswer
1024 × 512, 8 bits, in mebibytes1024 × 512 × 8 ÷ 8 ÷ 1024 ÷ 10240.5 MiB
2048 × 1024, 10 bits, in mebibytes2048 × 1024 × 10 ÷ 8 ÷ 1024 ÷ 10242.5 MiB
2 million pixels, 16 bits, in megabytes2 000 000 × 16 ÷ 8 ÷ 1 000 0004 MB
10 × 5 section, 256 colours256 colours = 8 bits; 10 × 5 × 8 ÷ 850 bytes
Exam tipRead the unit of the bit depth: "8 bytes per pixel" means no division by 8 for that part. Read the unit of the answer: mebibytes use 1024, megabytes use 1000. The file header is not included in an "estimate".

4 · Changing an image: quality and file size

ChangeEffect on the imageEffect on the file
Increase image resolutionMore pixels, so more detail and a sharper image, especially when enlargedMore pixels to store, so the file is larger
Decrease image resolutionFewer pixels, so less detail; the image looks blocky when enlargedSmaller file
Increase colour depthMore colours available, so smoother shading and more accurate coloursMore bits per pixel, so a larger file
Decrease colour depthFewer colours, so shades merge and detail is lostFewer bits per pixel, so a smaller file
Change the screen resolutionChanges how the image is displayed, not the image itselfNo change to the file
Change one pixel to a different colourThat pixel changesNo change if the colour depth is the same

5 · Vector graphics

A vector graphic is not stored as pixels. It is stored as a set of instructions.

TermMeaningExample
Drawing objectAn individual element of the imageA line, a rectangle, a circle, a letter
PropertyAn attribute of one drawing objectFill colour, line colour, line weight, position, size
Drawing listAll of the drawing objects in the image, stored with the commands or equations needed to draw each oneCircle: centre (120, 80), radius 40, fill yellow; line: from (0, 0) to (200, 100)

When the image is shown, the computer reads the drawing list and calculates the shapes. Because the shapes are recalculated, a vector graphic can be enlarged without pixelation, and one object can be edited without disturbing the rest.

6 · Bitmap or vector?

BitmapVector
Stored asA colour code for each pixelA drawing list of objects and their properties
EnlargingPixels get bigger and the image looks blockyThe shapes are recalculated, so quality is kept
File sizeUsually larger, because every pixel is storedUsually smaller for simple shapes
Best forPhotographs, scanned images, fine detail and shadingLogos, diagrams, plans, icons, text-based art
EditingEdit individual pixelsEdit each object and its properties
CompressionCan be compressed a lot (for example run-length encoding)Does not compress well, because there is little repeated data
Exam tipWhen a question says "justify" the choice itself earns nothing; the marks are for reasons that match the choice. Do not mix reasons from both types in one answer.

7 · Common ways to lose marks

  • Saying a pixel is "a dot of colour" without "smallest element" or "one colour".
  • Describing a bitmap without the sequence: pixel, colour, binary code, stored in order.
  • Forgetting to divide by 8 when the colour depth is in bits, or dividing when it is already in bytes.
  • Using 1000 for a mebibyte, or 1024 for a megabyte.
  • Saying that increasing screen resolution improves the file. Screen resolution does not change the stored image.

6 · Multiple choice







Examples are explained in general terms. Check current details before quoting them in an exam answer.

  
Why a small photo looks blocky when enlarged
A photo is a grid of pixels. Zooming in only makes each square bigger, so the edges become stepped. The computer cannot invent detail that was never stored.
Exam use: a bitmap enlarged: pixels get bigger, so the image is pixelated.

  
A logo on a card and on a billboard
A company usually keeps its logo as a vector graphic. The same drawing list is recalculated for a business card or a huge sign, with sharp edges at either size and a small file.
Exam use: justify vector: recalculated when resized, no pixelation, small file size.

  
Megapixels
A phone camera that records 12 megapixels stores about 12 million pixels in each photo. At 24 bits per pixel the raw image would need 36 million bytes, which is why photos are compressed before they are saved.
Exam use: image resolution × colour depth gives the uncompressed size; compression reduces it.

  
What is in the header
A BMP file begins with a header that holds the file type, the width and height, the colour depth, and where the pixel data starts. Without it the stream of pixel codes could not be put back into the right shape.
Exam use: file header items: file type, file size, dimensions, compression type, offset to the pixel data.

  
Fonts and maps
Many fonts and map symbols are stored as vector outlines, so one description works at any size on a phone or a poster. A satellite photo on the same map is a bitmap.
Exam use: mixed use: vector for shapes and text that scale, bitmap for photographic detail.

  • Define with the exact words. Pixel: smallest element, one colour. Image resolution: pixels wide by pixels high. Bit depth: bits per pixel.
    • 
    
  • Describe encoding in order. Pixels, one colour each, a unique binary code for each colour, codes stored in sequence.
    • 
    
  • Check the unit. Bits or bytes per pixel? Mebibytes (1024) or megabytes (1000)?
    • 
    
  • Show the multiplication. Width × height × bit depth, then the divisions. The working earns its own mark.
    • 
    
  • Say the cause. Decreasing the colour depth means fewer bits per pixel, so the file is smaller.
    • 
    
  • Justify one side only. For bitmap or vector, no mark for the choice, and mixed reasons contradict each other.
