7.3 Standard methods of solution

Some jobs come up again and again in programs. These standard methods are worth learning exactly: totalling, counting, finding the maximum, minimum and average, the linear search and the bubble sort. All examples use a 1-based array, as in the Cambridge pseudocode.

Totalling

Totalling keeps a running total. Start at 0, then add each value in turn.

Counting

Counting keeps a count that goes up by 1 each time something happens. Start at 0, and add 1 whenever the condition is met.

Maximum, minimum and average

For the maximum, start by assuming the first item is the largest, then replace it whenever a larger value is found. The minimum is the same with <. The average is the total divided by the number of items.

Initial valuesTotal and Count start at 0. Max and Min start at the first item, not 0. Starting Min at 0 would give a wrong answer if all values are positive.

Linear search

A linear search checks each item in order from the start until it finds the target or runs out of items. It works on any list, sorted or not. In the worst case it checks every item.

Bubble sort

A bubble sort puts a list into order. It makes repeated passes through the list. In each pass it compares each pair of neighbouring items and swaps them if they are in the wrong order. After the first pass the largest item has "bubbled" to the end, after the second pass the second largest is in place, and so on.

  • For N items, the basic algorithm makes at most N − 1 passes.
  • A swap needs a temporary variable, otherwise one value is overwritten.
  • If a whole pass makes no swaps, the list is already sorted and the algorithm can stop early (a flag such as Swapped can be used).

5 · Multiple choice

Descriptions are kept general. Check current details before quoting specifics.

A supermarket till

The till totals the price of each scanned item and counts how many items are in the basket.

Exam use: totalling and counting in one example: start both at 0 and add inside a loop.

A leaderboard

A game finds the highest score and keeps the scores sorted so the best appear first.

Exam use: maximum and sorting.

An election

Votes for each candidate are counted and then totalled; the maximum is the winner.

Exam use: counting, totalling and maximum together.

Finding a contact

Looking through an unsorted list of contacts one by one until you reach the name is a linear search.

Exam use: linear search works on any list, sorted or not, and may check every item.

Sorting a class by test score

A teacher repeatedly swaps neighbouring students that are out of order until the line is sorted: a bubble sort.

Exam use: compare neighbours and swap if out of order; the largest moves to the end first.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State what is meant by (a) totalling and (b) counting in an algorithm.
ReminderA running total and a running count.
(a) Totalling: keeping a running total by adding each value to it. (b) Counting: adding 1 to a count each time something happens (a condition is met).
Common mistakeSaying counting "adds up the numbers". Counting adds 1; totalling adds the values.
Q2 Write 4 marks Write pseudocode to input 10 numbers and output their total.
ReminderInitialise, loop, input, add, output.
Total ← 0 (initialised before the loop) FOR Count ← 1 TO 10 INPUT Number and Total ← Total + Number (inside the loop) OUTPUT Total (after the loop)
Common mistakeForgetting to set Total to 0, or putting OUTPUT inside the loop.
Q3 Write 3 marks The array Marks[1:30] holds 30 test marks. Write pseudocode to find the highest mark.
ReminderMax starts as the first item.
Max ← Marks[1] FOR Index ← 2 TO 30 with IF Marks[Index] > Max THEN Max ← Marks[Index] and OUTPUT Max after the loop
Common mistakeSetting Max to 0. Start with the first item.
Q4 Describe 3 marks Describe how a linear search finds a target in a list.
ReminderIn order, compare, stop.
Start at the first item in the list. Compare each item with the target in turn. Stop when the target is found (output its position) or when the end of the list is reached (output not found).
Common mistakeDescribing a binary search (halving). A linear search checks one by one.
Q5 State 2 marks A list has 100 items. State the maximum number of comparisons a linear search could need, and explain when this happens.
ReminderWorst case.
100 comparisons When the target is the last item or is not in the list.
Common mistakeSaying 50 (the average). Maximum means the worst case.
Q6 Complete 2 marks A bubble sort is used on the list 6 2 9 4 1. Write the list after the first pass.
ReminderCompare neighbours: swap when the left is bigger.
Pass 1 swaps: 6 and 2 swap, 9 and 4 swap, 9 and 1 swap. List after pass 1: 2 6 4 1 9
Common mistakeSorting the whole list. After one pass only the largest is guaranteed to be in place.
Q7 Describe 4 marks Describe how a bubble sort works.
ReminderPasses, neighbours, swap, repeat.
It makes repeated passes through the list. In each pass, each pair of neighbouring items is compared. If a pair is in the wrong order, they are swapped. Passes repeat until no swaps are needed (the list is sorted); the largest item moves to the end in the first pass.
Common mistakeSaying it "sorts the list" without describing the neighbour comparisons and swaps.
Q8 Write 4 marks Write pseudocode to count how many of the 30 marks in Marks[1:30] are 50 or more, and output the count.
ReminderCount starts at 0 and goes up by 1 inside an IF.
Count ← 0 FOR Index ← 1 TO 30 IF Marks[Index] >= 50 THEN Count ← Count + 1 OUTPUT Count after the loop
Common mistakeWriting Count ← Count + Marks[Index], which totals the marks instead of counting.

Top tips

  • Total and Count start at 0. Max and Min start at the first item.
  • Counting adds 1; totalling adds the value.
  • Average = Total / number of items, worked out after the loop.
  • Linear search checks one by one. Worst case: every item.
  • Bubble sort: compare neighbours, swap if out of order, repeat passes. The largest item reaches the end first.
  • A swap needs a temporary variable.
