Sound: Sampling Rate and Sampling Resolution

Coursebook: Chapter 1 · Information representation, section 1.2 Multimedia (sound)

How an analogue sound wave is sampled and stored in binary, what changing the sampling rate and resolution does to accuracy and file size, sound file calculations, and nine questions from the 2021 to 2026 papers.

This page in five sentences

Sound is an analogue wave, a continuous signal, and a computer can only store digital data, so the wave is sampled: its amplitude is measured at regular intervals and each measurement is stored as a binary number. The sampling rate is how many samples are taken each second (in hertz), and the sampling resolution is how many bits are used for each sample. A higher rate or a higher resolution makes the digital sound closer to the original, with smaller quantisation errors, but the file is larger because more bits are stored. Two things never change the accuracy: the length of the recording only changes the file size. Marks are for the exact meanings, for the effect on both accuracy and file size, and for a calculation with the working shown.

Computer useCannot be stored directlyCan be stored and processed

To record sound, the analogue signal is converted into digital data. To play it back, the digital data is converted back into an analogue signal for the speaker.

2 · How sound is sampled and encoded

  1. The amplitude (height) of the sound wave is measured at regular time intervals. Each measurement is a sample.
  2. The number of samples taken each second is the sampling rate, measured in hertz (Hz) or kilohertz (kHz). A rate of 44.1 kHz means the amplitude is measured 44 100 times each second.
  3. Each measured amplitude is rounded to the nearest of the values that can be stored, and given a binary number. The number of bits for each sample is the sampling resolution. With 16 bits there are 216 = 65 536 possible amplitudes; 2 bytes is the same as 16 bits.
  4. The binary number for each sample is stored in sequence.

The difference between the true amplitude and the nearest stored value is a quantisation error. The Watch tab animates the rounding.

3 · Changing the rate and the resolution

Decrease the sampling rateBigger gaps, so the digital wave is less like the originalSmaller

Exam tipName which setting you are describing. "Sampling rate" is about gaps in time; "sampling resolution" is about the number of values for each sample. A mark scheme that says "must be clear which resolution is being described" will not accept an answer that mixes the two.

4 · Estimating the file size

file size (bits) = sampling rate × sampling resolution × time (seconds)

Convert the time to seconds and the rate to samples per second (44.1 kHz = 44 100). Then divide by 8 for bytes and by 1 000 000 (megabytes) or 1024 × 1024 (mebibytes) for larger units. If the question says stereo, there are two channels, so multiply by 2.

5 · Common ways to lose marks

  • Writing that a higher sampling rate makes the sound louder or higher pitched. It makes the recording more accurate.
  • Saying "more bits" without saying "per sample" for the resolution.
  • Forgetting to convert minutes to seconds, or kilohertz to hertz.
  • Giving the effect on accuracy but not on file size, when the question asks about both.
  • Describing the sampling rate as "how often the sound is recorded" without the unit of time. Say "per second".

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Why a CD uses 44.1 kHz

People can hear sounds up to roughly 20 kHz. To capture a wave properly, the sampling rate has to be more than twice the highest frequency, so audio CDs use 44 100 samples each second with 16 bits per sample.

Exam use: typical rate and resolution: 44.1 kHz and 16 bits, so 44 100 amplitude measurements per second, each stored in 16 bits.

Why phone calls sound thin

Telephone speech has historically been sampled at about 8 kHz with 8 bits. That is enough to make speech understandable, but it removes the higher sounds, so music over a phone line sounds poor.

Exam use: a low sampling rate and resolution give a small file and lower accuracy, which is acceptable for speech.

High-resolution audio

Some music is offered at 96 kHz and 24 bits. Each second needs more than three times the data of a CD, and few listeners can hear the difference, so the larger file is a trade-off.

Exam use: higher rate and resolution: more accurate, much larger file.

Voice notes

A voice recording app often uses a low sampling rate and one channel so that messages are small enough to send quickly, since a voice does not need the range of music.

Exam use: choose settings to suit the use: smaller file against accuracy.

A recording that is twice as long

A podcast recorded for 40 minutes instead of 20 is not twice as accurate. It has the same quality, and the file is twice as big.

Exam use: the length of a recording changes the file size only, not the accuracy.

Based on Oct/Nov 2022 · 9618/13 · Q1(a)-(b) [4] A digital audio message is recorded. (i) State whether each action makes the accuracy increase, decrease or stay the same: change the sampling rate from 40 kHz to 60 kHz; change the duration from 20 to 40 minutes; change the sampling resolution from 24 to 16 bits. (ii) The message is recorded at 40 kHz with 16 bits for 10 minutes. Calculate the file size in megabytes. Show your working.
What the mark scheme wants
  • Rate up: accuracy increases. Duration longer: no change. Resolution down: accuracy decreases.
  • Working 40 000 × 16 × 600 ÷ 8, answer 48 MB.
Plan

10 minutes = 600 s. 40 000 × 16 × 600 = 384 000 000 bits ÷ 8 = 48 000 000 bytes = 48 MB.

Technical knowledge (K)Applied to the context (A)

Accuracy increases, stays the same, decreases. 40 000 × 16 × 600 = 384 000 000 bits ÷ 8 = 48 000 000 bytes = 48 megabytes.

Top tips

  • Name the setting. Say sampling rate (samples per second) or sampling resolution (bits per sample). Do not use 'quality' on its own.
  • Give both effects. Accuracy and file size. If the question asks about one, answer that one.
  • Use the words. Quantisation error, analogue, digital waveform, amplitude, sample.
  • Convert first. Minutes to seconds, kHz to Hz, bytes to bits, before multiplying.
  • Time changes size only. A longer recording is not more accurate.
  • Reverse arguments are fine. If the question is about decreasing, the mark scheme allows the opposite of the increase points.
