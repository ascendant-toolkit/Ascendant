Counting and Totalling

Running totals, counters and averages: how a variable keeps track of data inside a loop.

The big idea

Totalling adds up values. Counting adds 1 each time something happens. Both start at 0 before a loop, change inside it, and are output after it.

8.1.4 Counting and totalling

Programs often need to keep track of something as they run. Totalling adds up values. Counting works out how many times something happens. Both use a variable that changes inside a loop, so they build on iteration, and counting often uses selection too.

Totalling

A running total starts at 0. Inside the loop, each new value is added to it. The new total is stored back in the same variable.

Counting

A count starts at 0. Each time something happens, 1 is added. Counting always adds 1. Totalling adds the value.

Initialise before the loop, output after it

Setting a variable to its starting value is called initialising. Do it before the loop. If it is inside the loop, it is reset to 0 on every repeat. Output the answer after the loop, when the total is complete.

Two classic mistakesNot setting Total or Count to 0 (it holds a leftover or missing value). Putting OUTPUT inside the loop, which shows a half-finished total on every repeat.

Counting and totalling with a sentinel

If you do not know how many values there will be, use a loop that stops on a special value, called a sentinel (for example -1). Total and count as you go, then work out the average = Total / Count after the loop. The sentinel is not part of the data, so it is never added.

The input before the loopThe first INPUT comes before the WHILE so there is a value to test. The next INPUT goes at the end of the loop body.

Pseudocode and Python

The logic is identical. Python's total += number is a short way to write total = total + number, and you may see it in other code. In pseudocode, use the full form.

Top tips

  • Total and Count start at 0. Set them before the loop.
  • Counting adds 1. Totalling adds the value.
  • Output after the loop. Inside it you only see a running total.
  • Count with a condition: put the Count ← Count + 1 inside an IF.
  • Average = Total / Count, worked out after the loop.
  • With a sentinel, never add the sentinel. Input once before the loop and again at the end of the body.
