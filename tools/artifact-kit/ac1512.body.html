This page in five sentences

Computer architectures are classified by how many instruction streams and how many data streams they handle at once. SISD (single instruction, single data) is an ordinary sequential computer with one processor. SIMD (single instruction, multiple data) applies the same instruction to many data items at the same time, and MISD (multiple instruction, single data) applies different instructions to the same data stream. MIMD (multiple instruction, multiple data) has many processors, each running its own instructions on its own data, independently. A massively parallel computer links together a very large number of processors or separate computers, each working on its own part of one problem at the same time, and they communicate over a network by passing messages.

1 · The four categories

Single data streamMultiple data streams
Single instruction streamSISD: one processor does one instruction at a time on one piece of dataSIMD: the same instruction is performed on many data items at once
Multiple instruction streamsMISD: different instructions are performed on the same dataMIMD: different instructions on different data, at the same time

SISD: Single Instruction, Single Data

  • Data is taken from a single source and a single instruction is performed on it at a time.
  • It has one processor, a control unit and a memory unit, and executes instructions sequentially.
  • The traditional (von Neumann) computer, such as a basic single-core processor.

SIMD: Single Instruction, Multiple Data

  • The same operation is performed on multiple different data streams simultaneously.
  • A parallel computer with multiple (array) processors that execute the same instruction using different data sets.
  • Example: changing the brightness of every pixel in an image; graphics processors.

MISD: Multiple Instruction, Single Data

  • Different operations are performed on the same data stream.
  • Each processor works on the same data independently, using different instructions. Parallel computers with multiple processors.
  • Rare in practice. Example: several different checks on the same data in fault-tolerant systems.

MIMD: Multiple Instruction, Multiple Data

  • At any time any processor can execute different instructions on different sets of data.
  • Contains many processors that operate asynchronously and independently.
  • Example: a multi-core processor running several programs, a cluster of computers.

2 · Massively parallel computers

A massively parallel computer links together very many processors (thousands or more) or separate computers.

  • A large number of processors / computers connected together to form a more powerful "single machine".
  • They work simultaneously on the same problem, a set of coordinated computations, with each processor responsible for its own part of the problem.
  • They need a network infrastructure (interconnected data pathways) and communicate by sending messages (a message interface), or through shared pools of memory.

Used for problems that can be split into many independent parts: weather forecasting, simulations of molecules, searching enormous databases, training large AI models.

BenefitLimitation
Very large problems are solved far faster because the work is sharedThe problem must be split into parts that can run at the same time
More processors can be added to increase powerProcessors spend time communicating, which can slow things down; the network is costly and complex

3 · Common ways to lose marks

  • Expanding the acronym and nothing more. The question asks for the features: how many processors, what they do and to which data.
  • Mixing up SIMD and MISD: in SIMD the instruction is the same and the data differ; in MISD the data is the same and the instructions differ.
  • Describing MIMD without saying the processors work independently / asynchronously.
  • Describing a massively parallel computer as "one very fast processor". It is many processors linked together, communicating by messages.
  • Saying SISD is "slow". It is sequential: one instruction at a time on one data item.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A graphics card (SIMD)

To brighten an image the same instruction, add 20 to the brightness, is applied to millions of pixels at once. A graphics processor has many simple processors doing the same operation on different data.

Exam use: SIMD: the same instruction on many data items simultaneously.

A multi-core phone (MIMD)

While one core plays music another handles the screen and another the network. Each core runs different instructions on different data, independently.

Exam use: MIMD: many processors, different instructions, different data, asynchronously.

A basic microcontroller (SISD)

A very simple controller in a toy or alarm has one processor that runs one instruction at a time on one piece of data.

Exam use: SISD: one processor, sequential execution.

A weather forecast on a supercomputer

The atmosphere is divided into millions of boxes. Each of thousands of processors works out the weather for its own boxes at the same time and passes messages to its neighbours.

Exam use: massively parallel: many processors, each doing its part, communicating by messages.

Error checking in a flight system (MISD)

Several different programs check the same sensor data independently, and their answers are compared. This is a rare use of MISD.

Exam use: MISD: different instructions on the same data stream.

M/J 2026 · 9618/33 · Q4(b) State 2 marks State one difference and one similarity between the SIMD and MISD computer architectures.
ReminderBoth must be named in each answer. The difference: what is the same and what changes.

Difference (one): SIMD systems all execute the same instruction, whereas MISD systems perform different instructions SIMD systems work on many data streams simultaneously, whereas MISD systems all work on the same data source Similarity (one): Both are parallel systems Both use multiple processors

Common mistakeWriting only what SIMD does. A difference must mention both SIMD and MISD.

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

Distinguish 2 marks Distinguish between SISD and SIMD.
ReminderHow many data items are handled at once?

SISD has one processor that carries out one instruction at a time on one data item, sequentially. SIMD applies the same instruction to many data items at the same time, using several processors.

Explain 3 marks Explain why a graphics processor suits SIMD.
ReminderThink of pixels.

Operations such as changing brightness are the same for every pixel. The same instruction can be applied to many pixels (data items) at once. Many simple processors working at the same time finish the image much faster than one processor.

State 2 marks State two features of a MIMD computer.
ReminderInstructions, data, timing.

It has many processors, each able to execute different instructions on different data. The processors operate asynchronously / independently.

Describe 3 marks Describe how a massively parallel computer might forecast the weather.
ReminderSplit the problem, work at once, share results.

The atmosphere is divided into many small areas and each processor is responsible for its own part. All the processors work simultaneously on their parts of the problem. They communicate by sending messages over the network, for example to share boundary values with neighbours.

State 2 marks State two limitations of massively parallel computers.
ReminderSplitting and communicating.

The problem has to be split into parts that can be done at the same time. Communication between processors takes time and the network is complex and expensive.

Top tips

  • Say what is single and what is multiple. Instruction streams and data streams: S or M for each.
  • SIMD: same instruction, different data. MISD: different instructions, same data.
  • MIMD: independent. Many processors, different instructions and data, asynchronously.
  • SISD: one processor, sequential. One control unit, one memory unit.
  • Massively parallel: many, together, messages. Many processors linked by a network, each doing its part of one problem.
  • Do not only expand the acronym. Give the features.
