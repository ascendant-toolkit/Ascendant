Database Management Systems

Coursebook: Chapter 8 · Databases · section 8.2 Database management systems (DBMS)

The DBMS tools (data dictionary, logical schema, query processor and developer interface), and how a DBMS provides security and supports integrity, with animations, labs and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

A Database Management System (DBMS) is software used to create, maintain and query a database. Its main tools are the data dictionary (metadata: data about the data, such as table and field names, data types, validation rules, keys and relationships), the logical schema (a model of the database, such as an E-R diagram, not specific to one DBMS), the query processor (takes the user's criteria, searches, and returns and organises the results) and the developer interface (tools to create tables, relationships, forms, reports and queries). A DBMS provides security with authentication, access rights, views, back-up and recovery, encryption and record locking, and supports integrity with validation, referential integrity and normalisation. Exam answers name the tool and say what it does or contains.

1 · DBMS features and tools

ToolWhat it is or does
Data dictionaryStores metadata, data about the data in the database or the structure of the database: table names, field (attribute) names, data types, validation rules, primary and foreign keys, relationships
Logical schemaAn overview of the database structure that models the problem, using methods such as an E-R diagram; independent of any particular DBMS; shows the relationship between data and its structure
Query processorAllows the user to enter criteria, searches for the data that meets them (processes and executes queries written in SQL) and organises the results to display to the user
Developer interfaceAllows the user to create, modify and delete tables, set up relationships, create forms for data input (with drop-down boxes and buttons), design reports and menus, and run SQL queries

2 · Security

MethodHow it protects the data
Authentication (passwords, biometrics, two-factor)Prevents unauthorised access to the data
Access rights (privileges)Different users or accounts get different permissions to different tables (read only, read and write, full access, no access), so only those with permission can read or edit the data
ViewsDifferent users see different parts of the database, only what they need to see (for example a manager sees only their own shops)
Back-up and recoveryThe DBMS takes copies of the database automatically on a regular basis (stored off site) so the data can be recovered if lost or damaged
EncryptionData is turned into cipher text so it cannot be understood without the decryption key
Record and table lockingPrevents simultaneous access to the same data so updates are not lost or overwritten

3 · Integrity

A DBMS supports data integrity by enforcing validation rules, referential integrity (with cascading updates and deletes), and a normalised design, and by record locking so concurrent changes are consistent.

Common ways to lose marks

  • Describing the data dictionary as "a list of words". It stores metadata: table names, field names, data types, validation rules and keys.
  • Confusing the logical schema (the design, independent of any DBMS) with the data dictionary (the stored description).
  • Naming a security method without how it protects the data ("access rights" needs "so only those with permission can read or edit").
  • Saying the query processor "stores queries". It takes criteria, finds matching data and organises the results.
  • Describing the developer interface as "typing SQL". It is the set of tools to build tables, forms and reports.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A shop manager and a till operator

The manager can see sales for all shops and change prices; the till operator can only add sales. Different access rights and views for each.

Exam use: access rights and views.

Two people booking the last seat

The DBMS locks the seat record while one booking is processed so the second person cannot book it too.

Exam use: record locking.

Searching a library catalogue

You type criteria such as an author; the query processor finds the books and lists them in order.

Exam use: query processor.

A new form for entering orders

The database designer drags fields onto a form with drop-down boxes using the developer interface.

Exam use: developer interface.

A nightly copy of the database

Stored off site, so if the server fails the data can be recovered.

Exam use: back-up and recovery.

Top tips

  • Data dictionary: metadata. Names, types, rules, keys.
  • Logical schema: the design. E-R diagram; independent of any DBMS.
  • Query processor: criteria to results. Search and organise.
  • Developer interface: build things. Tables, forms, reports, queries.
  • Security: method plus how. Access rights so only permitted users...
  • Integrity: validation, referential integrity. Not the same as security.
