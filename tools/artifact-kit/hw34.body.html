3.4 Network Hardware

The network interface card, MAC addresses and their structure, IP addresses (static, dynamic, IPv4 and IPv6) and the role of a router.

The big idea

A NIC connects a computer to a network and carries a fixed MAC address. The network gives it an IP address, and a router uses IP addresses to send data to the right place.

3.4 Network hardware

NIC

A network interface card (NIC) is the hardware a computer needs to connect to a network, wired or wireless. It is given a MAC address when it is made.

Router

A router sends data to a specific destination on a network, connects a local network to the internet, and can assign IP addresses to the devices on the local network.

MAC address

A media access control (MAC) address uniquely identifies a device's NIC. It is set at the point of manufacture, so it does not change. It is usually written as 6 pairs of hexadecimal digits, for example:

3C22FB1AB407

The first half (blue) is the manufacturer code; the second half (green) is the serial code the manufacturer gives that device.

IP address

An internet protocol (IP) address identifies a device on a network so data can be sent to the right place. It is allocated by the network, not by the manufacturer. It can be static (does not change) or dynamic (may be different each time the device connects).

Descriptions are kept general. Check current details before quoting specifics.

The home router

One box connects the family's phones, laptops and TV to the internet. It hands each device a private IP address, and every device's network card has its own MAC address.

Exam use: shows the router assigning IP addresses and connecting a local network to the internet, and why MAC and IP addresses differ.

Laptop on different Wi-Fi networks

The same laptop has the same MAC address at home, at school and in a café, but a different IP address on each network.

Exam use: the MAC address is fixed to the hardware; the IP address is allocated by the network.

Websites with a fixed address

A company's web server usually needs an address that never changes, so people can always find it. Home devices usually get dynamic addresses.

Exam use: static against dynamic IP addresses and when each suits.

Running out of addresses

With billions of phones, laptops, TVs and sensors online, there are not enough IPv4 addresses for every device, so IPv6 with its enormous address space is being adopted.

Exam use: why IPv6 exists: the size of the address space.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 Describe 4 marks Describe what a MAC address is and how it is made up.
ReminderUnique, set when made, hex, two halves.
A MAC address uniquely identifies a device's network interface card (NIC) on a network. It is assigned at the point of manufacture. It is usually written in hexadecimal (six pairs of hex digits). It is made of a manufacturer code and a serial code.
Common mistakeSaying the network gives the MAC address. The manufacturer does; the network gives the IP address.
Q2 Compare 4 marks Compare IPv4 and IPv6 addresses.
ReminderBits, format, how many addresses, and why IPv6 exists.
IPv4 is 32 bits long; IPv6 is 128 bits long. IPv4 is written as four groups of denary numbers (0 to 255) separated by dots. IPv6 is written as eight groups of four hexadecimal digits separated by colons. IPv6 gives far more possible addresses (2128 against 232), so there is enough for all devices.
Common mistakeSaying IPv6 is "faster". The key difference is the size of the address space.
Q3 Describe 3 marks Describe the role of a router in a home network.
ReminderSends, connects, assigns.
It receives data and sends it to a specific destination on the network (using the destination IP address). It connects the local network to the internet. It can assign IP addresses to the devices on the network.
Common mistakeDescribing it only as "gives you Wi-Fi". Say it routes data and connects networks.
Q4 State 2 marks State what a network interface card (NIC) is, and what it is given when it is made.
ReminderWhat it lets the computer do, then the address.
A NIC is the hardware a computer needs to connect to (access) a network. It is given a (unique) MAC address at the point of manufacture.
Common mistakeSaying the NIC is given an IP address when made. The network allocates the IP address.
Q5 Explain 3 marks Explain the difference between a static IP address and a dynamic IP address.
ReminderWho allocates it, and whether it changes.
Both are allocated by the network (not the manufacturer). A static IP address stays the same every time the device connects. A dynamic IP address may be different each time the device connects.
Common mistakeSaying a static address means the device "does not move". It means the address does not change.
Q6 Compare 3 marks Compare a MAC address with an IP address.
ReminderWho sets each, whether it changes, and what it belongs to.
A MAC address is set by the manufacturer at manufacture; an IP address is allocated by the network. A MAC address belongs to the NIC and does not change; an IP address may change (dynamic). Both identify a device on a network.
Common mistakeWriting about only one address. A comparison needs both sides in each point.

Top tips

  • MAC = manufacturer, fixed. IP = network, can change.
  • MAC: 6 pairs of hex digits, a manufacturer code and a serial code.
  • IPv4: 32 bits, four denary groups, dots. IPv6: 128 bits, eight hex groups, colons.
  • Say why IPv6 exists: far more addresses, not "faster".
  • A router routes. Sends to a destination, connects networks, assigns IPs.
