This page in five sentences

Artificial intelligence (AI) is the ability of a computer system to carry out tasks that normally need human intelligence; machine learning is the part of AI in which a system learns from data instead of being given explicit rules; and deep learning is a part of machine learning that uses artificial neural networks with many hidden layers. The main categories of machine learning are supervised learning (trained on labelled data, to predict outcomes), unsupervised learning (given unlabelled data and left to find hidden patterns or clusters) and reinforcement learning (an agent learns by trial and error from rewards and punishments in an environment). Deep learning copes well with large amounts of unstructured data and can find patterns people would not spot. Each method is chosen for the kind of data available and the kind of answer needed.

1 · AI, machine learning and deep learning

They are nested: deep learning is a type of machine learning, which is a type of AI. A machine learning system is trained on data and improves its results with experience; it is not programmed with every rule.

2 · Supervised learning

  • The system is trained with labelled data: sample inputs with the known, correct outputs (for example emails marked spam or not spam).
  • It learns a mapping from inputs to outputs, and can then predict outcomes for new data and future events based on past outcomes.
  • It needs initial human input to provide and label the training data.

3 · Unsupervised learning

  • The system is given unlabelled data, with no known outcomes, and no instructions on what to do with it.
  • It searches for hidden patterns, structures, groupings or clusters and for similarities and differences, and uses them to predict outcomes.
  • It does not need human intervention or training with the correct outputs. As training progresses it gets closer to the desired outcome.

4 · Reinforcement learning

  • An agent learns to behave in an environment by performing actions and seeing the results of those actions: trial and error, using its own experiences.
  • It is based on feedback: a good action earns a reward (positive feedback) and a bad action a punishment (negative feedback).
  • It learns automatically from the feedback without labelled data or specific instructions, adjusting its weightings to improve at similar tasks.

5 · Deep learning

Deep learning is a specialised form of machine learning that uses artificial neural networks, designed to work like the human brain, with an input layer, a large number of hidden layers and an output layer. Each layer extracts higher-level features from the layer before, so the network gradually breaks the data down and finds hidden patterns. It learns by adjusting the weights of the connections, and uses back propagation of errors to refine them (see 18.1.4).

Reasons for using it

  • It makes good use of unstructured data, such as images, sound and text.
  • It outperforms other methods when the amount of data is large.
  • It can process data with a non-linear approach.
  • It is effective at identifying hidden patterns that humans might not see or that are too complex and slow for humans to find.
  • More hidden layers can give a more accurate outcome.

Examples: virtual assistants, chatbots, self-driving cars, image and facial recognition, fraud detection, translation, large language models, playing chess, weather forecasting. It can be made more effective by introducing more hidden layers.

6 · Common ways to lose marks

  • Writing "labelled" for unsupervised data. Supervised data is labelled; unsupervised is not.
  • Describing reinforcement learning without feedback: rewards and punishments for actions.
  • Saying deep learning is "the same as" machine learning. It is a branch of it that uses neural networks with many hidden layers.
  • Giving "it is better" as a reason for deep learning. Say: unstructured data, large data sets, hidden patterns.
  • Mixing up the neural network (the structure) and deep learning (learning with a many-layered one).

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Spam filters

The filter is trained on thousands of emails that people have marked as spam or not spam. From these labelled examples it learns to label new messages.

Exam use: supervised learning uses labelled data.

Shop recommendations

A shop groups customers with similar buying habits without anyone telling it the groups in advance, then suggests items popular in the same group.

Exam use: unsupervised learning finds clusters in unlabelled data.

Game-playing programs

A program plays against itself many times. Wins are rewards and losses are punishments, and it learns which moves work.

Exam use: reinforcement learning by trial and error.

Voice assistants and photo apps

Recognising speech or faces needs many layers of a neural network, each picking out a higher-level feature, trained on huge amounts of data.

Exam use: deep learning with many hidden layers.

Self-driving cars

They combine deep learning to recognise road scenes with reinforcement learning to improve driving decisions.

Exam use: different methods for different parts of the task.

Top tips

  • Supervised: labelled data. Known outputs; predicts future outcomes.
  • Unsupervised: unlabelled data. Finds hidden patterns and clusters; no human labelling.
  • Reinforcement: reward and punishment. An agent learns by trial and error in an environment.
  • Deep learning: many hidden layers. A neural network; a branch of machine learning.
  • Reasons for deep learning. Unstructured data, large data sets, non-linear, hidden patterns.
  • Neural network subset: deep learning. Not just 'machine learning'.
