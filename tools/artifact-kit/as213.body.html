Coursebook: Chapter 2 · Communication · section 2.1 Networks including the internet

NICs, switches, WAPs, bridges, repeaters, the router and its functions, and Ethernet with CSMA/CD collision handling; animations, labs and the real Paper 1 questions from 2021 to 2025.

This page in five sentences

A LAN is built from a few kinds of hardware: a network interface card (NIC) or wireless NIC (WNIC) in each device, cables, a switch that forwards data only to its destination, a server, a wireless access point (WAP) for wireless devices, a bridge to join two LANs and a repeater to restore a weakening signal. A router joins networks together: it receives packets, reads the destination IP address, uses its routing table to choose the best route and forwards the packet. Ethernet is the protocol used for wired LANs, and it uses CSMA/CD to cope with collisions: a device listens, sends only when the line is idle, and if a collision happens it stops, sends a jamming signal and retries after a random wait. A router and a switch do different jobs: a switch connects devices inside a LAN by MAC address; a router connects different networks by IP address.

1 · LAN hardware

DevicePurpose
Network interface card (NIC)Lets a device connect to a wired network. It has a MAC address that identifies the device on the network.

BridgeConnects two LANs or segments that use the same protocol and transmits data between them.
RepeaterRestores a digital signal so it can be transmitted over greater distances.

2 · The router

A router connects a LAN to other networks such as the internet. Its functions:

  • Receives packets from devices on the LAN or from the internet.
  • Analyses the destination IP address of each packet.
  • Looks the address up in its routing table and forwards the packet towards its destination, finding the most efficient route; it maintains and updates the routing table.
  • Allocates private IP addresses to devices on the LAN, and may share one public address between them (NAT).
  • Implements a firewall, and may change the format of a packet for the next network.
  • A home router usually also contains a switch and a WAP, and stores a table of the MAC and IP addresses of the devices attached to it.

A router does not direct each packet to all devices (that is a hub) and does not look up the IP address of a URL (that is a DNS server).

3 · Ethernet and CSMA/CD

Ethernet is a protocol (suite) for data transmission over standard wired network connections. Data is sent in frames; each frame has a source and destination (MAC or IP) address and error-checking data, so damaged frames can be resent. When devices share one transmission medium, two may transmit at the same moment and the signals collide. Ethernet manages this with CSMA/CD, Carrier Sense Multiple Access with Collision Detection:

  1. Carrier sense: a device that wants to transmit listens to the channel.
  2. It sends data only when the line is idle, no other data being transmitted.
  3. Multiple access means more than one computer is connected to the same medium, so two can start at once.
  4. Collision detection: if a collision is detected, the devices stop (abort) transmission and send a jamming signal.
  5. Each device waits a random time before it tries to resend. If further collisions occur, the random wait time is increased.

Drawbacks of CSMA/CD: waiting times can grow without limit and constant jamming could stop anything being sent; certain nodes cannot be prioritised; it is only suitable for short-distance networks and does not scale well, as more nodes mean much longer waits.

4 · Common ways to lose marks

  • Confusing a hub and a switch. A switch sends a packet only to the intended device.
  • Describing CSMA/CD without the random wait. The order is listen, send if idle, detect collision, jam, wait a random time, resend.
  • Saying a router "connects computers". Say it connects networks and routes packets using IP addresses and a routing table.
  • Giving the NIC's purpose as "to connect to the internet". It provides the interface to the network and identifies the device with a MAC address.
  • Mixing up a bridge (joins two LANs with the same protocol) and a repeater (restores the signal).

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

The box from your internet provider

It is a router, a switch and a wireless access point in one: it connects your home network to the internet, connects wired devices and gives Wi-Fi to the rest.

Exam use: a router connects networks; the WAP gives Wi-Fi.

The network socket in a classroom

Behind it, cables run to a switch in a cabinet. The switch sends each packet only to the computer it is meant for.

Exam use: a switch forwards to the intended device.

A Wi-Fi extender

It repeats the signal so it reaches rooms that are too far from the router. That is a repeater.

Exam use: a repeater restores the signal over greater distance.

Talking on a walkie-talkie

If two people talk at once you hear nothing. Both stop, and each waits a random moment before trying again. That is how Ethernet handles collisions.

Exam use: CSMA/CD: random wait after a collision.

The MAC address on a laptop's sticker

Every network card has its own MAC address, so the switch knows which device is which.

Exam use: the NIC identifies the device on the network.

Top tips

  • Switch: only to the recipient. Hub: to everyone.
  • Router: IP addresses and routing table. It connects networks.
  • CSMA/CD order. Listen, send if idle, collision, jam, random wait, resend.
  • NIC: MAC address. WNIC: also an antenna.
  • Bridge v repeater. Bridge joins LANs; repeater restores the signal.
  • Ethernet: frames. With addresses and error-checking data.
