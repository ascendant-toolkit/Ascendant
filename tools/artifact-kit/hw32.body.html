3.2 Input and Output Devices

Input and output devices, how they work, and sensors: what each measures, what data it captures and when to use it.

The big idea

Input devices put data in, output devices present results out, and sensors measure the real world so a computer can respond to it, often by switching an actuator.

3.2 Input and output devices

An input device is needed to enter data or instructions into a computer, because a computer cannot use real-world information (a key press, a sound, an image) until it is converted to digital data. An output device is needed to present the results of processing in a form people can use.

Input devices

DeviceHow it works
KeyboardEach key press closes a circuit and sends a code for that key.
Optical mouseAn LED or laser lights the surface and a sensor tracks how the pattern moves, so the pointer moves.
MicrophoneSound waves move a diaphragm, which makes an analogue electrical signal; this is converted to digital.
Digital cameraLight passes through a lens onto a sensor made of many light-sensitive cells; each cell's value becomes a pixel.
Barcode scannerShines a laser across the barcode. Dark bars reflect less light than white gaps; the pattern is turned into a number.
QR code scannerA camera reads the two-dimensional grid of squares and decodes it; it can hold far more data than a barcode.
Resistive touch screenTwo flexible layers are pressed together by a touch; the circuit finds where. Works with a finger, stylus or glove.
Capacitive touch screenA finger changes the electric field on the screen; the position is calculated. Needs a conductive touch. Supports multi-touch.
Infra-red touch screenA grid of infra-red beams across the screen; a touch breaks beams, which gives the position.
2D scannerA light and sensor move across a flat document to make a digital image.
3D scannerLasers or light patterns measure the surface of an object from many angles to build a 3D model.

Output devices

DeviceHow it works
LCD screenLiquid crystals open and close to let backlight through, making coloured pixels.
LED screenAn LCD screen that uses LEDs for its backlight, giving brighter, thinner, more energy-efficient displays.
LCD projectorLight is passed through small LCD panels and focused through a lens onto a screen.
DLP projectorLight is reflected off thousands of tiny mirrors that tilt on and off to form the image.
Inkjet printerNozzles spray tiny droplets of ink onto paper. Good quality photos, lower print volume.
Laser printerA laser draws the page on a drum; toner sticks to it and is fused onto the paper with heat. Fast, high volume.
3D printerBuilds a solid object layer by layer from a digital model, for example with melted plastic.
SpeakerAn electrical signal moves a cone to make sound waves.
ActuatorTurns an electrical signal into physical movement, for example a motor, valve or lock.

Sensors

A sensor is an input device that measures a physical quantity from its surroundings. Sensors capture analogue data, which an analogue-to-digital converter (ADC) changes into digital data the computer can process. The result may then control an actuator.

Descriptions are kept general. Check current details before quoting specifics.

A supermarket checkout

A barcode scanner reads the product code, a pressure sensor in the scales weighs loose fruit, a touch screen takes the customer's choices, and a printer outputs the receipt.

Exam use: a worked example of several input and output devices working together.

A car

Dozens of embedded systems: parking proximity sensors, tyre pressure sensors, an accelerometer that triggers airbags, and actuators that lock doors or move wing mirrors.

Exam use: match each sensor to the data it captures and the action an actuator takes.

A smartphone's sensors

An accelerometer rotates the screen and counts steps, a proximity sensor switches the screen off at your ear, a light sensor adjusts brightness, and a capacitive touch screen takes input.

Exam use: several sensors named with what each measures; a capacitive example.

Smart home alarm

A magnetic field sensor on the door, an infra-red motion sensor in the hall and an acoustic sensor for breaking glass all report to a controller that sounds a siren (an actuator).

Exam use: choosing the most suitable sensor for a given context.

School printing

A school office prints thousands of pages with a laser printer, while the art department uses an inkjet for photographs and a 3D printer for models.

Exam use: choose the output device to suit the job.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 Explain 3 marks A greenhouse uses a computer to keep the temperature steady. Explain how sensors and an actuator are used.
ReminderSensor measures, ADC converts, processor compares, actuator acts.
A temperature sensor measures the temperature (analogue data), converted to digital by an ADC. The processor compares the reading with the stored value. If it is too high, the processor sends a signal to an actuator (for example a motor that opens a window).
Common mistakeHaving the sensor "turn on the fan". Sensors only measure; the actuator acts.
Q2 Identify 3 marks Name the most suitable sensor for (a) an automatic street light, (b) a car parking aid, (c) a swimming pool water check.
ReminderWhat is being measured in each?
(a) Light sensor (b) Proximity sensor (c) pH sensor
Common mistakeAnswering "camera" or "sensor" without saying which type.
Q3 State 2 marks State what is meant by an input device and why a computer needs one.
ReminderWhat it does, and why.
An input device enters data or instructions into a computer. It is needed so that the computer can receive real-world information (such as key presses, sounds or images) to process.
Common mistakeWriting only examples. Say what an input device does.
Q4 Compare 4 marks Compare resistive and capacitive touch screens.
ReminderHow each detects a touch, and one consequence of that.
Resistive: two layers are pressed together by the touch. Resistive can be used with a stylus, a finger or a gloved hand. Capacitive: a finger changes the electric field on the screen. Capacitive needs a conductive touch (not an ordinary glove) but supports multi-touch such as pinch to zoom.
Common mistakeSaying one is "better". Say how each works.
Q5 Explain 4 marks A school buys a printer for 30 teachers who print hundreds of black-and-white pages a day. Explain whether a laser printer or an inkjet printer is more suitable.
ReminderChoose one, then give reasons about speed and volume.
A laser printer is more suitable. It prints at high speed, so large volumes are quick. It is better for high-volume printing because toner lasts for many pages. An inkjet prints more slowly and its ink would need replacing more often, but is better for quality photos.
Common mistakeChoosing without linking to the scenario (speed and volume).

Top tips

  • Sensors measure; actuators act. Name the actual sensor, not just "sensor".
  • Sensors capture analogue data. An ADC converts it to digital.
  • Match the sensor to what is measured: light, proximity, pH, moisture, temperature and so on.
  • Explain devices by how they work, not only by name.
  • For "most suitable", link your choice to the scenario (speed, volume, quality).
