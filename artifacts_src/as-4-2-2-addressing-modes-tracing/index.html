This page in five sentences

The addressing mode says how the processor finds the data an instruction uses. With immediate addressing the operand is the data (LDM #5); with direct addressing the operand is the address of the data (LDD 100); with indirect addressing the operand is the address of a location that holds the address of the data (LDI 100); with indexed addressing the address is the operand plus the contents of the index register IX (LDX 100); with relative addressing the operand is an offset from the address of the current instruction. Exam questions give a memory table and ask for the ACC after a few instructions, or ask you to trace a program in a table. Work one instruction at a time and write down exactly which address you used. Every trace row needs the value of the ACC or the memory location that changed.

1 · The addressing modes

ModeExampleHow the data is found
ImmediateLDM #5The operand is the number itself: ACC ← 5
DirectLDD 100The operand is the address of the data: ACC ← contents of 100
IndirectLDI 100The address to be used is at the given address: the contents of 100 are an address, and ACC ← the contents of that address
IndexedLDX 100Form the address from the operand + the contents of IX: ACC ← contents of (100 + IX)
RelativeJMP +3The address is an offset number of locations away, relative to the address of the current instruction

Worked example with memory 100: 101, 101: 67, 102: 104, 103: 100, 104: 68. LDM #103 gives 103. LDD 102 gives the contents of 102: 104. LDI 103: location 103 holds 100, so the address used is 100, which holds 101: ACC = 101.

Similarity between direct and indexed: both load the contents of an address into the accumulator. Difference: direct uses the address in the operand; indexed adds the contents of IX to the operand and uses the data at that calculated address.

2 · Tracing a program

  1. List the instructions in address order, and the starting contents of memory, ACC and IX.
  2. Execute one instruction at a time, starting at the first. Write the instruction's address in the first column.
  3. Record the new ACC, the memory location or IX that changes, and any output on that row.
  4. For CMP compare the ACC with the operand; JPE jumps only if equal, JPN only if not equal; otherwise carry on with the next instruction. END stops.
  5. Check the jumps: a loop traces the same instruction addresses again with new values.

The Cambridge instruction set also includes SUB, DEC, IN, OUT (outputs the ASCII character for the ACC value), MOV IX and LDR #n (loads IX). The table is printed on the paper.

Common ways to lose marks

  • Using the operand of LDI as the data. Look it up twice: first the address, then the data.
  • Forgetting to add IX for LDX.
  • Writing the wrong address in the first column when a jump is taken.
  • Recording a value in memory when the instruction only changes the ACC.
  • Treating CMP as changing the ACC. It only compares.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

An array in a program

Indexed addressing is how a loop moves through array elements: the base address stays in the instruction and IX moves along by one each time.

Exam use: LDX with INC IX.

A pointer to a record

A pointer holds the address of the data, not the data. Following it is indirect addressing.

Exam use: indirect addressing.

A program that moves in memory

Relative addressing lets code jump 'three instructions back' wherever it is loaded, so it still works if the program is moved.

Exam use: relative addressing.

Debugging with a trace

Writing down every register after each instruction is how you find where a value goes wrong.

Exam use: tracing.

A constant in a program

Typing a number like #5 directly into the instruction is immediate addressing: no memory lookup is needed.

Exam use: immediate addressing.

Top tips

  • LDM: data. LDD: address. LDI: address of address. Say it in that order.
  • LDX: operand plus IX. Show the sum.
  • Trace one instruction per row. Write the instruction address first.
  • CMP never changes ACC. It sets what JPE and JPN test.
  • Check memory after STO. It changes the location, not the ACC.
  • Loops repeat addresses. Rows return to the earlier instruction address.
