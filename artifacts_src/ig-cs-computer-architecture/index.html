3.1 Computer Architecture

The CPU, the components inside a Von Neumann CPU, the fetch–decode–execute cycle, cores, cache and clock, the instruction set and embedded systems.

The big idea

The CPU processes every instruction and piece of data a computer uses. It does this with a set of registers, units and buses in a repeating fetch–decode–execute cycle, and its speed depends on its cores, cache and clock.

3.1 Computer architecture

The CPU and the microprocessor

The central processing unit (CPU) processes the instructions and data that are input into the computer, so that the result can be output. A microprocessor is a type of integrated circuit on a single chip: a CPU built on one chip.

Inside the CPU: Von Neumann architecture

In a Von Neumann computer, instructions and data are stored together in the same memory (RAM), as binary, and the CPU fetches both from there.

A register is a tiny, very fast storage location inside the CPU. A bus is a set of wires that carries bits between parts of the computer.

The fetch–decode–execute (FDE) cycle

The CPU repeats this cycle for every instruction in a program.

Fetch

  1. The address in the PC is copied to the MAR.
  2. The PC is incremented so it points at the next instruction.
  3. The address goes along the address bus; the control bus sends a read signal; the instruction comes back along the data bus into the MDR.
  4. The instruction is copied from the MDR to the CIR.

Decode

The control unit decodes the instruction in the CIR, working out what it means using the CPU's instruction set.

Execute

The instruction is carried out. Arithmetic or logic goes to the ALU and the result is stored in the ACC; or data is fetched from or stored to memory using the buses. Then the cycle starts again.

Core, cache and clock

Cores

A core is a processing unit that can run its own FDE cycle. More cores means more instructions can be processed at the same time, but only if the software can share its work between cores.

Cache

Cache is a small amount of very fast memory close to the CPU that keeps recently or frequently used instructions and data. A larger cache means fewer slower trips to RAM.

Clock

The clock sets the pace of the CPU. Clock speed is the number of cycles per second, measured in hertz. A 3 GHz clock gives 3 billion cycles per second, so a higher clock speed usually means more instructions per second.

Performance

Performance depends on all three: the number of cores, the size of the cache and the speed of the clock. One on its own does not decide it.

Instruction set

An instruction set is the list of all the commands that a CPU can process. Each command is machine code, binary the CPU understands directly. A program must be translated into the instruction set of the CPU that will run it.

Embedded systems

An embedded system is a computer system built into a larger device to perform one dedicated function, for example in domestic appliances (washing machines, microwaves), cars, security systems, lighting systems and vending machines. A general-purpose computer, such as a PC or laptop, performs many different functions.

6 · Multiple choice

Descriptions are kept general. Check current details before quoting specifics.

A washing machine

A small embedded system runs one program: it reads a water level sensor and a temperature sensor, then switches the motor, heater and valves on and off. Its instructions are fixed in ROM and nobody installs apps on it.

Exam use: the classic embedded system. Say "dedicated function" and contrast with a laptop.

A smartphone processor

A modern phone has a multi-core processor, cache and a high clock speed in one microprocessor. Games can use several cores at once; a simple alarm clock app cannot.

Exam use: a link between cores, cache and clock and performance, and why more cores do not always mean faster.

Car engine control

An embedded system inside the engine reads sensors many times a second and adjusts fuel and timing. It runs a fixed program in ROM.

Exam use: embedded systems are found in vehicles; they perform one dedicated function.

Why a faster clock gets hot

Raising the clock speed makes the CPU do more work each second, and it gives off more heat, so fast CPUs need heat sinks and fans.

Exam use: a reason why clock speed is not the only way to improve performance.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State the purpose of the CPU and what a microprocessor is.
ReminderProcess, then say what is processed. A microprocessor is on one chip.
The CPU processes instructions and data that are input so that the result can be output. A microprocessor is an integrated circuit on a single chip (a CPU on one chip).
Common mistakeCalling the CPU "the brain" without saying what it does. Say it processes instructions and data.
Q2 Describe 4 marks Describe the purpose of the MAR, the MDR, the PC and the ACC in a Von Neumann CPU.
ReminderOne mark per register. Say what each holds.
PC: holds the address of the next instruction to be fetched. MAR: holds the address in memory being read from or written to. MDR: holds the data or instruction just fetched from (or about to be written to) memory. ACC: holds the results of calculations from the ALU.
Common mistakeMixing up MAR and MDR. MAR = address; MDR = data.
Q3 Describe 5 marks Describe the fetch stage of the fetch–decode–execute cycle.
ReminderFollow the instruction's journey: PC, MAR, buses, MDR, CIR.
The address in the PC is copied to the MAR. The PC is incremented (to point to the next instruction). The address is sent along the address bus to RAM (with a read signal on the control bus). The instruction at that address is sent along the data bus to the MDR. The instruction is copied from the MDR to the CIR.
Common mistakeWriting that the PC "goes to the CIR". The PC holds an address, never the instruction.
Q4 Describe 3 marks Describe the decode and execute stages.
ReminderWho decodes? Where does the instruction come from? What happens in execute?
The control unit decodes the instruction held in the CIR (using the instruction set). In execute, the instruction is carried out, for example the ALU performs a calculation. The result is stored, for example in the ACC (or data is fetched from or stored in memory using the buses).
Common mistakeSaying the ALU decodes. The control unit decodes.
Q5 Explain 4 marks A user replaces their dual-core 2.4 GHz CPU with a quad-core 3.6 GHz CPU with more cache. Explain why the computer may now perform better.
ReminderExplain each of the three factors: core, clock, cache. The word "may": it depends on the software.
More cores means more instructions can be processed at the same time (if the software can use them). A higher clock speed means more FDE cycles per second, so more instructions are processed each second. A larger cache stores more frequently used instructions and data close to the CPU. So the CPU has to fetch from the slower RAM less often.
Common mistakeWriting "it is faster" without linking it to cycles, simultaneous instructions or fewer RAM accesses.
Q6 Describe 3 marks Describe what is meant by an embedded system and give two examples.
ReminderDedicated function, inside a larger device, and a contrast with a general-purpose computer.
A computer system built into a device to perform a dedicated (single) function, unlike a general-purpose computer that performs many functions. Examples: washing machine, car engine management, vending machine, security system (any two).
Common mistakeListing a laptop or a phone. Those are general-purpose.

Top tips

  • Registers hold things. PC: next address. MAR: address. MDR: data. CIR: current instruction. ACC: result.
  • Name the bus. Address bus for addresses, data bus for data and instructions, control bus for signals.
  • For FDE, follow the instruction's journey in order, naming each register.
  • The PC holds an address, never the instruction.
  • Performance: cores, cache, clock. Say what each does, not just "faster".
  • Embedded = one dedicated function. A phone or laptop is not an embedded system.
