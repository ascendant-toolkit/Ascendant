Getters and Setters

Coursebook: Chapter 20 · Further programming, section 20.1 Programming paradigms

What getters and setters do, why they exist, why a getter sometimes takes a position, and how to write them in Python and pseudocode; animations, labs and review questions.

This page in five sentences

A getter is a method that returns the value of a private attribute. A setter is a method that changes it, using a new value passed in as a parameter. Because attributes are private, getters and setters are the only way other code can read or change them. Most getters have no parameter and most setters have one. If the attribute holds several values, such as a list of cards, the getter and setter need an extra position parameter to say which one.

1 · The standard pattern

Python

class Pet:    # PetName : STRING    # YearBorn : INTEGER    def __init__(self, NewName, NewYear):        self.__PetName = NewName        self.__YearBorn = NewYear     def GetPetName(self):        return self.__PetName     def SetPetName(self, NewName):        self.__PetName = NewName

2 · Why a getter can have a parameter

A getter returns a value. If the attribute is a single value, there is only one thing it could return, so no parameter is needed. If the attribute holds many values, such as a list, the getter must be told which one.

Python

class Hand:    # Cards : ARRAY[0:4] OF Card    def __init__(self, Card1, Card2, Card3, Card4, Card5):        self.__Cards = [Card1, Card2, Card3, Card4, Card5]     def GetCard(self, Position):        return self.__Cards[Position]     def SetCard(self, Position, NewCard):        self.__Cards[Position] = NewCard

Pseudocode (exam style)

CLASS Hand  PRIVATE Cards : ARRAY[0:4] OF Card  PUBLIC FUNCTION GetCard(Position : INTEGER) RETURNS Card    RETURN Cards[Position]  ENDFUNCTION  PUBLIC PROCEDURE SetCard(Position : INTEGER, NewCard : Card)    Cards[Position] <- NewCard  ENDPROCEDUREENDCLASS

Here GetCard(2) returns the third card. The parameter is not a new value to store; it is an index that selects part of the attribute. The setter has two parameters, the position and the new value.

3 · Setters can check the value

def SetAge(self, NewAge):    if NewAge >= 0 and NewAge <= 40:        self.__Age = NewAge

4 · Quick rules

Getter

Return. Never print. Never change anything.

Setter

Assign. Never return. Replace the old value, or add to it, as the question says.

5 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A thermostat

Reading the temperature is a getter. Setting the target temperature is a setter, and it refuses values outside a safe range.

Exam use: a setter with validation.

A playlist

GetSong(position) returns the song at a position. SetSong(position, song) replaces it. Both need the position because the attribute holds many songs.

Exam use: getter and setter with a position.

A player profile

The profile page calls GetUsername() to show the name and SetUsername() when it is edited. The rest of the game never touches the stored value.

Exam use: getter reports, setter updates.

A medical appointment

A report calls GetDoctor() and GetDate(). A receptionist uses SetDate() to move the appointment. Reports never change the data.

Exam use: the report only reads; the setter changes.

Top tips

  • Getter: return. Never print, never assign.
  • Setter: assign. Never return. The new value is the parameter.
  • A parameter on a getter means a list. The parameter is the position, not a value to store.
  • Write only what is asked. The question names which getters and setters it wants.
  • Count marks. Each part of the method is a mark: header, self, return or assignment.
