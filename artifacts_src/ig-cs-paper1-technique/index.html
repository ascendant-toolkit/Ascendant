IGCSE Computer Science · 0478 · Exam technique

Paper 1 Computer Systems: Technique and Practice

How Paper 1 is built and marked, a plan for the 105 minutes, how to show working in number questions, what each diagram part earns, the misconceptions examiners flag, and fourteen real questions.

This part in five sentences

Paper 1 is a 75-mark written paper in 1 hour 45 minutes on Topics 1 to 6, made of short and structured questions that you answer on the question paper, with no calculator. About 60% of the marks are for knowledge (AO1) and about 20% each for applying it to a scenario (AO2) and for reasoned judgements (AO3), so most marks reward precise technical facts, and the rest reward applying them to the device in the question. The paper mixes one-mark recall with number work where you must show the working, diagrams where each labelled part earns a mark, and explain questions set in a scenario. The examiner reports keep naming the same causes of lost marks: vague wording, ignoring the context, and mixing up stages or devices. At 1.4 minutes a mark you have time to plan every answer, so aim to earn every mark on the short questions and then use the time on the 4-mark and 6-mark answers.

5 · Show the working

Paper 1 has no calculator, and many number questions award separate marks for working. The syllabus says calculations use 1024, not 1000, and that answers must be in the units asked for.

SkillWhat earns the working markWhat goes wrong
Binary additionThe carries shown, then each nibble correct, and for overflow: a 9th bit or a statement that the result is too big for 8 bitsThe reports say candidates who converted to denary, added and converted back did not show binary addition and lost the working mark
Denary to binaryWorking such as 128 + 32 + 8 + 4 + 2 + 1Writing the answer with nothing else
Binary or denary to hexadecimalSplit into nibbles, convert eachReading the whole byte as one number
Logical shiftEach bit moves; the end bit is lost; a 0 is added at the other end. Left shift multiplies, right shift divides"The value is increased" or "changed" is too vague for the effect
Two's complement"Flip and add" working, then the signReading a two's complement pattern as an ordinary positive number
File sizeBits = (image) pixels × colour depth, or (sound) sample rate × resolution × seconds; ÷ 8 for bytes; ÷ 1024 for each larger unitDividing by 1000, or stopping at bits when the question asks for KiB
Exam tipThe mark scheme for a three-mark conversion question commonly splits into two marks for stages of working and one for the answer. A correct answer with no working may still earn full marks, but a wrong answer with working keeps marks. Always write the working.

6 · Diagrams: what each correct part earns

DiagramParts that each earn a mark
Decode stage of the FDE cycle (4)The instruction goes from the MDR to the CIR/control unit; it travels along the data bus; the CIR is part of the control unit; the instruction is split into opcode and operand; the control unit decodes it using the instruction set
Retrieving a web page (5)URL sent from the browser to the DNS; DNS finds the matching IP address (passing it to the next DNS if it cannot); IP address returned to the browser; request sent from the browser to the web server; web page sent back; browser renders the HTML
Blockchain in a transaction (4)A digital ledger is used; the payment details are sent from the device to the ledger; the transaction is stored in a block with details such as a digital signature and time stamp; each block has a unique hash; the full block is added to the chain held on every device

The reports say few candidates drew the decode stage correctly; many drew the fetch or the execute stage. Some candidates also showed the request for the web page going from the DNS to the web server, when the browser sends it after receiving the IP address.

7 · Misconceptions the examiners have flagged

Wrong ideaWhat is correct
Secondary storage is only used when primary storage is fullIt stores data and programs permanently, so they are still there each time the device is switched on
The accumulator carries out calculationsIt stores the interim result of a calculation; the ALU does the calculation
Encryption stops data being stolenIt makes stolen data meaningless to the person who has it
JPEG is a type of compressionJPEG is a file format. The two types are lossy and lossless
Hexadecimal is for the benefit of the computerIt is a shorter representation of binary that is easier for people to read and write
A hard disk drive is the best storage for a phoneSolid state suits it: small, light, no moving parts, fast, cool, quiet, low power
The DNS sends the request for the page to the web serverThe DNS returns the IP address to the browser, which sends the request
Decode and execute are the sameDecode: the control unit splits the instruction into opcode and operand using the instruction set. Execute: the instruction is carried out

8 · Choosing a device and justifying it

Questions that set a device, such as a smart phone, a smartwatch or an automated plough, reward choices that fit it. For storage in a smart phone the mark scheme gives one mark for naming solid state, then three marks for reasons, each with its consequence:

ReasonConsequence for the phone
Small and thinIt fits easily inside the phone
LightIt does not make the phone heavy to carry
No moving partsDurable: the data is less likely to be lost if the phone is dropped
Fast read and writeFiles and software load quickly
Runs cool and quietThe phone does not get hot to hold, and does not spoil music or video with noise
Low powerIt does not drain the battery

9 · Common ways to lose marks

  • Confusing the stages of the fetch-decode-execute cycle, or naming a stage instead of a register or bus.
  • No working on number questions, or converting to denary when binary addition was asked for.
  • Vague wording: "faster", "better", "more secure", with no technical term.
  • Generic devices in a scenario.
  • Describing when asked to explain, or listing when asked for a description of how it helps.
  • Skipping the diagram: each labelled part is a mark and a diagram can be built from memory with arrows and labels.
  • Not reading "use only terms from the list".

6 · Multiple choice

These come from the Principal Examiner Reports for Cambridge IGCSE Computer Science, which describe what candidates actually wrote. The wording is ours.

Drawing fetch or execute instead of decode

Oct/Nov 2024, papers 11 and 13: asked what happens at the decode stage, many candidates described or drew the execute stage, and some the fetch stage. The mark scheme looks for the instruction going from the MDR to the CIR, the split into opcode and operand, and the control unit decoding with the instruction set.

Exam use: FDE questions: write the name of the stage at the top of your answer and check every point belongs to it.

Converting to denary to add

Oct/Nov 2024, papers 11 and 13: asked to add two binary values, some candidates converted both to denary, added, and converted back. The report says they did not show the working as binary addition, which is where a mark is given.

Exam use: 'add in binary' questions: write the numbers one above the other with a carries row.

Reading two's complement as plain binary

Oct/Nov 2024, paper 13: some candidates converted a two's complement value as though it were an ordinary positive binary number. The mark scheme gives a mark for working such as flip and add and a mark for the negative denary answer.

Exam use: if a question mentions two's complement, check the left-hand bit first.

The wrong direction for the request

Oct/Nov 2024, paper 12: some candidates drew the request for the web page going from the DNS to the web server. The DNS returns the IP address to the browser, and the browser then sends the request.

Exam use: diagram questions: put an arrow and a label on every step, and check the direction.

The accumulator does not calculate

Oct/Nov 2024, paper 12: a common misconception was that the accumulator carries out calculations. It stores the interim result of a calculation.

Exam use: CPU questions: link each register to what it stores, not to a process it does not perform.

A hard disk drive in a phone

Oct/Nov 2024, paper 11: the most common wrong answer for the most suitable storage in a smart phone was a hard disk drive. Solid state was accepted, with reasons such as small size, no moving parts and low power.

Exam use: 'most suitable' questions: pick the item that fits the device, then say why.

Written questions (reworded)

The wording, context and figures are our own, so they are safe to set as practice. The source paper is named for reference. Mark scheme points are in our own words. Open a question, plan an answer, then read the mark scheme points.

Based on Oct/Nov 2024 · 0478/11 · Q3(d) [3] Add these two 8-bit binary integers and show your working as binary addition: 01010100 and 01110100.
What the mark scheme wants
  • One mark for working that shows binary addition, for example the carries
  • One mark for each correct nibble: the answer is 11001000 (denary 84 + 116 = 200)
  • The report says candidates who converted to denary, added and converted back did not show binary addition
Plan

Write the numbers one above the other, add a carries row, and work from the right: 0+0, 0+0, 1+1 (0 carry 1), 0+0+1, 1+1 (0 carry 1), 0+1+1 (0 carry 1), 1+1+1 (1 carry 1), 0+0+1.

Based on Oct/Nov 2024 · 0478/13 · Q1(e) [2] The 8-bit two's complement binary integer 10011100 is stored. Convert it to a denary number and show your working.
What the mark scheme wants
  • One mark for correct working, for example flip the bits and add 1
  • One mark for the correct denary number: 10011100 flips to 01100011, adding 1 gives 01100100 = 100, so the answer is −100
  • The left-hand bit is 1, so the number is negative
Plan

Check the left-hand bit. It is 1, so flip and add. Do not read 10011100 as 156.

Based on Oct/Nov 2024 · 0478/12 · Q3(d) [3] A logical left shift of one place is performed on the binary integer 00110101. (i) Describe the shift. (ii) State the effect on the value.
What the mark scheme wants
  • (i) Two from: each bit moves one place to the left; the most significant bit is lost; a 0 is added as the new least significant bit
  • (ii) The value is multiplied by 2: 00110101 (53) becomes 01101010 (106)
  • The report says answers such as 'it increases' were too vague
Plan

Use the words moved, lost and added. For the effect, give the operation: multiplied by 2.

Based on May/June 2024 · 0478/12 · Q2(d) [3] A 24-bit colour image is 256 pixels wide and 128 pixels high. Calculate the file size in kibibytes (KiB). Show your working.
What the mark scheme wants
  • Up to two marks for stages of working, for example 256 × 128 = 32 768 pixels, then × 24 bits = 786 432 bits
  • ÷ 8 gives 98 304 bytes; ÷ 1024 gives the answer
  • One mark for the correct answer: 96 KiB
Plan

Pixels, then bits, then bytes, then KiB. Divide by 1024 for the last step, not 1000.

Based on Oct/Nov 2024 · 0478/12 · Q2(c) [3] A 16 second sound clip is recorded at a sample rate of 8192 Hz with a resolution of 16 bits. Calculate the file size in kibibytes (KiB). Show your working.
What the mark scheme wants
  • Up to two marks for stages of working: 8192 × 16 × 16 = 2 097 152 bits
  • ÷ 8 gives 262 144 bytes
  • ÷ 1024 gives the answer, one mark: 256 KiB
Plan

Sample rate × resolution × seconds gives bits. Then ÷ 8, then ÷ 1024.

Based on Oct/Nov 2024 · 0478/11 · Q4(a) [4] An email is split into data packets. Describe the structure of a data packet.
What the mark scheme wants
  • Any four from: the packet has three sections
  • A packet header, which contains data such as the destination address
  • A payload, which contains the main data of the email
  • A trailer, which contains data such as the error detection method
Plan

The report says some candidates listed what goes in the header instead of describing the structure. Name the three sections, then say what each holds.

Based on Oct/Nov 2024 · 0478/12 · Q5(b) [6] A barcode scanner sends stock data to a stock control system using serial simplex transmission. (i) Explain how data is sent using serial simplex. (ii) Explain why serial simplex is appropriate here.
What the mark scheme wants
  • (i) Three: bits are sent one at a time; down a single wire; in one direction only
  • (ii) Any three from: the stock system may be a long distance away, and serial is more reliable over distance
  • The data does not need to arrive quickly, and only small amounts are sent, so the speed of parallel is not needed
  • Bits arrive in order, so the data cannot be skewed, and there are fewer errors or less interference
  • No reply is needed, so half- or full-duplex is not necessary
Plan

Part (i) is how; part (ii) is why. Put the stock system and the one-way data into the reasons.

Based on Oct/Nov 2024 · 0478/11 · Q5(b) [3] Describe what happens at the decode stage of the fetch-decode-execute cycle.
What the mark scheme wants
  • Any three from: the control unit or CIR receives the instruction from the MDR, using the data bus
  • The instruction is split into opcode and operand
  • The control unit decodes the instruction using the instruction set
Plan

The report says many candidates described the execute stage. Start with 'The instruction goes from the MDR to the CIR', and stay at the decode stage.

Based on Oct/Nov 2024 · 0478/11 · Q5(e) [2] A user changes their dual core CPU with a clock speed of 2.0 GHz to a dual core CPU with a clock speed of 3.0 GHz. Explain the effect on the performance of the CPU.
What the mark scheme wants
  • It can now carry out more instructions, or more fetch-decode-execute cycles, each second
  • So the performance of the CPU increases
Plan

The report says few gave a technically correct reason. Say what changes (more instructions per second) and the result (performance rises). Name the direction.

Based on Oct/Nov 2024 · 0478/13 · Q3(b) [4] Draw a labelled diagram to show what happens at the decode stage of the fetch-decode-execute cycle.
What the mark scheme wants
  • The instruction or data is sent from the MDR to the CIR or control unit, using the data bus
  • The CIR is shown as part of the control unit
  • The instruction is separated into operand and opcode
  • The control unit decodes the instruction using the instruction set
Plan

Draw MDR → (data bus) → CIR inside the CU, then a box that splits into opcode and operand, with the instruction set labelled. Each labelled part is a mark.

Based on Oct/Nov 2024 · 0478/12 · Q7(d) [5] Draw and annotate a diagram to show how a web page is found and retrieved when a user enters a URL into a browser.
What the mark scheme wants
  • The URL is sent from the browser to the DNS
  • The DNS finds the matching IP address, passing the URL to the next DNS if it is not found
  • The IP address is returned to the browser
  • The request for the page is sent from the browser to the web server
  • The web page or HTML files are sent back to the browser, which renders the HTML
Plan

Three boxes (browser, DNS, web server) and arrows labelled in order. The report says some candidates sent the request from the DNS to the server.

Based on Oct/Nov 2024 · 0478/11 · Q8 [4] Draw and annotate a diagram to show how blockchain is used when a customer pays for goods online.
What the mark scheme wants
  • A digital ledger is used and the customer's device sends the payment data to it, encrypted
  • The payment is recorded, with details such as digital signature, time and date
  • The transaction is stored in a block, and a block can hold several transactions
  • Each block has a block hash or unique identifier
  • When the block is full it is added to the blockchain held on every device
Plan

The report says very few candidates drew this correctly. Label the device, the ledger, a block with its hash, and the chain on every device.

Based on Oct/Nov 2024 · 0478/11 · Q2(c) [6] A smart phone has primary and secondary storage. (i) Explain the purpose of the secondary storage. (ii) Name the most suitable type of secondary storage for the phone and justify your choice.
What the mark scheme wants
  • (i) Two from: to store data and files permanently, so they do not have to be entered or installed each time the phone is switched on
  • To let software be downloaded and installed, or to store the user's files, or to create virtual memory
  • (ii) One mark for solid state, then three from: small, so it fits in the phone; light; no moving parts, so durable if dropped
  • Fast read and write, so files load quickly; runs cool; quiet; low power, so it does not drain the battery
Plan

The report says some thought secondary storage was only used when primary storage is full. For (ii) the common wrong answer was a hard disk drive. Name solid state, then give reasons with consequences.

Based on Oct/Nov 2024 · 0478/13 · Q5(b) [3] An automated irrigation system uses a microprocessor. Describe the role of the microprocessor in the system.
What the mark scheme wants
  • It receives data from the sensors
  • It analyses the data, for example by checking whether it is within or outside a range
  • It sends signals to trigger actions based on the data
Plan

Only the role of the microprocessor is asked for. The report says some candidates described the whole system.

Top tips

  • Show the working. Binary addition with carries, flip and add, bits then bytes then KiB.
  • Use 1024, not 1000. For every file size unit.
  • Name the stage. Decode, not fetch or execute.
  • Arrows and labels. Every part of a diagram is a mark.
  • Fit the device. Phone: touchscreen, SSD. Not a mouse or an HDD.
  • Say which way it changes. More instructions per second, not 'faster'.
  • Read 'use only terms from the list'. And note if terms can be reused.
