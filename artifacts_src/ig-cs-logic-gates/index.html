Logic Gates

The standard symbols, functions and truth tables for NOT, AND, OR, NAND, NOR and XOR gates.

The big idea

A logic gate turns binary inputs into one binary output by a fixed rule. Learn the six gates, their symbols and their truth tables.

10.1 Logic gates

Boolean logic works with two values only: 1 (true, on) and 0 (false, off). A logic gate is an electronic component that takes one or two binary inputs and produces one binary output, following a fixed rule. Computers are built from millions of gates.

A truth table lists every possible combination of inputs and the output for each. With two inputs there are 2² = 4 rows, listed in binary counting order: 00, 01, 10, 11.

Memory aids

  • AND: both. OR: at least one. XOR: exactly one.
  • NAND is the opposite of AND: the output column 0 0 0 1 becomes 1 1 1 0.
  • NOR is the opposite of OR: the output column 0 1 1 1 becomes 1 0 0 0.
  • AND has a single 1 in its output column; OR has three; NAND has three; NOR has one; XOR has two.
Do not confuse OR and XOROR is 1 when the inputs are 1 and 1. XOR is 0 when the inputs are 1 and 1, because it needs the inputs to be different.

Gates and switches

An AND gate behaves like two switches in series (both must be closed for the lamp to light). An OR gate behaves like two switches in parallel (either one lights the lamp). A NOT gate is an inverter.

4 · Multiple choice

Descriptions are kept general. Check current details before quoting specifics.

Two light switches on a staircase

Either switch changes the light. If it is on, flipping either switch turns it off; if it is off, flipping either switch turns it on.

Exam use: an XOR situation: the light is on when the switches are in different positions.

A safe with two keys

The safe opens only if key 1 and key 2 are turned.

Exam use: an AND gate: both inputs must be 1.

A car warning chime

The chime sounds if the driver's door is open or the passenger's door is open.

Exam use: an OR gate.

A lift door

The door must close if the doorway is not blocked.

Exam use: a NOT gate inverts a signal.

A security light

A light that comes on when it is dark and movement is detected.

Exam use: AND combining two sensors.

Inside a processor

Combinations of NAND and NOR gates make adders, memory and control circuits. A NAND gate on its own can build every other gate.

Exam use: gates are the building blocks of all digital electronics.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State the output of (a) an AND gate and (b) a NOR gate when both inputs are 1.
ReminderWork from the rule.
(a) AND with inputs 1 and 1: output 1 (b) NOR with inputs 1 and 1: output 0
Common mistakeMixing up NOR with OR. NOR is the inverse of OR.
Q2 Describe 2 marks Describe the function of an XOR gate.
ReminderDifferent inputs.
The output is 1 when the two inputs are different (one input is 1 and the other is 0). The output is 0 when the inputs are the same.
Common mistakeDescribing OR: for XOR, inputs of 1 and 1 give 0.
Q3 Complete 4 marks Complete the truth table for a NAND gate with inputs A and B: (0,0), (0,1), (1,0), (1,1).
ReminderNOT of AND.
(0,0) gives 1 (0,1) gives 1 (1,0) gives 1 (1,1) gives 0
Common mistakeWriting the AND column (0 0 0 1) instead of its inverse.
Q4 Identify 3 marks A gate has the symbol . Name the gate and state its output for inputs of 0 and 0.
ReminderCurved back, with a bubble.
The gate is a NOR gate. Both inputs are 0, so the OR result would be 0... ...which the NOR inverts: the output is 1.
Common mistakeNaming it OR because of the shape. The bubble means NOR.
Q5 State 2 marks State how many rows are in a truth table for a gate with two inputs, and why.
Reminder2 to the power of the number of inputs.
4 rows Each of the two inputs can be 0 or 1, giving 2 × 2 = 4 combinations (2²).
Common mistakeSaying 2 rows.
Q6 State 2 marks A gate outputs 1 only when its two inputs are different. Name the gate.
ReminderXOR.
XOR (exclusive OR) It outputs 1 for 0,1 and 1,0 and outputs 0 for 0,0 and 1,1.
Common mistakeAnswering OR.
Q7 Explain 2 marks Explain why the NOT gate has a different number of inputs from the other gates.
ReminderOne input.
The NOT gate has a single input and simply inverts it. All the other gates compare two inputs to decide the output.
Common mistakeSaying NOT is "broken".
Q8 State 3 marks State the output of (a) a NOT gate with input 0, (b) an OR gate with inputs 1 and 1, (c) an XOR gate with inputs 1 and 1.
ReminderApply each rule.
(a) 1 (b) 1 (c) 0
Common mistakeGiving 1 for the XOR.

Top tips

  • Learn the six output columns for inputs 00, 01, 10, 11: AND 0001, OR 0111, NAND 1110, NOR 1000, XOR 0110. NOT: 0→1, 1→0.
  • The bubble means NOT. NAND, NOR and NOT have one.
  • XOR needs different inputs. 1 and 1 gives 0.
  • A two-input truth table has 4 rows. List them in order: 00, 01, 10, 11.
  • NOT is the only gate with one input.
