Von Neumann Model, Registers and Buses

Coursebook: Chapter 4 · Processor fundamentals · section 4.1 Central Processing Unit architecture

The Von Neumann model, the stored program concept, special and general purpose registers and the address, data and control buses, with animations, a bus-width lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

The Von Neumann model has a processor (CPU) made of an Arithmetic and Logic Unit (ALU), a Control Unit (CU), registers and a system clock, connected by buses to main memory (the Immediate Access Store, IAS) and to input and output. Its key idea is the stored program concept: instructions and data are stored in the same memory space (main memory) and the CPU fetches instructions one at a time. Registers are tiny, very fast stores inside the CPU: special purpose registers have one defined role (PC, MAR, MDR, CIR, IX, SR) and general purpose registers (such as the Accumulator, ACC) hold data during operations. The address bus carries addresses, the data bus carries data and instructions, and the control bus carries control signals such as read, write, timing and interrupt. Exam answers state each part's purpose in one precise sentence.

1 · The components

ComponentPurpose
ALUPerforms arithmetic (add, subtract) and logical (AND, OR, shift, compare) operations
Control Unit (CU)Reads an instruction from the address in the PC, decodes it, coordinates and synchronises the other components, manages execution of instructions and sends and receives control signals along the control bus
System clockCreates timing signals (sent on the control bus) that synchronise all operations; its speed (clock speed) sets how many fetch-execute cycles can run per second
RegistersFast storage locations inside the CPU
Main memory (IAS)Holds all the instructions, data and programs currently in use; volatile; fast access
BusesSets of parallel wires that carry signals between components

The stored program concept: instructions and data are held together in main memory, in the same memory space, and are fetched and executed in sequence by the CPU. The program does not have to be rewired for each task: loading a different program into memory changes what the computer does.

2 · Registers

RegisterPurposeType
Program Counter (PC)Holds the address of the next instruction to be fetchedSpecial
Memory Address Register (MAR)Holds the address of the memory location currently being read from or written toSpecial
Memory Data Register (MDR)Holds the data or instruction read from the address in the MAR, or the data to be written to itSpecial
Current Instruction Register (CIR)Holds the instruction currently being decoded and executedSpecial
Index Register (IX)Holds a number that is added to the operand to form the address of the data (indexed addressing)Special
Status Register (SR)Holds bits (flags) that are set or cleared by the results of arithmetic and logic operations, or by interrupts, and can be checked to change the instruction sequenceSpecial
Accumulator (ACC)Holds the intermediate results of arithmetic and logical operationsGeneral

Special purpose registers have a specified role and hold the state of the program's execution; general purpose registers can be used for whatever the programmer defines and hold data during operations.

3 · The three buses

BusCarriesDirectionWidth affects
Address busThe address from the MAROne way, from the CPU to memoryHow many memory locations can be addressed: 2n for n lines
Data busData and instructions, to and from the MDRBoth waysHow much data is transferred at the same time
Control busControl signals: read, write, timing signals from the clock, interrupt, bus requestsBoth waysNot a performance factor

Common ways to lose marks

  • Saying the PC "stores the next instruction". It stores the address of the next instruction (the corrected statement in the exam).
  • Saying the CU sends signals "on the data bus". They travel on the control bus.
  • Saying the MDR "transfers data to the address in the MAR". It holds the data read from, or to be written to, that address.
  • Describing the clock only as "making the computer faster". Say it synchronises operations with timing signals.
  • Confusing special and general purpose registers: special purpose have one defined role.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

The 4 GB limit on 32-bit systems

A 32-bit address bus can address 2^32 locations, which is 4 GB. That is why older 32-bit computers could not use more memory.

Exam use: address bus width limits memory.

Buying a computer: '64-bit'

A wider data bus moves more data per step, so the processor spends less time waiting for data.

Exam use: data bus width.

Running a different app

The same hardware runs a game or a spreadsheet because the program is stored in memory, not built into the circuits.

Exam use: stored program concept.

A phone's clock speed

A 3 GHz clock makes three billion timing signals each second; each fetch-execute stage waits for these signals.

Exam use: the clock synchronises operations.

A calculator's overflow warning

The status register holds a flag that is set when an arithmetic result is too large, and the program can check it.

Exam use: status register flags.

Top tips

  • PC holds an address. Never 'the next instruction'.
  • MAR address, MDR data. The MDR holds data read from, or to be written to, that address.
  • CU uses the control bus. Not the data bus.
  • Special: one role. General: any role. Give the contrast.
  • Same memory space. The stored program concept in four words.
  • 2^n for n address lines. Wider address bus, more locations.
