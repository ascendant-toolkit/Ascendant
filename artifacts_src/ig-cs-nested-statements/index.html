Nested Statements

Selection and iteration placed inside each other, up to three levels deep.

The big idea

A nested statement is a structure inside another structure. The inner one only runs when the outer one reaches it, and it runs again each time the outer one does.

8.1.5 Nested statements

A statement is nested when one structure is placed completely inside another: an IF inside an IF, a loop inside a loop, an IF inside a loop, and so on. Nesting lets a program make follow-up decisions and repeat whole blocks of work.

Nested selection

An IF inside another IF. The inner condition is only tested if the program reaches it through the outer one. Each IF needs its own ENDIF.

A CASE statement can be nested too, and an IF can sit inside one of its branches.

Selection inside iteration

An IF inside a loop makes a decision about every item. This is how you count passes, check each input or find the highest value.

Nested iteration

A loop inside a loop. For each single repeat of the outer loop, the inner loop runs all of its repeats. Each loop needs its own counter.

How many times?For two FOR loops with fixed limits, multiply: outer repeats × inner repeats. 3 × 3 = 9.

Keeping it readable

Indent each level further than the one outside it, and close structures in reverse order: the last one opened is the first one closed. Structures may sit inside each other but must never cross.

Three levels is the limitIn the exam you will not be asked to write more than three levels of nested statements.
Nested IF or AND?IF A THEN IF B with no ELSE does the same job as IF A AND B. Use a nested IF when each level needs its own ELSE or its own message. In Python, elif keeps a chain of tests flat.

A cash machine

The machine first checks the PIN. Only if it is correct does it check whether there is enough money for the withdrawal.

Exam use: nested selection: the inner test is only reached when the outer test is TRUE.

A school report run

For every student, the program goes through every subject, then prints that student's average.

Exam use: nested iteration: outer loop for students, inner loop for subjects.

Checking a login form

Exam use: selection inside a condition-controlled loop.

Q1 State 2 marks State what is meant by a nested statement and give one example.
ReminderSay what is inside what.
A statement / structure placed inside another one Example: an IF inside a loop (or IF inside IF, or loop inside loop)
Common mistakeGiving two separate IF statements one after the other. That is not nesting.
Q2 State 3 marks State the output of this code when X is 12 and Y is 3.
IF X > 10  THEN    IF Y > 5      THEN        OUTPUT "A"      ELSE        OUTPUT "B"    ENDIF  ELSE    OUTPUT "C"ENDIF
ReminderTest the outer condition first.
X > 10 is TRUE, so the inner IF is tested Y > 5 is FALSE, so the inner ELSE runs Output: B
Common mistakeOutputting C. The outer ELSE only runs when X > 10 is FALSE.
Q3 State 2 marks State how many times the word "Hi" is output, and show how you worked it out.
FOR A ← 1 TO 4    FOR B ← 1 TO 5        OUTPUT "Hi"    NEXT BNEXT A
ReminderMultiply the repeats.
4 × 5 = 20 times
Common mistakeAdding 4 + 5. The inner loop runs fully for each outer repeat.
Q4 Write 4 marks A mark is stored in Mark. Write pseudocode to output "Invalid" if it is below 0 or above 100. Otherwise output "Pass" for 50 or more and "Fail" for less than 50.
ReminderValidate on the outer IF, grade on the inner IF.
IF Mark < 0 OR Mark > 100 THEN OUTPUT "Invalid" inner IF Mark >= 50 inside the ELSE, outputting "Pass" / "Fail" both IFs closed with ENDIF in the right places
IF Mark < 0 OR Mark > 100  THEN    OUTPUT "Invalid"  ELSE    IF Mark >= 50      THEN        OUTPUT "Pass"      ELSE        OUTPUT "Fail"    ENDIFENDIF
Common mistakeWriting AND in the first test. No number is both below 0 and above 100.
Q5 Write 5 marks Write pseudocode to input 30 numbers. Count how many are positive and how many are negative (ignore zeros), then output both counts.
ReminderSet both counts to 0 before the loop.
Positive ← 0 and Negative ← 0 before the loop loop 30 times with INPUT inside IF Number > 0, add 1 to Positive test for Number < 0 and add 1 to Negative OUTPUT both after the loop
Positive ← 0Negative ← 0FOR Count ← 1 TO 30    INPUT Number    IF Number > 0      THEN        Positive ← Positive + 1      ELSE        IF Number < 0          THEN            Negative ← Negative + 1        ENDIF    ENDIFNEXT CountOUTPUT Positive, Negative
Common mistakeUsing a plain ELSE for negatives, which also counts the zeros.
Q6 Complete 4 marks Give the values output by this code, in order.
FOR A ← 1 TO 3    FOR B ← 1 TO A        OUTPUT A * B    NEXT BNEXT A
ReminderWrite down A and B for every inner repeat.
A = 1: B runs 1 to 1, output 1 A = 2: outputs 2, 4 A = 3: outputs 3, 6, 9 full order: 1, 2, 4, 3, 6, 9
Common mistakeRunning B from 1 to 3 every time. Its end value is A.
Q7 Write 6 marks There are 5 students and each takes 3 tests. Write pseudocode to input the marks and output the total for each student.
ReminderAsk where Total ← 0 must go.
outer loop for 5 students Total ← 0 inside the outer loop inner loop for 3 tests INPUT Mark inside the inner loop Total ← Total + Mark inside the inner loop OUTPUT Total after the inner loop but inside the outer loop
FOR Student ← 1 TO 5    Total ← 0    FOR Test ← 1 TO 3        INPUT Mark        Total ← Total + Mark    NEXT Test    OUTPUT TotalNEXT Student
Common mistakeSetting Total ← 0 before the outer loop, so totals carry over between students.
Q8 Explain 3 marks The code below should output 12 values but does not run correctly. Identify the error, explain why it is wrong and correct it.
FOR X ← 1 TO 3    FOR Y ← 1 TO 4        OUTPUT X + Y    NEXT XNEXT Y
ReminderWhich loop was opened last?
NEXT X and NEXT Y are the wrong way round the inner loop (Y) must be closed before the outer loop (X), because loops cannot cross correct order: NEXT Y then NEXT X
Common mistakeChanging the loop limits. The limits are fine; the order of the NEXT lines is not.
Q9 Write 6 marks Write pseudocode to input the ages of 100 visitors. Each age must be from 0 to 120; ask again until it is. Count the visitors aged under 12 and output the count.
ReminderThis needs three levels: FOR, then REPEAT, and an IF.
Children ← 0 before the loop FOR loop that repeats 100 times REPEAT with INPUT Age inside UNTIL Age >= 0 AND Age <= 120 IF Age < 12 add 1 to Children, inside the FOR loop but after the REPEAT OUTPUT Children after the FOR loop
Children ← 0FOR Visitor ← 1 TO 100    REPEAT        INPUT Age    UNTIL Age >= 0 AND Age <= 120    IF Age < 12      THEN        Children ← Children + 1    ENDIFNEXT VisitorOUTPUT Children
Common mistakeCounting inside the REPEAT loop, before the age has been checked.

Top tips

  • Indent every level. The indentation should show which structure each line belongs to.
  • Close in reverse order. The structure opened last is closed first.
  • Every IF needs its own ENDIF, every FOR its own NEXT with the matching counter.
  • Two nested FOR loops: multiply the repeats (unless the inner limits change).
  • Place totals carefully. Reset inside the outer loop if each group needs its own total.
  • Trace the outer counter slowly and the inner counter quickly. Add a trace table column for each.
