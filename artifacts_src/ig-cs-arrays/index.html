Arrays

One-dimensional and two-dimensional arrays, using variables as indexes, and writing to and reading from arrays with iteration.

The big idea

An array stores many values of one data type under a single name, and a loop with an index can process them all. A 2D array is a table that needs two indexes and nested loops.

8.2 Arrays

An array is a fixed-length structure that holds several values of the same data type under one name. Each value is called an element and is reached by its index, a consecutive whole number. Arrays let a program store 30 marks without 30 separate variables, and process them with a loop.

One-dimensional (1D) arrays

A 1D array is a list. It is declared with a name, a lower and upper bound, and a data type. The index goes in square brackets.

Index12345
Marks6245785091

Here Marks[3] is 78. The index can be a number or a variable, so Marks[Index] uses the current value of Index. This is what makes loops over arrays work.

First indexIn pseudocode the lower bound is usually 1, but in Python (and many languages) the first index is 0. The exam says which to use; the lower bound is stated in the declaration. Using an index outside the bounds is an error.

Writing to and reading from an array with iteration

A FOR loop is ideal, because the index counts through the elements. The first loop writes values into the array; the second reads them out.

The same pattern gives a total, a count or a maximum (see 7.3): replace the INPUT or OUTPUT with the calculation you need.

Two-dimensional (2D) arrays

A 2D array is a table with rows and columns. It needs two indexes: Array[Row, Column]. It is declared with two ranges.

Col 1Col 2Col 3Col 4
Row 14729
Row 25183
Row 36247

Here Amount[2,3] is 8 (row 2, column 3). To visit every cell you use nested iteration: an outer loop for the rows and an inner loop for the columns.

Why use arrays?

  • Many related values share one name, which keeps programs shorter and easier to read.
  • A loop with an index variable can process all of them, however many there are.
  • Data can be stored, searched and sorted (see 7.3).

Common mistakes

  • Index out of range: for example Marks[6] in a 5-element array.
  • Off by one: the loop runs 0 to 5 when the array is indexed 1 to 5 (or the reverse).
  • Using the index where the element is needed: Total ← Total + Index instead of Marks[Index].
  • Forgetting that the array's size is fixed when it is declared.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State what is meant by an array.
ReminderFixed size, same type, index.
A data structure that stores multiple values (elements) of the same data type under one name, with each element accessed using an index.
Common mistakeDescribing it only as "a list".
Q2 Write 2 marks Write pseudocode to declare a 1D array to store the names of 30 students.
ReminderDECLARE name : ARRAY[l:u] OF type.
DECLARE StudentNames : ARRAY[1:30] OF STRING (the lower and upper bound, and the data type, are correct)
Common mistakeUsing INTEGER for names, or writing the size without the index range.
Q3 Write 4 marks Write pseudocode to input 10 numbers into the array Numbers[1:10], then output them all.
ReminderTwo FOR loops with an index variable.
FOR Index ← 1 TO 10 INPUT Numbers[Index] NEXT Index A second loop (or the same loop correctly) outputting Numbers[Index] for each index
Common mistakeUsing a different array name inside the loop.
Q4 Write 4 marks The array Marks[1:30] holds test marks. Write pseudocode to output the total and the average of the marks.
ReminderTotal ← 0, loop adding Marks[Index].
Total ← 0 before the loop FOR Index ← 1 TO 30 with Total ← Total + Marks[Index] Average ← Total / 30 OUTPUT Total and OUTPUT Average (after the loop)
Common mistakeAdding Index instead of Marks[Index].
Q5 Explain 2 marks Explain why a 2D array needs nested loops to read every element.
ReminderTwo indexes.
A 2D array has two indexes (a row and a column). One loop steps through the rows and a loop inside it steps through the columns for each row.
Common mistakeSaying "because it is bigger".
Q6 Write 5 marks Seats[1:5, 1:8] is a 2D array of BOOLEAN (TRUE if a seat is taken). Write pseudocode to count and output the number of seats that are taken.
ReminderNested FOR loops and a count.
Count ← 0 FOR Row ← 1 TO 5 FOR Column ← 1 TO 8 IF Seats[Row, Column] = TRUE THEN Count ← Count + 1 OUTPUT Count after both loops
Common mistakePutting Count ← 0 inside the loops.
Q7 State 2 marks The array Colours[1:4] holds "red", "blue", "green", "pink". State the value of (a) Colours[2] and (b) Colours[Index + 1] when Index is 3.
ReminderIndex starts at 1.
(a) "blue" (b) "pink" (Colours[4])
Common mistakeCounting from 0 when the array starts at 1.
Q8 Explain 2 marks A program has the statement Marks[11] ← 50 but Marks is declared ARRAY[1:10]. Explain the error.
ReminderOutside the bounds.
The index 11 is outside the range of the array (1 to 10), so there is no element to store the value in (an out-of-range error).
Common mistakeSaying the array is "full".

Top tips

  • An array holds many values of one type under one name, reached by an index.
  • DECLARE Name : ARRAY[1:30] OF STRING gives the bounds and type.
  • Use a FOR loop with an index variable: Marks[Index].
  • 2D arrays: two indexes, [Row, Column], and nested loops.
  • Do not mix up the index and the element. Add Marks[Index], not Index.
  • Check the first index (0 or 1) and the upper bound.
