Validation and Verification

The need for validation and verification, six validation checks, check digits, visual checks and double entry.

The big idea

Validation checks that data is reasonable; verification checks that it was entered correctly. Valid data can still be wrong, which is why both are used.

7.4 Validation and verification

People make mistakes when they type data in. Programs use two kinds of check to catch them: validation checks that the data is reasonable, and verification checks that the data was entered correctly.

Validation

Validation is an automatic check by the program that the data entered is sensible and meets rules. It cannot prove the data is correct: an age of 52 passes a range check even if the person meant 25. If the data fails, the program should show an error message and ask again.

Validation checkWhat it checksExample
Range checkThe value is between a lowest and highest allowed value.Month must be 1 to 12. Mark must be 0 to 100.
Length checkThe data has the right number of characters.Password must be at least 8 characters. A phone number must have 10 digits.
Type checkThe data is the right data type.Age must be an integer, with no letters.
Presence checkThe field has not been left empty.The email box must contain something.
Format checkThe data matches a set pattern.A date as DD/MM/YYYY, or a product code of two letters then three digits (AB123).
Check digitThe last digit is calculated from the other digits. It is recalculated when the number is entered and must match.The last digit of a barcode or ISBN.

Check digits

A check digit is an extra digit added to the end of a number. It is calculated from the other digits using a formula. When the number is entered again, the calculation is repeated and the result compared with the check digit. If they differ, the number was entered wrongly. Check digits detect mistakes such as a mistyped digit or two digits swapped.

Example method (ISBN-13): multiply the first 12 digits by 1, 3, 1, 3 ... alternately, add the results, and the check digit is 10 minus the last digit of the total (or 0 if that gives 10).

Digit978030640615
Weight131313131313
Product9218030612018115

Total = 93. The last digit of the total is 3, so the check digit is 10 − 3 = 7. The ISBN is 9780306406157.

Verification

Verification checks that the data entered matches the original source or what the user intended. It does not check that the data is sensible.

Visual check

The user reads what they typed on the screen and compares it with the original (for example a paper form). Slow, and people can miss mistakes.

Double entry check

The data is entered twice (for example a password or email address) and the program compares the two entries. If they differ, the user must start again.

Validation against verification

ValidationVerification
Checks that…the data is reasonable and follows the rulesthe data was entered correctly (matches the source)

Use bothValidation alone lets "52" through when 25 was meant. Verification alone lets an impossible age of 250 through if it is typed twice. Programs often use both.

Creating an account

Websites reject an empty username (presence), a short password (length), an email without "@" (format), and ask you to type the password twice (double entry).

Exam use: several validation checks and a verification check in one familiar example.

Barcodes and ISBNs

The last digit on a barcode is a check digit. A scanner recalculates it and beeps or rejects a bad scan.

Exam use: check digit: calculated from the other digits and recalculated when read.

Online payments

Card numbers include a check digit so a mistyped number is spotted before the payment is attempted.

Exam use: a check digit detecting a mistyped digit.

Booking a flight

The date must be in a valid format, in the future (range), and the passport number the right length.

Exam use: format, range and length checks.

Typing your email twice

Many sign-up forms ask for the email twice. If the two do not match, you are asked to try again.

Exam use: double entry verification: compares two entries.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State what is meant by validation.
ReminderAutomatic, and what it checks.
Validation is an automatic check by a program that the data entered is reasonable (sensible) and meets set rules.
Common mistakeSaying validation checks the data is correct. It only checks it is reasonable.
Q2 Name 3 marks A form asks for a customer's age (0 to 120) and a 10-digit phone number. Name three suitable validation checks and say what each would check.
ReminderPick range, type and length.
Range check: age is between 0 and 120. Type check: age is an integer (no letters). Length check: the phone number has exactly 10 digits.
Common mistakeNaming a check without saying what it checks in the scenario.
Q3 Explain 2 marks A user types 52 as their age instead of 25. Explain why validation does not detect this.
ReminderValid, but wrong.
52 is within the allowed range (and an integer), so it passes the validation checks. Validation only checks that data is reasonable, not that it is correct.
Common mistakeSaying the validation "did not work". It worked; 52 is a valid age.
Q4 Describe 3 marks Describe how a check digit is used to check a number.
ReminderCalculated, added, recalculated.
A check digit is calculated from the other digits using a formula and added to the end of the number. When the number is entered, the calculation is performed again. If the new result does not match the check digit, the number has been entered wrongly.
Common mistakeSaying the check digit is a random number. It is calculated from the other digits.
Q5 Describe 2 marks Describe how a double entry check verifies a new password.
ReminderTwice, then compare.
The user is asked to enter the password twice. The program compares the two entries and, if they are different, asks the user to enter them again.
Common mistakeDescribing a range check.
Q6 Describe 3 marks Describe what a visual check is and give one disadvantage.
ReminderCompare screen with source.
The user reads the data they have entered on the screen and compares it with the original (source) document. Disadvantage: it is slow, and the user could miss a mistake (or does not detect source errors).
Common mistakeSaying a visual check checks the data is sensible. That is validation.
Q7 State 2 marks State two differences between validation and verification.
ReminderPurpose and method.
Validation checks that data is reasonable; verification checks it was entered correctly (matches the source). Validation is automatic by the program; verification is by the user comparing, or by entering twice.
Common mistakeDescribing only one of them.
Q8 Calculate 2 marks The first 12 digits of an ISBN-13 give a total of 87 after multiplying by alternating weights of 1 and 3. Calculate the check digit.
Reminder10 minus the last digit of the total.
Last digit of the total is 7. Check digit = 10 − 7 = 3.
Common mistakeUsing 87 mod 11 or forgetting the final "10 minus" step.

Top tips

  • Validation = reasonable. Verification = matches the source.
  • Name the check and what it checks in the scenario: range, length, type, presence, format, check digit.
  • Valid does not mean correct. 52 passes a range check even if 25 was meant.
  • Verification: visual check or double entry check. Double entry compares two entries.
  • A check digit is calculated from the other digits and recalculated on entry.
