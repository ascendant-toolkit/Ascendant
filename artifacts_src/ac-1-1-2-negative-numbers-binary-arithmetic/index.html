Negative Integers, Binary Addition and Subtraction, and Overflow

Coursebook: Chapter 1 · Information representation, section 1.1 Data representation

One's and two's complement, adding and subtracting binary integers with the carries shown, how overflow happens, and eleven questions from the 2021 to 2026 papers.

This page in five sentences

An 8-bit pattern can mean an unsigned number (0 to 255) or, using two's complement, a number from −128 to +127, where the left-most bit is worth −128. To make a number negative you flip every bit and add 1. Computers add by the same column rules you use in denary, and they subtract by adding the two's complement of the second number, then ignoring any carry out of the left. When the true answer needs more bits than are available the result is wrong, which is called overflow. Exam marks are for the working (carries, flips, the added 1) and then the answer, so write them down.

1 · Representing negative integers

A fixed number of bits is used, so the first job is to know what the pattern means. The syllabus asks for one's complement and two's complement.

RepresentationHow negative numbers are made8-bit rangeNotes

One's complementFlip every bit of the positive value−127 to +127Two patterns for zero: 0000 0000 and 1111 1111
Two's complementFlip every bit, then add 1−128 to +127One zero. The left-most column is worth −128.

For n bits, two's complement holds −2n−1 to 2n−1 − 1. With 10 bits that is −512 to +511.

Making a number negative

  1. Write the positive value in the full number of bits: 30 = 0001 1110.
  2. Flip every bit: 1110 0001. (This is the one's complement.)
  3. Add 1: 1110 0010. This is −30 in 8-bit two's complement.

A shortcut: copy bits from the right up to and including the first 1, then flip the rest. 0001 1110 → 1110 0010.

Reading a two's complement number

If the left-most bit is 0 the number is positive: read it as normal. If it is 1, work with column values where the first column is −128. For 1110 0010: −128 + 64 + 32 + 2 = −30. For 1110 0111: −128 + 64 + 32 + 4 + 2 + 1 = −25. For 0110 1011: 64 + 32 + 8 + 2 + 1 = 107.

2 · Binary addition

Column sumWriteCarry
0 + 0 = 000
0 + 1 = 110
1 + 1 = 1001
1 + 1 + 1 (with a carry) = 1111

Work from the right, writing the carry above the next column. 1011 0000 + 0001 1011: the right-most columns give 1 and 1, then 0 + 1, and so on, and the answer is 1100 1011 (176 + 27 = 203). Adding three numbers works the same way, but a column can produce a carry of 2, so take the carries one column at a time.

3 · Overflow

Overflow happens when the result of a calculation is too large to be stored in the number of bits available. The extra bit is lost, so the stored result is wrong.

  • Unsigned numbers: a carry out of the left-most column means the sum was more than 255. 1100 0000 + 0100 0000 = 1 0000 0000 needs nine bits, so the 8-bit result is 0000 0000.
  • Two's complement numbers: overflow occurs when two positives give a negative result, or two negatives give a positive one, because the answer is outside −128 to +127. 0110 0100 (100) + 0011 0010 (50) = 1001 0110, which reads as −106.
  • Three numbers: 1001 1110 + 0110 0001 + 0001 1001 is 158 + 97 + 25 = 280, which needs nine bits. The 8-bit result is 0001 1000 (24), and you write "overflow".

The mark scheme definition is short: the result is larger than can be stored in the number of bits available.

4 · Binary subtraction

There are two accepted methods, and you can use either.

Method 1: add the two's complement

  1. Write the number being subtracted in full width: 30 = 0001 1110.
  2. Make it negative: flip and add 1 to get 1110 0010.
  3. Add it to the first number: 0110 1011 + 1110 0010 = (1) 0100 1101.
  4. Ignore the carry out of the left-most column. The answer is 0100 1101 (107 − 30 = 77).

Method 2: direct subtraction with borrowing

Subtract column by column from the right, borrowing from the next column when the top bit is smaller than the bottom bit. Show the borrows. The mark scheme for a recent subtraction accepted direct subtraction if the borrows or carries were visible.

Exam tipDo not convert to denary and back. The mark schemes say there are no marks for converting the numbers to denary, subtracting, and converting the answer back to binary.

The same circuit adds and subtracts, which is why two's complement is used: a processor needs only an adder and a way to flip bits and add 1.

5 · Common ways to lose marks

  • Flipping the bits but forgetting to add 1, which gives the one's complement.
  • Treating the left-most bit as +128 when the question says two's complement.
  • Leaving out the carries, so the working mark is lost.
  • Counting the ninth bit as part of an 8-bit answer instead of discarding it and saying overflow occurred.
  • Using too few bits: the negative of 30 in 12 bits starts 1111, not 1110.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

The counter that ran out

A large aircraft's control software once kept time in a counter that grew every hundredth of a second in a 32-bit signed number. After about 248 days of continuous power it would have overflowed, and the fix was to restart the systems before then and update the software.

Exam use: give a consequence of overflow: the stored value wraps to a wrong, often negative, value.

A rocket and a number that did not fit

In 1996 a rocket's guidance software converted a large number into a 16-bit signed integer that was too small to hold it. The overflow caused an error and the launch failed shortly after take-off.

Exam use: overflow is an error condition because the result is too large for the bits available.

The view counter

A video site once had a view count stored as a 32-bit signed integer, with a largest value of 2 147 483 647. A video passed that total, and the site changed the field to a 64-bit number.

Exam use: n bits signed holds up to 2^(n−1) − 1, so a larger count needs more bits.

One circuit for add and subtract

A processor's arithmetic logic unit only needs an adder. To subtract, it flips the bits of the second number, adds 1, and adds. This is why two's complement is used instead of storing a separate sign.

Exam use: explain why two's complement is useful: the same hardware adds and subtracts, and there is only one zero.

Odometers

A mechanical or digital counter that reaches its largest value rolls over to zero. An unsigned 8-bit counter does the same: 255 plus 1 gives 0, with a carry that is lost.

Exam use: unsigned overflow: a carry out of the left-most column that is not stored.

Top tips

  • Write the full width first. Put the positive number in 8 or 12 bits before you flip. Short patterns give wrong negatives.
  • Flip, then add 1. Flipping alone is the one's complement. The mark is for the added 1.
  • Show the carries. Write each carry above its column. It is the working mark.
  • Ignore the carry out when subtracting. In two's complement subtraction the ninth bit is discarded and the answer is the other eight bits.
  • Say overflow in words. When the true answer does not fit, write the 8-bit result and the word overflow.
  • Do not go through denary. Mark schemes give no marks for converting to denary, calculating, and converting back.
