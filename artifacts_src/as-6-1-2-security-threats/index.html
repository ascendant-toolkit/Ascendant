Security Threats: Malware, Phishing, Pharming, Hackers

Coursebook: Chapter 6 · Security, privacy and data integrity · section 6.1 Data security

Viruses, spyware, phishing, pharming and hackers, how they differ and how each risk can be restricted, with animations, labs and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

A threat is something that can harm data or a computer system. Malware (malicious software) includes viruses, which replicate themselves and can corrupt, delete or fill storage, and spyware, which is installed without the user's knowledge, secretly records their actions (such as keystrokes) and sends them to a third party. Phishing uses an email pretending to be from an official body to persuade people to disclose private information or click a link to a fake site; pharming uses malicious code on the computer to redirect the user to a fake website automatically. A hacker is a person who gains unauthorised access to a computer system. Each threat is restricted by a matching measure: anti-malware, firewalls, strong passwords and multi-factor authentication, user training and care in what is downloaded.

1 · The threats

ThreatWhat it isWhat it does
VirusMalicious software that replicates (copies) itselfCorrupts, deletes or changes files and data, or fills storage
SpywareMalware downloaded or installed without the user's knowledgeSecretly records the user's actions or keystrokes and sends the logs to a third party; runs in the background
PhishingAn email (or message) that pretends to be from an official body, such as a bankPersuades people to disclose private information such as bank details, or to click a link to an unofficial website: it needs the user to act
PharmingMalicious code or software installed on a computerRedirects the user to a fake website to obtain personal data, automatically (no user action needed)
HackerA person who gains unauthorised access to a computer systemCan delete, damage or steal data, or install malware

2 · Comparing threats

  • Spyware and virus, similarities: both are malicious software; both are installed or run without the user's knowledge; both can be hidden in legitimate software and can try to avoid the firewall; both run in the background.
  • Spyware and virus, differences: a virus replicates itself and can damage data; spyware does not replicate, it only records data and sends it to a third party.
  • Phishing and pharming, similarities: both try to obtain financial or personal information; both falsely represent an official organisation (a bank); both make use of fake websites.
  • Phishing and pharming, differences: phishing uses an email to prompt the user to act; pharming is malicious code that redirects to a fake website automatically.

3 · Restricting the risk

ThreatMeasureHow it works
Virus, malwareAnti-virus or anti-malwareScans files, downloads and devices and compares them with a database of known viruses; quarantines or deletes a match or alerts the user. Keep the definitions up to date
SpywareAnti-spyware, firewall, a virtual (on-screen) keyboardDetects and removes the program; the firewall blocks it sending data out; an on-screen keyboard defeats a keystroke logger
HackerFirewall, strong passwords, multi-factor authentication, access rightsThe firewall monitors traffic and blocks transmissions that are not allowed; a strong password mixes character types and is long; multi-factor authentication needs a second form of verification
PhishingTraining and careful checkingDo not click links in unexpected emails; check the sender and address; use a spam filter
PharmingAnti-malware, checking for the secure padlock and addressRemove the malicious code; verify the website
Malware in generalDownload only from reputable sources; keep back-ups; deny administrator rights to everyday users; avoid removable devicesReputable sources are less likely to contain malware; a back-up restores data lost to malware; fewer rights means everyday users cannot install it

Common ways to lose marks

  • Describing malware as "a virus that damages computers". Describe the specific behaviour, such as replicating or recording keystrokes.
  • Giving a threat with no description, or a measure with no explanation of how it works.
  • Repeating the same measure for two threats when the question says each measure must be different.
  • Mixing phishing and pharming. Phishing needs the user to click; pharming redirects automatically.
  • Describing a hacker as someone with "malicious intent". The key idea is unauthorised access.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

An email 'from your bank'

It asks you to click a link and enter your login. The sender address and link are slightly wrong: this is phishing.

Exam use: phishing.

A keystroke logger in a free program

A free download secretly records everything you type, including passwords, and sends it to the attacker.

Exam use: spyware.

Typing the right web address and still getting a fake page

Malicious code on your computer sends you to a fake copy of the site: pharming.

Exam use: pharming.

A school server breached

Someone guessed a weak password and gained unauthorised access: a hacker.

Exam use: hacker; strong passwords and multi-factor authentication.

A USB stick from a stranger

Plugging it in can install malware, which is why removable devices are avoided.

Exam use: malware restriction.

O/N 2021 · 9618/11/13 · Q2(c) Give 3 marks Two malware threats are spyware and viruses. Give two similarities and one difference between spyware and a virus.
ReminderBoth malicious, both unknown to the user. Virus replicates, spyware records.

Similarities, any two: Both are pieces of malicious software Both are downloaded, installed or run without the user's knowledge Both can pretend to be, or be embedded in, legitimate software Both run in the background

Difference, any one: A virus can damage computer data; spyware only records or accesses data A virus does not send data out of the computer; spyware sends recorded data to a third party A virus replicates itself; spyware does not

ReminderMalware, hacker, spyware, each with a description and a different measure.

One mark for the threat, one for its description and one for the measure, twice: Malware: malicious software that replicates and can delete or damage the papers; install and run anti-malware Hacker: illegal access in order to delete or damage the papers; use a firewall or strong passwords Spyware: software installed without the teacher's knowledge which records keystrokes and sends the data to a third party; use a firewall, anti-spyware or a virtual keyboard

ReminderPretends to be official, asks for information or a click. Secretly records and sends logs.

O/N 2023 · 9618/13 · Q8(b)(c) State / Explain 2 + 3 marks (b) State one difference and one similarity between pharming and phishing. (c) Explain how the data security risks of malware can be restricted.
ReminderAutomatic redirect against email prompt; both seek personal information. Reputable sources, back-up, anti-malware, firewall, rights.

(b) Difference: pharming is malicious code that redirects to a fake website, whereas phishing uses an email to prompt user action (or pharming is automatic, phishing needs user action) Similarity: both try to obtain financial or personal information; both falsely represent an official organisation; both make use of fake websites

(c) Any three: Download programs from reputable sources, as they are less likely to contain malware Back up computer systems so they can be restored after data loss from malware Install and run an anti-malware program so regular scans find and remove or quarantine malware, with definitions kept up to date Use a firewall to block unused ports so malware cannot enter Deny administrator privileges to everyday users so malware cannot be downloaded by them Avoid removable devices so malware cannot be installed from them

O/N 2025 · 9618/11 · Q8(a) Explain 2 marks Viruses and pharming are examples of malware. Explain what is meant by a virus and pharming.
ReminderReplicates and alters files. Redirects to a fake site.

Virus: malicious program or software that replicates itself and deletes or alters files or data stored on a computer Pharming: malicious code installed on a computer which redirects the user to a fake website to obtain personal data

M/J 2026 · 9618/12 · Q2(c) Describe 3 + 3 marks Personal data needs to be kept secure whilst on the computer. (i) Describe what is meant by a virus, and identify and describe one method to restrict the risk. (ii) Describe what is meant by a hacker, and identify and describe one method to restrict the risk.
ReminderVirus: replicates and fills storage or damages data; anti-malware scans. Hacker: unauthorised access; firewall, MFA, strong password.

(i) Description: malicious software that replicates on the computer and can fill storage or delete, corrupt or change data Method: anti-virus or anti-malware software Description: scans files, downloads or devices and compares against a database of known viruses, and quarantines, deletes or alerts the user if a match is found

(ii) Description: a person who gains unauthorised access to a computer system Method: firewall, multi-factor authentication, strong passwords or encryption Description: for example the firewall monitors all data compares it to stored criteria and blocks transmissions that are not allowed; MFA requires a second form of verification such as biometrics or an authenticator app

Common mistakeWriting 'a hacker has malicious intent'. The mark is for unauthorised access.

Top tips

  • Threat, description, measure. Three separate marks.
  • Different measure for each threat. Do not repeat 'firewall'.
  • Virus replicates. Spyware records and sends.
  • Phishing: the user acts. Pharming: automatic redirect.
  • Hacker: unauthorised access. Say it in those words.
  • Say how the measure works. Scan, compare, quarantine; check packets.
