Bit Manipulation: Shifts and Masks

Coursebook: Chapter 4 · Processor fundamentals · section 4.3 Bit manipulation

Logical shifts and the AND, OR and XOR masks, clearing, setting, flipping and testing bits, with animations, a bit calculator and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

Bit manipulation changes individual bits of the accumulator with shifts and bit masks. A logical shift moves every bit left (LSL) or right (LSR) by n places and fills the gap with zeros, which multiplies (left) or divides (right) an unsigned number by powers of 2. The bitwise AND, OR and XOR instructions combine the ACC with a mask (the operand) one bit at a time: AND clears bits (and tests them), OR sets bits, XOR flips bits. The operand may be an immediate value (#n denary, Bn binary, &n hexadecimal) or the contents of an address. Exam questions give the ACC contents and an instruction and ask for the new contents, or ask for the instruction that makes a given change.

1 · Shifts

InstructionEffectExample
LSL #nLogical shift left n places; zeros enter on the right; bits shifted off the left are lost0001 1110 LSL #2 = 0111 1000
LSR #nLogical shift right n places; zeros enter on the left0001 0111 LSR #3 = 0000 0010

A shift left by n multiplies an unsigned value by 2n (if no bits are lost); a shift right by n divides by 2n and discards the remainder. LSL #4 on 0110 1101 gives 1101 0000: the leading 0110 is lost. The 2026 instruction set also lists arithmetic shifts (ASL, ASR: the sign bit is preserved on a right shift) and cyclic shifts (CSL, CSR: bits pushed off one end re-enter at the other); logical shifts are the ones asked for in the calculations in 2021 to 2025.

2 · Bit masks

InstructionRule for each bitUse
AND mask1 only if both bits are 1Clear bits (mask 0 clears; mask 1 keeps), or test a bit
OR mask0 only if both bits are 0Set bits to 1 (mask 1 sets; mask 0 keeps)
XOR mask1 if the bits differFlip bits (mask 1 flips; mask 0 keeps), or compare

Worked: ACC = 0110 0101. To set every bit to 1: OR #255 (or XOR #154, which flips just the 0 bits). To flip every bit: XOR #255, giving 1001 1010. To set the least significant bit to 1 and leave the rest unchanged: OR #1 (OR B00000001). To clear the data in an 8-bit register: AND B00000000. To test whether a number is odd: AND #1, then compare the result with 1: it is true when the least significant bit is 1.

3 · Reading the operand

#29 is denary 29 (0001 1101), B01001111 is binary and &12 is hexadecimal 12 = 0001 0010. An operand that is an address (for example AND 31) means the contents of address 31 are the mask. Convert the operand to 8 bits before you combine it with the ACC, and write the answer in 8 bits.

Common ways to lose marks

  • Not converting #n or &n to binary first.
  • Using the address as the mask instead of the contents of the address.
  • Writing fewer or more than 8 bits after a shift.
  • Using AND to set bits or OR to clear them. Remember: AND clears, OR sets, XOR flips.
  • Saying "bit manipulation tests odd numbers" without naming the instruction, or without the comparison with 1.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Pixel colours

Image programs pull the red, green and blue values out of a packed number with AND masks and shifts, thousands of times per image.

Exam use: AND masks and LSR.

Permissions on a file

A set of on/off options is stored in one number; OR sets an option, AND with the opposite mask clears it, XOR toggles it.

Exam use: setting, clearing and flipping flags.

Fast multiplying

Shifting left by 1 doubles a number much faster than a full multiplication, so compilers use it.

Exam use: LSL = × 2.

Checking odd or even

A program tests the lowest bit with a mask to see whether a number is odd without dividing.

Exam use: AND #1.

Simple encryption

XOR a message with a key to scramble it; XOR again with the same key to get the message back.

Exam use: XOR flips bits and is reversible.

Top tips

  • AND clears, OR sets, XOR flips. Say the mask value too.
  • Convert the operand to 8 bits. #n, Bn and &n are all numbers.
  • An address operand: use its contents. Not the address itself.
  • Write all eight bits. In groups of four.
  • Odd test: AND #1, compare with 1. Both parts.
  • LSL ×2, LSR ÷2. Bits can fall off the end.
