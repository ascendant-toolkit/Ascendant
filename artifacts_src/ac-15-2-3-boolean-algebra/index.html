Boolean Algebra and De Morgan

Coursebook: Chapter 15 · Hardware and virtual machines, section 15.2 Boolean algebra and logic circuits

Sum-of-products from a truth table, the laws of Boolean algebra, De Morgan's laws and step-by-step simplification; animations, labs and the real Paper 3 questions from 2021 to 2026.

This page in five sentences

Boolean algebra is a set of laws for rewriting logic expressions, where . means AND, + means OR and a bar over a term means NOT. Any truth table can be written as a sum-of-products: one AND term for each row where the output is 1, all joined by OR. De Morgan's laws break a bar over a group: the bar over AND becomes OR, and the bar over OR becomes AND, with each term inverted. Simplifying means using the laws to give an equivalent expression with fewer terms or gates, and the exam asks you to show each step. Every answer can be checked by comparing truth tables.

1 · From a truth table to a sum-of-products

Find every row where the output is 1. For each one write an AND term using each input once: write the input as it is if its value in that row is 1, with a bar if it is 0. Join the terms with OR.

X is 1 in rows 001, 100, 101 and 111, so X = A.B.C + A.B.C + A.B.C + A.B.C. This is a sum (OR) of products (ANDs), and it is exactly the expression for a circuit made of AND gates feeding one OR gate.

RememberUse the rows where the output is 1. A row with 0 in the output column gives no term. Four inputs give sixteen rows; check that you have one term per 1 and no others.

2 · The laws

IdentityA . 1 = AA + 0 = A
Annulment (null)A . 0 = 0A + 1 = 1
IdempotentA . A = AA + A = A
Inverse (complement)A . A = 0A + A = 1
Double negationA = AA = A
CommutativeA . B = B . AA + B = B + A
Associative(A . B) . C = A . (B . C)(A + B) + C = A + (B + C)
DistributiveA . (B + C) = A . B + A . CA + B . C = (A + B) . (A + C)
AbsorptionA . (A + B) = AA + A . B = A
RedundancyA . (A + B) = A . BA + A . B = A + B
De MorganA . B = A + BA + B = A . B

The ones used most in the exams are De Morgan, double negation, distributive, absorption, idempotent and annulment. Write the name of the law next to each line.

3 · De Morgan's laws

Break the bar and change the operator:

  • A + B = A . B: NOT (A or B) is the same as NOT A and NOT B. This is a NOR gate.
  • A . B = A + B: NOT (A and B) is the same as NOT A or NOT B. This is a NAND gate.

The laws extend to three terms: A + B + C = A . B . C. A double bar cancels, so A + B = A . B (the bar breaks, A is inverted twice, B once).

4 · Simplifying with the laws

A method that works:

  1. Remove any bars over groups with De Morgan, and cancel double bars.
  2. Look for a common factor and take it out with the distributive law.
  3. Use inverse, idempotent, annulment, identity or absorption to remove terms.
  4. State the law on each line, and finish with the simplified expression.

5 · Common ways to lose marks

  • Changing the operator but forgetting to bar each term: ~(A + B) is ~A . ~B, not ~A + ~B.
  • Leaving out the name of the law. Several marks are for showing the right law at each step.
  • Writing a sum-of-products term for each 0 row.
  • Dropping a bar during copying. Rewrite carefully and check with a truth table if there is time.
  • Stopping early. Check whether a common factor can still be taken out.

Designing a circuit from a specification

An engineer writes the sum-of-products from the required truth table, simplifies it, then builds the circuit. Fewer terms means fewer gates, a smaller chip and less power.

Exam use: simplifying reduces the number of gates.

NAND and NOR gates

Chips are often built from only NAND (or only NOR) gates because they are cheap and quick to make. De Morgan's laws show how to turn AND/OR designs into NAND/NOR ones.

Exam use: ~(A . B) = ~A + ~B.

Search filters

'NOT (cats OR dogs)' means 'NOT cats AND NOT dogs': a result must contain neither word. That is De Morgan's law in a search box.

Exam use: ~(A + B) = ~A . ~B.

Safety interlocks

A machine runs only when the guard is closed AND the stop button is not pressed. Simplified expressions mean simpler wiring and fewer faults.

Exam use: the output is a Boolean expression of the inputs.

Programming conditions

NOT (x > 5 AND y > 5) can be rewritten as x <= 5 OR y <= 5, which is often easier to read.

Exam use: De Morgan's laws apply to conditions in code as well.

Top tips

  • Sum-of-products: rows where the output is 1. One AND term for each, joined by OR.
  • Bar a letter when its value in that row is 0. Row 1001 gives A.~B.~C.D.
  • De Morgan: break the bar, change the operator. ~(A+B) = ~A.~B and ~(A.B) = ~A+~B.
  • Cancel double bars. ~~A = A. Check each bar carefully.
  • Name the law on every line. Marks are for the laws as well as the answer.
  • Check with a truth table. If both expressions have the same table they are equal.
