Automated Systems

How sensors, microprocessors and actuators work together, and the advantages and disadvantages of automation in industry, transport, agriculture, weather, gaming, lighting and science.

The big idea

An automated system uses sensors, a microprocessor and actuators in a loop of feedback, so a task can run with little human help.

6.1 Automated systems

An automated system carries out a task with little or no human involvement. It does this by combining sensors, a microprocessor and actuators in a repeating loop.

Sensor

Measures a physical quantity (temperature, light, pressure, moisture) and sends the reading in. Sensors give analogue data, so an analogue-to-digital converter (ADC) turns it into digital data.

Microprocessor

Compares each reading with the stored value (the target or limit), and decides what to do. It follows a stored program.

Actuator

Turns the microprocessor's signal into physical action: a motor, valve, pump, heater, lamp or alarm. A digital-to-analogue converter (DAC) may be needed.

Feedback

The effect of the action changes the next reading, so the sensor keeps measuring and the loop repeats. This is how the system keeps a value steady.

The control loop

sensor measures → ADC → microprocessor compares with the stored value → signal → actuator acts → (the sensor measures again)

The program on the left runs for ever, checking the sensor each time round the loop.

Advantages and disadvantages

Advantages

  • Works 24 hours a day without breaks, sleep or holidays
  • More accurate and consistent than a person; fewer human errors
  • Faster responses to changes
  • Can work in dangerous or remote places
  • Running costs can be lower in the long term

Disadvantages

  • High initial cost to buy, install and program
  • Jobs may be lost because fewer people are needed
  • Needs maintenance; faults, power cuts or software bugs can stop it
  • Cannot easily cope with unexpected situations
  • Can be a target for hackers; people may depend on it too much

6 · Multiple choice

Descriptions are kept general. Check current details before quoting specifics.

Street lights

A light sensor reads the daylight. When it falls below a stored value, the microprocessor switches the lamp on; when it rises again, it switches it off.

Exam use: a one-sensor, one-actuator example with a clear stored value.

Central heating thermostat

A temperature sensor tells the microprocessor how warm the room is. It switches the boiler on below the set temperature and off above it.

Exam use: feedback: the heating changes the temperature, which the sensor reads again.

An automated factory

Robot arms and conveyor belts run all day, with sensors checking each product.

Exam use: industry: constant quality and 24-hour work, against high cost and lost jobs.

Automatic weather station

Sensors measure temperature, pressure, humidity and rainfall in remote places and send data back without staff.

Exam use: the weather scenario: accurate data in dangerous or remote places.

A smart irrigation system

Moisture sensors in a field tell the system when to switch on pumps, so crops get just enough water.

Exam use: agriculture: less waste, but it relies on working sensors.

Space and deep-sea probes

Automated probes collect data in places too dangerous or far away for people.

Exam use: science: working where humans cannot, but unable to react creatively.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 Describe 4 marks A greenhouse uses an automated system to keep the temperature at 25 °C. Describe how a sensor, a microprocessor and an actuator work together.
ReminderSensor measures, ADC, compare, actuator, repeat.
A temperature sensor measures the temperature in the greenhouse (analogue data, converted by an ADC). The data is sent to the microprocessor. The microprocessor compares the reading with the stored value (25 °C). If it is too high (or low), it sends a signal to an actuator (for example to open a window or switch the heater), and the process repeats.
Common mistakeSaying the sensor "turns on the heater". Sensors measure; actuators act.
Q2 Explain 2 marks Explain why an analogue-to-digital converter (ADC) is needed in an automated system.
ReminderAnalogue in, digital out.
Sensors collect analogue data (real-world measurements). A microprocessor can only process digital data, so the ADC converts it.
Common mistakeSaying the ADC "makes the data bigger" or "stores it".
Q3 Explain 3 marks Explain how feedback is used in an automated system.
ReminderThe effect is read again.
The sensor keeps measuring (continuously or at regular intervals). The actuator's action changes the quantity being measured. The microprocessor uses the new reading to decide the next action, keeping the value steady.
Common mistakeDescribing one measurement only. Feedback needs the loop to repeat.
Q4 Describe 4 marks Farmers use an automated irrigation system. Give two advantages and two disadvantages.
ReminderTwo of each, linked to farming.
Advantage: the right amount of water is supplied, so less water is wasted. Advantage: saves labour, and works day and night. Disadvantage: expensive to buy and install. Disadvantage: a faulty sensor could cause over- or under-watering (or needs maintenance).
Common mistakeWriting general answers such as "it is faster". Link each point to farming.
Q5 Explain 3 marks A factory replaces some workers with an automated production line. Explain the advantages and a disadvantage for the factory.
ReminderOutput, accuracy, cost.
It can work 24 hours a day without breaks, so more is produced. It is more accurate and consistent, so fewer errors and less waste. Disadvantage: high initial cost (and jobs may be lost).
Common mistakeOnly giving advantages when the question asks for both.
Q6 Describe 3 marks An automatic weather station is placed in a remote mountain area. Describe two advantages and one disadvantage of using an automated system.
ReminderRemote, continuous, maintenance.
It can collect readings in a remote or dangerous place without a person present. It can record data continuously, day and night. Disadvantage: it needs maintenance, and a damaged sensor or a power failure would stop or spoil the readings.
Common mistakeForgetting to link answers to remote or weather.
Q7 Explain 2 marks A street light turns on when it gets dark. State what the microprocessor compares and what it does when the reading is below the stored value.
ReminderReading against stored value.
It compares the light sensor reading with the stored (threshold) value. If it is lower, it sends a signal to switch the lamp (actuator) on.
Common mistakeSaying the sensor makes the decision. The microprocessor decides.

Top tips

  • Sensor measures, microprocessor decides, actuator acts.
  • The microprocessor compares the reading with a stored value. Always say this.
  • ADC: sensors give analogue data; the microprocessor needs digital.
  • Feedback: the loop repeats, and the action changes the next reading.
  • Link each advantage and disadvantage to the scenario: industry, transport, agriculture, weather, gaming, lighting, science.
