File Handling

Why programs store data in files, and how to open, read from, write to and close a file.

The big idea

Variables vanish when a program ends, but a file keeps data. Every file task follows open, use, close, with READ to take data out and WRITE to put data in, which erases what was there before.

8.3 File handling

Why store data in a file?

Variables and arrays live in RAM, so their contents are lost when the program ends. A file stores data on secondary storage, so it is kept permanently and can be used the next time the program runs.

  • Data is kept between runs: high scores, settings, customer records.
  • A program can read large amounts of data without the user typing it in.
  • Data can be shared between programs, or backed up and moved.

Open, use, close

Every file operation follows the same three steps.

StepPseudocodeWhat it does
1. OpenOPENFILE "Names.txt" FOR READ
OPENFILE "Names.txt" FOR WRITE		Opens the file in one mode. The file name is a string.
2. UseREADFILE "Names.txt", Name
WRITEFILE "Names.txt", Name		Reads one item or line into a variable, or writes a value into the file.
3. CloseCLOSEFILE "Names.txt"Closes the file when it is no longer needed.

READ mode

For reading data from the file. Each READFILE gives the next item or line.

WRITE mode

For writing data into the file. A new file is created and any existing data in the file is lost.

One mode at a timeA file is opened in only one mode at a time. To write and then read, close the file and open it again in the other mode.

Copying a line from one file to another

Single items and whole lines of text can both be read and written. Each READFILE moves on to the next item or line, so a loop reads through the file in order.

Programs often need to read until the end of the file. Exam questions normally say how many items are in the file, or use a function such as EOF (end of file) in the question. In Python, a loop such as "for line in file" reads every line.

Why close a file?

  • It makes sure all the written data is saved to the file.
  • It frees the file so other programs, or the same program in another mode, can use it.
  • It avoids corrupting the data.

Common mistakes

  • Opening a file for WRITE when you meant to keep its old data: it is erased.
  • Using READFILE before opening the file, or after closing it.
  • Forgetting CLOSEFILE.
  • Reading more items than the file holds.

Saving a game

A game writes the player's level and score to a file so they are still there tomorrow.

Exam use: storing data permanently so it survives after the program ends.

A high score table

On start-up the game reads the scores from a file. When the game ends it writes the updated list back.

Exam use: READ mode at the start; WRITE mode to replace the file.

A program reads the list of usernames and passwords from a file to check a login.

Exam use: reading data from a file, rather than typing it in each time.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State two reasons why a program might store data in a file.
ReminderPermanent, large, shared.
Data is kept permanently (it is not lost when the program ends or the computer is switched off). The program can use the data again next time, or share it with other programs (or read large amounts of data without typing).
Common mistakeSaying files are "faster than RAM". Files keep data when the power is off.
Q2 Describe 3 marks Describe the three steps needed to write data to a file.
ReminderOpen, write, close.
Open the file in WRITE mode (OPENFILE ... FOR WRITE). Write the data to the file (WRITEFILE). Close the file (CLOSEFILE).
Common mistakeForgetting to close the file.
Q3 Explain 2 marks Explain what happens to existing data in a file when it is opened for WRITE.
ReminderA new file is created.
A new (empty) file is created, so any existing data in the file is lost.
Common mistakeSaying the new data is added to the end.
Q4 Write 5 marks Write pseudocode to input 5 names and write them to the file Names.txt.
ReminderOPENFILE, loop, INPUT, WRITEFILE, CLOSEFILE.
OPENFILE "Names.txt" FOR WRITE A loop that repeats 5 times (FOR Count ← 1 TO 5) INPUT Name inside the loop WRITEFILE "Names.txt", Name inside the loop CLOSEFILE "Names.txt"
Common mistakePutting OPENFILE inside the loop, which erases the file each time.
Q5 Write 5 marks The file Scores.txt contains 10 whole numbers, one on each line. Write pseudocode to read them and output their total.
ReminderREAD mode, Total ← 0, loop.
OPENFILE "Scores.txt" FOR READ Total ← 0 FOR Count ← 1 TO 10 with READFILE "Scores.txt", Score Total ← Total + Score CLOSEFILE "Scores.txt" and OUTPUT Total after the loop
Common mistakeOpening in WRITE mode, which would erase the scores.
Q6 Explain 2 marks Explain why a file should be closed when a program has finished with it.
ReminderSaved and freed.
To make sure all the data is saved to the file. To free the file so that it can be used by another program (or opened in another mode).
Common mistakeSaying "to save memory" only.
Q7 Describe 2 marks Describe the difference between opening a file for READ and for WRITE.
ReminderDirection of data.
READ: data is read from the file (the program uses the file's contents). WRITE: data is written into the file (a new file is created and existing contents are lost).
Common mistakeWriting only about one mode.
Q8 Describe 3 marks Describe what this program does.
OPENFILE "FileA.txt" FOR READ
OPENFILE "FileB.txt" FOR WRITE
READFILE "FileA.txt", LineOfText
WRITEFILE "FileB.txt", LineOfText
CLOSEFILE "FileA.txt"
CLOSEFILE "FileB.txt"
ReminderRead one, write one, close both.
It opens FileA for reading and FileB for writing. It reads a line of text from FileA and writes it into FileB (copying the line). Both files are closed.
Common mistakeDescribing it line by line without saying the overall effect: a line is copied.

Top tips

  • Open, use, close. Always close the file.
  • READ takes data out; WRITE puts data in.
  • WRITE mode erases the existing file.
  • One mode at a time. To switch, close and re-open.
  • Use a loop to read or write several items; open the file before the loop and close it after.
  • Say why files are used: data is kept after the program ends.
