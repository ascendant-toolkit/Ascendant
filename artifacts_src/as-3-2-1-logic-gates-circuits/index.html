Logic Gates and Logic Circuits

Coursebook: Chapter 3 · Hardware · section 3.2 Logic gates and logic circuits

The six logic gates, truth tables with working space, drawing a circuit from an expression and writing an expression from a circuit or table, with circuit animations, toggle labs and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

A logic gate turns binary inputs into one output; the syllabus uses NOT, AND, OR, NAND, NOR and XOR. A logic circuit joins gates together; you can work out its output with a truth table whose working space column holds an intermediate result. You must be able to draw a circuit from a logic expression, write the expression for a circuit and complete a truth table in either direction. Work in a fixed order: inner brackets first, NOT before AND, and every gate of the expression becomes exactly one gate in the diagram. Logic circuits are used in monitoring and control systems, in memory and in the ALU.

Say it in words, as the mark schemes do: NOT inverts. AND: output is 1 only when both inputs are 1. OR: output is 0 only when both inputs are 0, otherwise 1. NAND: output is 0 when both inputs are 1, otherwise 1. NOR: output is 1 when both inputs are 0, otherwise 0. XOR: output is 1 when one input is 1 and the other is 0, that is when the inputs are different, otherwise 0. AND and OR can have more than two inputs, for example A AND B AND C is 1 only when all three are 1.

2 · Completing a truth table

  1. List every input combination in binary order: 2 inputs give 4 rows, 3 give 8, 4 give 16.
  2. Split the expression into its parts and put each part in the working space.
  3. Work out the innermost brackets first, then combine them, applying NOT to a term as soon as it appears.
  4. Write the final column. The paper gives one mark for each half of the rows, so errors in the middle of the table can cost a mark.

Example: X = (A XOR B) AND NOT C. A XOR B is 1 when A and B differ. NOT C is 1 when C is 0. X is 1 only for the rows 010 and 100.

3 · Drawing a circuit from an expression

Each operator in the expression becomes a gate, and the brackets show which gate feeds which. Start from the outermost operator: it is the last gate. Work inwards, drawing the gates that feed it. Every gate gets inputs from the inputs or from the gates inside its brackets. Example: X = (A XOR B) AND NOT C has three gates: an XOR on A and B, a NOT on C, and an AND of the two results.

Mark schemes award marks for each correct gate with correct inputs and for no superfluous gates. Draw every NOT as its own gate (or a bubble if you are sure), keep the labels A, B and C on the left and X on the right.

4 · Writing an expression from a circuit or a truth table

From a circuit: work from the left, writing each gate's expression with brackets, and substitute it into the next gate. From a truth table, take each row where the output is 1, write an AND term (use NOT for any input that is 0), and join the terms with OR. For R S T with output 1 only at 001 and 110, Q = (NOT R AND NOT S AND T) OR (R AND S AND NOT T).

5 · Logic in context

Conditions in the scenario map directly onto gates. Take a greenhouse window X that opens if the temperature is too high (T) and the wind speed is acceptable (W = 0) and either rain is not detected (R = 0) or the manual override is off (M = 0). Then X = T AND NOT W AND (NOT R OR NOT M).

Common ways to lose marks

  • Treating XOR as OR: XOR is 0 when both inputs are 1.
  • Forgetting a NOT in the middle of the expression. Put every NOT in the working space.
  • Drawing a gate for a bracket that does not exist, or skipping a gate: count the operators and the gates.
  • Describing a gate as "it outputs 1 if A and B". Use the exact conditions for both 0 and 1 outputs.
  • Leaving out the brackets when writing an expression from a circuit.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A two-way light switch

A light on a landing is on if exactly one of two switches is up. That is an XOR gate: the output is 1 when the inputs are different.

Exam use: XOR.

A car that will not start

The engine starts only if the car is in park AND the brake is pressed. An AND gate makes a safe condition out of two inputs.

Exam use: AND.

A smoke alarm

The alarm sounds if smoke is detected OR the battery is low. OR combines conditions where either is enough.

Exam use: OR.

A machine guard

A press works only when neither of two guard sensors is triggered: NOR is 1 only when both inputs are 0.

Exam use: NOR.

Computer memory and the processor

Every flip-flop in SRAM and every adder in the ALU is built from gates.

Exam use: logic circuits are the basis of hardware.

Top tips

  • Use the words of the mark scheme. 'The output is 0 when both inputs are 1, otherwise 1.'
  • Work inside the brackets first. Put each part in the working space.
  • One operator, one gate. Count them before you draw.
  • XOR means different. Not 'or'.
  • Write every NOT. Missing NOTs lose the most marks.
  • Test two rows. When matching tables to expressions.
