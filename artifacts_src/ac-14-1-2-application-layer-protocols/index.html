Application Layer Protocols: HTTP, FTP, Email and BitTorrent

Coursebook: Chapter 14 · Communication and internet technologies, section 14.1 Protocols

What HTTP, FTP, SMTP, POP3, IMAP and BitTorrent are used for, how email travels, and how BitTorrent shares a file in pieces; animations, a swarm simulation and the real 9618 questions from 2022 to 2025.

This page in five sentences

The Application layer of TCP/IP contains the protocols that programs use to exchange data, and you need to know six and what each is for. HTTP(S) transfers the hypertext documents that make up web pages, FTP sends and receives files between devices, SMTP sends email, and POP3 and IMAP receive email. BitTorrent shares files peer-to-peer, with the pieces of a file coming from many users' computers instead of one server. SMTP is a push protocol (the sender pushes mail out), and POP3 and IMAP are pull protocols (the receiving client pulls mail from the server). The exam asks you to name a protocol and describe its use, or to match protocols to uses.

1 · The six protocols

ProtocolPurposeKey points
HTTP / HTTPS (Hypertext Transfer Protocol; S = secure)Sending and receiving web pages / hypertext documents (and images, video) between a web server and a browserThe browser sends a request, the server a response. HTTPS is encrypted (TLS)
FTP (File Transfer Protocol)Sending and receiving files over a network, between devices: uploading to and downloading from a serverUsed to move files such as a website's pages to a web server

Sending against receivingSending email: SMTP. Receiving email: POP3 or IMAP. An exam answer for "name a protocol associated with sending and one with receiving" is SMTP and POP3 or IMAP.

2 · How an email travels

  1. You write a message in your email client and press send. The client uses SMTP to push it to your outgoing mail server.
  2. Your mail server uses SMTP to pass it to the recipient's mail server (and on, via other servers, if needed).
  3. The recipient's mail server stores it in their mailbox.
  4. The recipient's client pulls it with POP3 (download, normally removing it from the server) or IMAP (view it, leaving it on the server, with every device in sync).
POP3IMAP

3 · HTTP in a little more detail

A browser asks for a page with an HTTP request and the server answers with a response.

Request:   GET /index.html HTTP/1.1
           Host: www.example.com

Response:  HTTP/1.1 200 OK            (the status: 200 means success, 404 means page not found)
           Content-Type: text/html
            ... the web page ...

4 · How BitTorrent shares a file

  1. A user who has the whole file creates a small torrent (descriptor) file with metadata about it: its name, size and the address of a tracker. The whole file must be on at least one peer to begin with.
  2. The file is divided into equal-sized pieces.
  3. Other users get the torrent file and connect to a tracker, which acts like a server holding data about all the computers sharing the file (the swarm).
  4. Each peer downloads pieces from other peers, many at once, until it has the whole file.
  5. As soon as a peer has a piece it becomes a source of that piece for others. A peer that has the complete file and keeps sharing it is a seed.

This puts the load on the whole swarm instead of one server, so it can share files between thousands of users. All users are of equal status: there is no central web server.

5 · Common ways to lose marks

  • Writing "email" as the purpose of POP3 and IMAP without saying receiving (retrieving) email, and without saying SMTP is for sending.
  • Saying IMAP "sends" email. It receives; SMTP sends.
  • Not giving the difference between POP3 and IMAP: IMAP keeps the message on the server so it can be read from any device.
  • Describing BitTorrent as "a website for downloading". It is a peer-to-peer protocol with no central server holding the file.
  • Giving only the name of a protocol: the mark needs the use too.
  • Describing HTTP as only for "the internet". It transfers hypertext documents (web pages).

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Viewing a website

Every page you open in a browser arrives through HTTP or HTTPS: the browser asks, the web server replies with the page, the images and the style files.

Exam use: HTTP(S) transfers web pages / hypertext documents.

Uploading a school website

A teacher uploads a new set of web pages to the school's web server using FTP, because FTP is designed to send and receive files between devices.

Exam use: FTP: sending and receiving files over a network.

Reading your email on a phone and a laptop

IMAP keeps the mail on the server, so the same inbox, with the same read and unread messages, appears on both devices.

Exam use: IMAP: access from any device without removing the message from the server.

Sending a message

When you press send, your email program hands the message to the outgoing mail server with SMTP, and mail servers use SMTP to pass it on.

Exam use: SMTP sends email; it is a push protocol.

Downloading a large game or Linux image

Instead of one overloaded server, the file comes in pieces from hundreds of other users who already have it, using BitTorrent.

Exam use: BitTorrent: peer-to-peer file sharing; no central server.

2. Review questions

Written for practice and revision, not taken from past papers. Use them to check your understanding before attempting the real questions above.

Distinguish 2 marks Distinguish between the SMTP and POP3 protocols.
ReminderSending against receiving.

SMTP is used to send email, from a client to a mail server and between mail servers (push). POP3 is used to receive email: the client downloads it from the mail server (pull).

Compare 3 marks Compare the POP3 and IMAP protocols for a user who reads email on a phone and a laptop.
ReminderWhere the mail is kept.

POP3 downloads the message to one device and normally removes it from the server, so the other device does not have it. IMAP leaves the message on the server and keeps all devices in sync. So IMAP is better for reading the same mail on two devices.

State 2 marks State two ways in which sharing a file with BitTorrent differs from downloading it from a web server.
ReminderWhere does the file come from?

BitTorrent downloads pieces from many peers at once; a web server sends the whole file from one place. BitTorrent has no central server holding the file, and every peer that has a piece shares it.

Identify 2 marks A web designer needs to copy a folder of new pages to the company's web server. Name the most suitable protocol and say why.
ReminderMoving files.

FTP It is used for sending and receiving files over a network between devices

Describe 3 marks Describe what happens when a browser requests a web page using HTTP.
ReminderRequest and response.

The browser sends an HTTP request to the web server for the page. The server finds the page and sends an HTTP response containing the hypertext document, with a status such as 200. The browser displays the page.

Top tips

  • Name and use. Every protocol answer needs the name and what it is used for.
  • SMTP sends, POP3 and IMAP receive. Say 'sending' or 'receiving' explicitly.
  • IMAP: any device, server copy kept. That is the distinction from POP3.
  • HTTP: web pages. FTP: files. Hypertext documents against file transfer.
  • BitTorrent: peer-to-peer, no central server. Pieces, torrent file, tracker, swarm, seed.
  • Do not give the protocol the question names. If POP3 is given, choose others.
