This page in five sentences

An abstract data type (ADT) is a collection of data together with the operations allowed on it, described without saying how it is stored. A stack is last in, first out (LIFO): PUSH adds to the top and POP removes from the top, using a top of stack pointer. A queue is first in, first out (FIFO): items are added at the end (rear) and removed from the front, each with its own pointer; a circular queue wraps round so empty locations are reused. A linked list stores each item in a node with a pointer to the next node, a start pointer to the first node, a null pointer at the end and a free list of unused nodes. All three are built from arrays (or records) and variables for the pointers.

1 · Stack (LIFO)

  • PUSH: check the stack is not full, store the value where the pointer says, move the pointer; POP: check the stack is not empty, take the value, move the pointer back.
  • The value on the stack for the longest time is at the bottom; the next value out is at the top.
  • A stack can grow upwards (index 1, 2, 3 ...) or down through memory (207, 206 ...). Read the question to see which way, and whether the pointer is at the last value added or the next free place.
  • Uses: Back button history, undo, returning from procedure calls, evaluating expressions.
// stack in ThisStack[1:60], SP = next free index, OnStack = items heldFUNCTION Push(ThisValue : REAL) RETURNS BOOLEAN   IF OnStack = 60 THEN      RETURN FALSE            // stack is full   ENDIF   ThisStack[SP] ← ThisValue   SP ← SP + 1   OnStack ← OnStack + 1   RETURN TRUEENDFUNCTION

Initially SP is 1 and OnStack is 0. The array elements need no initial values: an element cannot be popped until a value has been pushed (which overwrites it).

2 · Queue (FIFO)

  • Front pointer: the next item to be removed. End pointer: the last item added.
  • Add: check the queue is not full; move the end pointer on by 1 (back to 0 after the last location); store the item at the end pointer.
  • Remove: check the queue is not empty; copy the item at the front pointer; move the front pointer on by 1 (wrapping round).
  • If the front and end pointers are equal there is one item in the queue.
  • Number of items in a circular queue: end − front + 1, and if that is not above zero add the number of locations.
// adding to a circular queue held in an array of 8 (0 to 7)IF Items = 8 THEN   OUTPUT "Queue full"ELSE   EndPtr ← EndPtr + 1   IF EndPtr > 7 THEN      EndPtr ← 0            // wrap round   ENDIF   Queue[EndPtr] ← NewItem   Items ← Items + 1ENDIF

3 · Linked list

  • A node holds a data item and a pointer to the next node. The start pointer points to the first node; the last node has a null pointer (written Ø).
  • Items are accessed in order by following the pointers. The order of the data is set by the pointers, so an item is added or deleted by changing pointers only; no data is moved (an array would have to shift items to keep the order).
  • Disadvantages: extra memory for the pointers, and more complex to set up and program.
  • Free list: the unused nodes are linked together too. After initialisation the start pointer is null, the free list pointer points to the first node and all the nodes are on the free list.
  • Implementation: two 1D arrays (one for data, one for pointers, the same index being one node) and two integer variables (start pointer, free list pointer); or one array of records with a data field and a pointer field. A value outside the array indices (such as 0) is the null pointer.
  • Insert: take the first node from the free list (move the free pointer on), store the data in it, set its pointer to the node that should follow it, and set the pointer of the node before it to point to the new node. Delete: change the previous node's pointer to skip the deleted node and add that node to the free list.

Common ways to lose marks

  • Not checking for a full stack/queue before adding, or an empty one before removing.
  • Forgetting wrap-around in a circular queue.
  • Moving the pointer in the wrong direction (stack grows down in memory in some questions).
  • In a linked list, drawing arrows but leaving out the start pointer, the null pointer or the free list.
  • Saying "it is faster" for a linked list: the advantage is that only the pointers change.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A browser's Back and Forward buttons

Two stacks hold the pages you have left: Back pops the most recent page, and the page you are leaving is pushed onto the Forward stack.

Exam use: stack.

Undo in a document

Each change is pushed on a stack; Undo pops the most recent change.

Exam use: stack.

A printer queue

Print jobs are added at the end and the printer takes the job at the front, so the first to arrive is printed first.

Exam use: queue.

A keyboard buffer

Key presses wait in a circular buffer until the program reads them in the order they were typed.

Exam use: circular queue.

A music playlist

Each track holds a pointer to the next one, so a track can be inserted anywhere without moving the others.

Exam use: linked list.

Top tips

  • Name the end of each structure. Top of stack; front and end of queue; start, null and free pointers.
  • Check full and empty. Before adding or removing.
  • Read how the stack grows. Up or down memory; pointer at last value or next free.
  • Wrap round. Circular queue pointers return to the first location.
  • Only pointers change. Linked list inserts and deletes move no data.
  • Show every pointer. A linked list diagram needs start and null.
