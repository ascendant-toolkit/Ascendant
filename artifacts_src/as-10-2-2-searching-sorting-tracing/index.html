Searching, Sorting and Dry Runs

Coursebook: Chapter 10 · Data types and structures · section 10.2 Arrays

Linear and binary search, bubble and insertion sort with the efficient bubble sort and a BYREF swap, and how to complete trace tables, with animations, labs and the real Paper 2 questions from 2021 to 2026.

This page in five sentences

A linear search checks each element in turn until the target is found or the end is reached; a binary search works on a sorted array: compare with the middle element and discard the half that cannot contain the target (LeftPointer and RightPointer move, MidPointer ← (Left + Right) DIV 2). A bubble sort repeatedly compares neighbouring elements and swaps them if they are in the wrong order; an insertion sort takes each element (the key) and shifts larger elements right to insert it in the right place. A bubble sort is made more efficient by reducing the inner loop's boundary by one each pass (the largest value is then in place) and by stopping the outer loop when a pass makes no swaps. A dry run with a trace table records the value of each variable after each statement; in an exam you fill in the table row by row, starting from the initial values.

A linear search needs no sorting and works on any array: loop through the elements, compare each with the target, stop when found (a flag in a WHILE or a REPEAT), and report 'not found' after the loop if it was never found.

2 · Sorting

// bubble sort A (ascending)FOR LoopCounter ← 1 TO 999   FOR Index ← 1 TO 999      IF Numbers[Index] > Numbers[Index + 1] THEN         Temp ← Numbers[Index]         Numbers[Index] ← Numbers[Index + 1]         Numbers[Index + 1] ← Temp      ENDIF   NEXT IndexNEXT LoopCounter
  • Descending order: change the > in the comparison to <.
  • More efficient version (B): the inner loop runs to Boundary, which falls by one each pass because the largest remaining value is now in place; the outer loop is a REPEAT that stops when NoSwaps is TRUE (a pass made no swaps). The outer loop runs the minimum number of times (once) when the array is already sorted.
  • Swap procedure: parameters must be passed by reference, otherwise the procedure changes copies and the array is unchanged: PROCEDURE Swap(BYREF Num1, Num2 : INTEGER).

Insertion sort of D, T, H, R: the key is taken in turn, larger elements to its left shift right and the key is inserted. Final order D H R T.

3 · How to dry-run a procedure

  1. Write down the starting values of every variable and array element in the first row.
  2. Execute one pass of the loop at a time, writing a new row after the statements that change values; copy unchanged values only if the table needs them.
  3. Check the loop condition every pass, using the new values; stop when it fails.
  4. Do any final assignment after the loop in a last row.

Example: Process(3) with Mix = 1, 3, 4, 2; each pass sets Value ← Mix[Index], reduces Mix[Index] by 1, sets Index ← Value and adds 1 to Count; after five passes Mix[4] ← Count × Index.

Common ways to lose marks

  • Doing two passes of a loop in one row of the trace table.
  • Forgetting to carry unchanged values, or changing a value in the wrong row.
  • Using BYVAL parameters in a Swap procedure.
  • Describing the efficient bubble sort without both the shrinking inner loop and the early stop of the outer loop.
  • Using binary search on an unsorted array.

Looking up a name in a phone book

You open near the middle, see whether the name comes before or after, and discard half the book each time: a binary search.

Exam use: binary search.

Sorting playing cards in your hand

You pick up each card and slide it into the right place among the cards you already hold: insertion sort.

Exam use: insertion sort.

Searching an unsorted list

A shopping list in random order must be checked item by item: linear search.

Exam use: linear search.

Why sort at all

Once data is sorted a binary search finds an item in a few steps, even in millions of records.

Top tips

  • One pass, one row. Carry unchanged values.
  • Read the old values first. Then update Index.
  • Binary search: sorted data. Mid ← (Left + Right) DIV 2.
  • Efficient bubble: two changes. Shrinking boundary; stop on no swaps.
  • BYREF for Swap. Otherwise the array is unchanged.
  • Check the loop condition each pass. Using the new values.
