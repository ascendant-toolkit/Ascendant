Karnaugh Maps

Coursebook: Chapter 15 · Hardware and virtual machines, section 15.2 Boolean algebra and logic circuits

Karnaugh maps for three and four inputs: Gray code layout, looping the 1s, wrap-around, reading the terms and simplifying; animations, a K-map builder and the real Paper 3 questions from 2021 to 2026.

This page in five sentences

A Karnaugh map (K-map) is a grid that shows a truth table so that neighbouring cells differ in exactly one input, which makes simplification a matter of drawing loops instead of using Boolean algebra. The rows and columns are labelled in Gray code (00, 01, 11, 10), not in binary order. You loop groups of 1s in sizes 1, 2, 4, 8 or 16, as large as possible, and the loops may wrap round the edges. Each loop becomes one AND term made of the inputs that do not change inside the loop, and the terms are joined with OR to give the simplified sum-of-products. A K-map is guaranteed to give an optimal sum-of-products, which is why the exam uses it.

1 · The layout

With four inputs the columns are A B and the rows are C D. The number in each cell is the row number of the truth table (A is the most significant bit), so cell 11 is row 1011.

With three inputs the paper puts A down the side and B C across the top:

A \ BC00011110
00132
14576

Gray code matters: going from 01 to 11 changes only A, and going from 11 to 10 changes only B, so any two cells side by side differ in one input. The last column (10) is also next to the first (00) because 10 and 00 differ in one bit, so the edges wrap round.

2 · Filling in the map

  • From a truth table: for each row put the output value in the cell with that row's inputs. Row 1011 goes in column A B = 10 and row C D = 11.
  • From a sum-of-products: each full product term (every input present) is one cell, so write 1 in the cell it names and 0 everywhere else. A.B.C is A = 1, B = 0, C = 1.
  • Write the 0s as well: the mark scheme says "0s must be present".

3 · Looping the 1s

  1. Every 1 must be in at least one loop.
  2. A loop is a rectangle of 1, 2, 4, 8 or 16 cells (a power of two), containing only 1s, with sides of the grid next to each other.
  3. Make each loop as large as possible, and use as few loops as possible. Loops may overlap.
  4. Loops may wrap round the left and right edges, round the top and bottom edges, and the four corners together make a loop of four.
  5. No diagonals.

Reading a loop

Look at the labels along the loop's rows and columns. An input that is always 1 across the loop goes into the term as it is. An input that is always 0 goes in with a bar. An input that changes is left out. A loop of 2 drops one input, a loop of 4 drops two, a loop of 8 drops three.

CD \ AB00011110

Groups: A.B B.D C.D

The bottom row CD = 11 (loop of 4) is always C = 1, D = 1, so it gives C.D. The AB = 11 column (loop of 4) gives A.B. The block in the middle where B = 1 and D = 1 (loop of 4) gives B.D. Together: X = A.B + B.D + C.D. Do not carry out any further simplification unless asked.

A 3-input example (O/N 2025, Paper 31): the 1s are in cells 2, 3, 5 and 6.

A \ BC00011110
000011312
104150716

Groups: A.B A.B.C B.C

The top row loop of two (A = 0, B = 1) gives A.B; the right-hand column loop of two (B = 1, C = 0) gives B.C; the cell A = 1, B = 0, C = 1 cannot be joined to anything, so it is a loop of one with all three inputs: A.B.C.

4 · Taking it further with algebra

Some questions then ask for the answer in its simplest form using Boolean algebra. Take out a common factor: A.B + A.D = A.(B + D) and A.B + B.D = B.(A + D).

5 · Why use a K-map?

The mark scheme gives: solving logic expressions with a K-map is easier because you do not need to use Boolean algebra; it is guaranteed to give an optimal solution; it converts a complex logic problem into a simpler one. "It makes it easier" on its own does not score.

6 · Common ways to lose marks

  • Writing the columns in binary order (00, 01, 10, 11) instead of Gray code (00, 01, 11, 10).
  • Looping a group that is not a power of two, such as three cells.
  • Leaving a loop smaller than it could be: a loop of 2 inside a possible loop of 4 gives a longer term.
  • Forgetting wrap-around: the left and right columns, and the top and bottom rows, are neighbours.
  • Putting the changing input into the term. Only the inputs that are constant inside the loop belong.
  • Leaving out the 0s when completing the map.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Designing a chip with fewer gates

Chip designers simplify the control logic. A K-map turns the truth table of a small circuit into the smallest set of AND and OR terms, so fewer gates are used.

Exam use: a simplified sum-of-products needs fewer gates.

A seven-segment display

Each segment of a digit display lights for certain values of four input bits. A K-map for each segment gives the simplest wiring from the 4-bit number to the segment.

Exam use: four inputs, a 4 by 4 K-map.

Traffic light and lift controllers

The logic that decides when to change lights or open a door has many inputs. Simplifying with K-maps reduces cost and removes unneeded conditions.

Exam use: fewer terms, fewer wires, fewer faults.

Don't-care conditions

Some input combinations never happen. Designers can loop those cells with the 1s to get larger groups and simpler logic. (The exam does not ask this.)

Exam use: larger loops give simpler terms.

Checking an answer

If you are not sure your loops are right, write the truth table for your simplified expression and compare it with the original.

Exam use: the two truth tables must match.

It is Gray code: only one input changes between neighbouring cells, including from the last column back to the first So adjacent 1s can be grouped, and the group has terms in which one input has been eliminated

State 3 marks State the rules for forming a loop on a K-map.
ReminderSize, shape and contents.

The loop contains only 1s Its size is a power of two: 1, 2, 4, 8 or 16, and it is a rectangle with no diagonals Loops should be as large as possible; they may overlap and may wrap round the edges

Describe 3 marks A loop of four covers the cells with A = 1 and B = 1, for every value of C and D. State its term and the number of inputs it drops.
ReminderWhich inputs are constant?

A is always 1 and B is always 1, so the term contains both C and D change inside the loop, so they are left out Term A.B: two inputs dropped

Top tips

  • Gray code order. Label columns and rows 00, 01, 11, 10.
  • Write the 0s. The mark scheme says 0s must be present.
  • Loop only 1s, in powers of two. 1, 2, 4, 8 or 16. Large loops, few loops.
  • Check the edges. Left and right edges, top and bottom, and the four corners wrap round.
  • Constant inputs go in the term. Always 1: plain. Always 0: barred. Changing: left out.
  • Do not simplify further unless asked. 'Do not carry out any further simplification'.
