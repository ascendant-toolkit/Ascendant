Virtual Memory, Paging and Segmentation

Coursebook: Chapter 16 · System software, section 16.1 Purposes of an operating system

Virtual memory, paging with page tables, segmentation, page replacement and disk thrashing; animations, address-translation and page-replacement labs and the real Paper 3 questions from 2022 to 2024.

This page in five sentences

Virtual memory uses part of secondary storage (the disk) to extend main memory (RAM), so the CPU appears to be able to use more memory than is physically installed; only the data in use needs to be in RAM and the rest is swapped in and out as necessary. It is managed by paging, which divides memory into fixed-size blocks (pages in the logical address space, frames in physical memory), or by segmentation, which divides it into variable-size logical segments such as code, data and stack. A page or segment table maps the logical address the program uses onto a physical address in RAM. When RAM is full a page has to be replaced: the OS chooses one to move out to disk to make room. If too much swapping takes place the computer suffers disk thrashing: more time is spent moving pages than running programs.

1 · Why virtual memory is needed

  • RAM is limited, and running many processes at once could need more memory than is installed.
  • Programs and data that are not needed immediately can be moved from RAM to virtual memory on the disk, which makes efficient use of RAM and the processor.
  • Virtual memory is created temporarily when it is needed, using space on the disk.
  • It is slower than RAM, because the disk is much slower.

2 · Paging

In paging the memory is divided into blocks of the same fixed size. The program's (logical) address space is divided into pages; physical memory into frames of the same size. Any page can go in any free frame, so the frames used by a program need not be next to each other.

  • A page table records, for each page, the frame it is in (or that it is not in memory).
  • A logical address is a page number and an offset within that page. The OS uses the page table to find the frame, then adds the offset: physical address = frame number × page size + offset.
  • Only the pages in use need to be in RAM. If the CPU needs a page that is not in RAM there is a page fault: the OS reads the page from the disk into a free frame (or into a frame freed by replacing another page).
  • The OS divides memory into pages (not the programmer).

Example. Page size 1024 bytes. Logical address 3000 is in page 3000 ÷ 1024 = 2 (remainder 952): page 2, offset 952. If the page table says page 2 is in frame 7, the physical address is 7 × 1024 + 952 = 8120.

3 · Segmentation

In segmentation the logical address space is divided into segments of varying size, usually the logical parts of a program such as the main code, a procedure, the data or the stack. The size of each segment is decided by the program or the compiler, not by the OS.

  • Each segment has a name or number and a size. Segments are numbered, and the number is used as an index in a segment map table that maps logical addresses to physical addresses.
  • A logical address is a segment number and an offset. The offset must be within the size of the segment.
  • During execution, segments from virtual memory are loaded into physical memory.

4 · Replacing pages

When a page fault occurs and no frame is free, the OS must pick a page to remove (a victim). If that page has been changed since it was loaded, it is written back to the disk first. The syllabus does not name the algorithm; two common ones are first in first out (replace the page that has been in memory longest) and least recently used (replace the page not used for the longest time). A good choice keeps the pages that are about to be needed in RAM.

5 · Disk thrashing

Disk thrashing can occur when virtual memory is being used and main memory is full. More and more pages have to be swapped between RAM and the disk, so there is a very high rate of disk accesses and the read/write head moves constantly. Moving the head takes a long time, so eventually more time is spent swapping pages than processing data (the thrash point), and programs may freeze or fail to run.

It can be reduced by installing more RAM or by running fewer programs at once.

6 · Common ways to lose marks

  • Saying virtual memory is "the same as RAM" or "a type of RAM". It is disk space used as an extension of memory.
  • Giving the difference between paging and segmentation without both sides: pages are fixed size, segments are variable size.
  • Describing segmentation without the segment number, the offset and the segment map table.
  • Explaining thrashing as "the disk wearing out". It is excessive swapping, so more time is spent on swapping than on processing.
  • Forgetting the cause of thrashing: main memory is full while virtual memory is in use.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A computer slows down when you open too many programs

The OS moves pages out to the disk to make room. If you open even more, it spends its time moving pages back and forth: thrashing. Closing programs or adding RAM helps.

Exam use: disk thrashing: more time swapping than processing.

A very large game on a computer with little RAM

Only the parts of the game in use are kept in RAM; the rest wait on the disk and are paged in when needed. The game runs, but loading pauses are noticeable.

Exam use: virtual memory extends RAM.

A library with a few reading desks

The desks are RAM and the stacks are the disk. You keep only the books you are using on the desk and fetch others when needed. If you keep swapping books, you spend more time walking than reading.

Exam use: swapping and thrashing.

Chapters and pages of a book

Paging splits the book into equal pages whatever is on them. Segmentation splits it into chapters of different lengths because each chapter is a logical unit.

Exam use: fixed size against variable size.

Fitting furniture into rooms

Paging is like cutting everything into identical boxes so they fit anywhere; segmentation keeps each piece whole, so it needs a space big enough for it.

Exam use: frames can be anywhere; segments need contiguous blocks.

(b) Any three: Disk thrashing may occur when frequent transfers take place between main memory and secondary memory, or when virtual memory is being used As main memory fills up, more pages need to be swapped in and out of virtual memory This swapping leads to a very high rate of hard disk head movements Eventually more time is spent swapping the pages than processing the data

Top tips

  • Virtual memory uses the disk. It extends RAM; the CPU appears to have more memory.
  • Paging: fixed. Segmentation: variable. Pages and frames are the same size; segments differ.
  • Segmentation answers. Segment number, offset, segment map table.
  • Page fault. The page is not in RAM: load it from the disk, replacing another if RAM is full.
  • Thrashing needs a cause. Main memory full, constant swapping, more time swapping than processing.
  • Fix thrashing. More RAM or fewer programs.
