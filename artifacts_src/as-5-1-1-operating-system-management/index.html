The Operating System and its Management Tasks

Coursebook: Chapter 5 · System software · section 5.1 Operating systems

The purposes of an operating system and its key management tasks (process, memory, file, security and hardware), with animations, labs and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

The operating system (OS) is system software that hides the complexity of the hardware from the user, provides a platform for application software to run and provides a user interface. Its key management tasks are process management (scheduling which process runs next, multitasking, resolving conflicts), memory management (allocating RAM to processes and freeing it), file management (organising files and folders on storage), security management (users, passwords, access rights) and hardware management (device drivers, input and output, interrupts, buffers). A question usually asks you to identify tasks (a name per mark) or to describe them (a name and a matching description). Give a specific description for each task, not just its name. Interrupts and buffers belong partly to hardware management.

1 · Purposes of an operating system

  • To hide the complexities of the hardware from the user and from application programs.
  • To provide a platform for application software to run on.
  • To provide a user interface so the user can communicate with the computer.

2 · The key management tasks

TaskWhat it does
Process managementDecides which process runs next (scheduling) and allocates time slices; moves processes between states (ready, running, waiting); supports multitasking so several programs seem to run at once; resolves conflicts when two processes need the same resource; allows processes to share data and prevents them interfering with each other
Memory managementAllocates RAM to processes when they start and frees it when they close; makes sure two processes do not access the same memory; controls the movement of data between RAM, the processor and virtual memory
File managementDivides storage into file allocation units and allocates space to files; creates and maintains directory (folder) structures; names, creates, renames, opens, closes, copies, moves and deletes files; sets the logical file system (such as FAT or NTFS); controls access, access rights and sharing; marks unallocated space as available
Security managementPrevents unauthorised access by validating users and processes (accounts and passwords); implements access rights and permissions; provides or updates a firewall and anti-malware; provides recovery of lost data; applies OS security updates; keeps logs and audits activity
Hardware managementInstalls and loads device drivers for devices connected to external ports; manages communication between devices and the computer, sending data to output devices and receiving it from input devices; handles buffers for different speeds; manages hardware interrupts

3 · Multitasking

With one processor core the OS shares processor time between processes in time slices: each process runs for a short slice, is paused, and the next one runs. This happens so fast that the user sees several programs running at once. The OS decides the order using a scheduling algorithm (for example giving a high-priority process more or earlier time) and keeps each process's registers so it can resume exactly where it stopped.

Common ways to lose marks

  • Listing only the task name when the question says "describe". Add what it does.
  • Describing file management as "storing files". Say it creates directories, allocates space and controls access.
  • Mixing process and memory management: scheduling is process management; allocating RAM is memory management.
  • Saying hardware management "controls the hardware". Say it installs device drivers, manages communication and interrupts.
  • Saying the OS is "the interface". That is one purpose among three.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Running music while you type

The OS gives the music player and the word processor turns on the processor, so both seem to run at the same time.

Exam use: multitasking: process management.

Plugging in a printer

The OS finds and loads the printer's driver so programs can print without knowing how the printer works.

Exam use: hardware management hides complexity.

Logging into a school computer

Your account decides which files you can open: the OS checks your identity and your access rights.

Exam use: security management.

Closing a program frees memory

When you close an app, the OS takes its RAM back so another program can use it.

Exam use: memory management.

Creating a new folder

The OS records the folder in its directory structure and later finds the files stored in it.

Exam use: file management.

Top tips

  • Name each task, then describe it. Marks come in pairs.
  • Three purposes. Hide hardware, platform, user interface.
  • Process: scheduling. Memory: allocate and free RAM.
  • File: directories, space, access. Not just 'stores files'.
  • Hardware: drivers and interrupts. Security: accounts and rights.
  • Use the scenario. A printer, a login, a new app.
