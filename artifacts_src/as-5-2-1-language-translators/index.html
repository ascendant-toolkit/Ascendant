Coursebook: Chapter 5 · System software · section 5.2 Language translators

The assembler, the compiler and the interpreter compared, why partial compilation is used, and which translator suits development or a finished program, with animations, a compile-or-interpret lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

A language translator converts a program written in one language into machine code that the processor can run. An assembler translates assembly language into machine code. A compiler translates the whole high-level program in one go, reporting all errors together, and if there are none it produces an executable file (object code) that runs without the source code. An interpreter translates and runs the program one line at a time, stopping at the first error so the programmer can correct it immediately and carry on. Interpreters are better during development (easier to debug, can test unfinished programs); compilers are better for the finished program (fast to run, source code stays private). Some languages are partially compiled and partially interpreted: the source is compiled to an intermediate code and interpreted at run time.

1 · Compiler and interpreter compared

CompilerInterpreter
TranslatesAll the code at the same time, then the program is runOne line at a time, then runs that line
OutputAn executable (object code) file that can run without the source codeNo executable file: the source code is needed every time the program runs
ErrorsChecks all the code first and reports all errors together; the program does not run if there are errors; one error can cause false extra errorsStops at the first error and displays it; the error can be corrected immediately (in real time) and translation continues from that line
Best forThe finished program (it runs faster, and the source code is not distributed)Development: debugging line by line, testing unfinished code or small sections

2 · Drawbacks of a compiler during development

  • Large amounts of source code take time to compile; it can be slower to produce the object code than an interpreter.
  • The code must be recompiled whenever it is changed.
  • The program cannot run if there are any errors, and errors cannot be corrected in real time.
  • One error can cause false reporting of other errors.
  • Sections of code or unfinished code cannot easily be tested.

3 · Advantages of an interpreter

  • Easier to debug: it translates line by line and stops when an error is found, reporting one error at a time.
  • The error can be corrected in real time and the program restarts from the same point.
  • The effect of changes can be seen immediately, and a partially completed program can be translated and tested.

4 · Partially compiled and partially interpreted languages

Some languages compile the source into an intermediate code that is then interpreted when the program runs. Reasons: the compiled program can be used on different platforms because it is interpreted at run time; the machine code is optimised for the CPU at run time; and the source code does not need recompiling for each machine, so it is efficient to run.

Common ways to lose marks

  • Saying a compiler "translates line by line". That is the interpreter.
  • Writing that an assembler translates "high-level language". It translates assembly language into machine code.
  • Saying interpreted programs "run faster". Compiled programs usually run faster.
  • Describing the advantage of an interpreter with no development context, such as "it is easier". Say it stops at the first error so it can be corrected in real time.
  • Forgetting that the compiler produces an executable file that runs without the source code.

Examples are explained in general terms. Check current details before quoting them in an exam answer.

An app downloaded from a store

The app is compiled: you get an executable and cannot see or run the source code.

Exam use: compiled programs run without the source.

Learning to program in a notebook

Python runs each line as you type, so you can run half a program and fix a mistake immediately.

Exam use: interpreter, good for development.

A website's JavaScript

The browser interprets the code line by line on your machine, so the same page works on any device.

Exam use: interpreted at run time.

Java programs

Java is compiled to an intermediate code that a runtime then runs on any platform: partially compiled and partially interpreted.

Exam use: platform independence.

Writing assembly for a tiny chip

An assembler turns each mnemonic into one machine instruction for that chip.

Exam use: assembler.

Top tips

  • Compiler: whole program. Executable file; all errors together.
  • Interpreter: one line. Stops at the first error.
  • Say 'real time'. Errors corrected immediately.
  • Assembler: assembly to machine code. Never high-level.
  • Pair each point with its reason. Different platforms because it is interpreted.
  • Development: interpreter. Finished: compiler. Say which stage.
