This page in five sentences

An array stores many values of the same data type under one identifier; each element is reached by an index. A 1D array is declared with its bounds and type, DECLARE Data : ARRAY [1:30] OF REAL; a 2D array has two bounds, DECLARE Version1 : ARRAY [0:2, 1:15] OF CHAR (floor, room). Before an array can be declared you must know its data type (and its size). Arrays are processed with a loop whose counter is the index: to total or count, initialise before the loop; to find the largest or smallest, start with the first element and replace it when a better one is found; to search, compare each element and stop when found. The benefits of an array over separate variables are that the algorithm is simpler and easier to write, understand and test, you can use a loop to iterate through the values, and many values are stored under a single identifier.

1 · Declaring and using arrays

DECLARE RNum : ARRAY [1:100] OF INTEGERDECLARE Data : ARRAY [1:120] OF REALDECLARE Version1 : ARRAY [0:2, 1:15] OF CHAR RNum[5] ← 42Version1[0, 3] ← 'A'          // floor 0, room 3OUTPUT Data[Index]

Bounds are inclusive: [1:100] has 100 elements and [0:2, 1:15] has 3 × 15 = 45. Use the loop counter as the index: FOR Index ← 1 TO 100. For a 2D array, use one loop for the first index and another for the second if the whole array is needed.

Unique random values: initialise the array to a rogue value, and for each element generate a number, check it against the values already stored, generate another if it is found, otherwise store it.

Common ways to lose marks

  • Declaring the array without its type, or with the wrong bounds (an array of 120 elements is [1:120]).
  • Using a loop that goes one too far (an index of 101 in a 100-element array) or one too short.
  • Initialising the total, count or maximum inside the loop.
  • Comparing the loop counter instead of the element: IF Index > Max instead of IF Data[Index] > Max.
  • Outputting the count or total inside the loop when the question asks for a final value.

Top tips

  • Declare: bounds and type. ARRAY [1:120] OF REAL.
  • Initialise before the loop. Total, Count, Max.
  • The loop counter is the index. Data[Index], not Index.
  • 2D arrays: two loops or two indexes. [floor, room].
  • Output after the loop. A final count or total.
  • Three benefits. Simple, iterate, one identifier.
