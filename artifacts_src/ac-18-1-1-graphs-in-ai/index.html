Graphs in Artificial Intelligence

Coursebook: Chapter 18 · Artificial Intelligence, section 18.1 Artificial Intelligence

The purpose and structure of a graph: nodes, edges, weights, paths and cycles, and why graphs aid AI; animations, a path explorer and the real Paper 3 questions from 2021 and 2025.

This page in five sentences

A graph is a data structure (an abstract data type) made of vertices (also called nodes) that represent things, joined by edges that represent the relationships or connections between them. In artificial intelligence a graph is used to record relationships between entities, for example places on a map and the distances between them, so that an algorithm can search it for the best path. Edges (and sometimes nodes) can carry a weight such as a distance, cost or time. A path is a list of nodes connected by edges from one node to another; a cycle is a path that returns to the node it started from. Many AI problems can be defined as finding a path in a graph, and neural networks can themselves be drawn as graphs.

1 · Structure of a graph

TermMeaningIn the graph above
Vertex / nodeAn entity: a place, a person, a stateA, B, C, D
EdgeA connection between two nodes (an arc)A–B, A–C, B–C, B–D, C–D
WeightA value on an edge: distance, cost, timeThe numbers 4, 2, 1, 5, 8
PathThe list of nodes connected by edges between two given nodesA, C, B, D (cost 2 + 1 + 5 = 8)
CycleA list of nodes that returns to the same nodeA, B, C, A
NeighboursNodes joined to a node by an edgeThe neighbours of C are A, B and D

The graph above is undirected: an edge can be used in either direction. A directed graph has arrows, so an edge can only be followed one way, as in a one-way street. A graph with weights is a weighted graph; the shortest path between two nodes is the path whose weights add up to the least. Which path has the fewest edges is not always the cheapest: from A to D, A–B–D has 2 edges and costs 9, but A–C–B–D has 3 edges and costs 8.

2 · Storing a graph

A graph can be stored in a program as an adjacency matrix (a table with a row and a column for every node, holding the weight where there is an edge) or an adjacency list (each node with a list of its neighbours and weights). You will not be asked to write code for a graph.

3 · Why graphs are used in AI

  • They record relationships between entities in a way algorithms can use: places and the distances between them, people in a social network, web pages and links.
  • Many AI problems can be defined as finding a path in a graph: the best route for a delivery van or a satnav, the shortest route a game character takes, or the sequence of moves that reaches a goal.
  • Graphs can be analysed by a range of algorithms, for example Dijkstra's algorithm and the A* algorithm (next page), which are used in machine learning and path-finding.
  • Artificial neural networks can be represented as graphs: neurons are nodes and the weighted connections are edges.

To justify using a graph for a situation, say what the nodes are, what the edges and weights are, and what question the graph will answer. For example, for a delivery company: nodes are towns, edges are roads, weights are distances, and the graph is searched for the shortest route.

4 · Common ways to lose marks

  • Describing a graph as a chart or a bar graph. In AI a graph is a set of nodes and edges.
  • Mixing up nodes and edges: nodes are the entities, edges are the connections.
  • Not saying what the weights mean when a question gives a situation.
  • Writing that a graph "finds" the route. The graph stores the data; an algorithm such as Dijkstra's finds the route.
  • Choosing the path with the fewest nodes instead of the lowest total weight.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

A satnav

Junctions are nodes, roads are edges and the distances or journey times are weights. The satnav searches the graph for the cheapest route.

Exam use: a graph stores places and distances for a path search.

Social networks

People are nodes and friendships are edges. The graph lets a site suggest people you might know, a friend of a friend.

Exam use: graphs record relationships between entities.

A video game map

Characters move across a graph of locations. The game uses it to find a route round obstacles.

Exam use: path-finding in games.

Rail and flight networks

Stations or airports are nodes and services are edges weighted by time or cost, so a planner can find the quickest or cheapest journey.

Exam use: weighted edges.

The internet

Routers are nodes and links are edges. Routing protocols use graph algorithms to decide where to send packets.

Exam use: networks are graphs.

Top tips

  • Nodes and edges. Nodes are the entities; edges are the connections.
  • Weights mean something. Distance, cost or time: say which.
  • Path v cycle. A path joins two nodes; a cycle returns to its start.
  • A graph stores; an algorithm searches. Dijkstra's and A* find the best path.
  • Fewest edges is not cheapest. Add up the weights.
  • Justify with a situation. Say what the nodes, edges and weights are.
