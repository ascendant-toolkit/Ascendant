Command Words and Mark Allocation: Answering What Is Asked

How the command word and the mark tell you what to write, how to turn a description into an explanation, why technical terms and context matter, and fourteen real questions with what the mark scheme wanted.

This page in five sentences

Every question in Paper 1 and Paper 2 has a command word and a mark, and together they say how much to write and what kind of sentence earns credit. A state or identify question wants a short fact, a describe question wants the features, and an explain question wants a reason, so it earns marks only when it says why or how. The examiner reports for every recent series ask for the same three habits: use technical terms, use the context in the question, and answer the command word. Mark schemes mostly award one mark per point, often in pairs of a point and the reason that goes with it, so a 4-mark explain question needs two points with a reason each. A wrong extra statement does not lose a mark (the generic marking principles say marks are not deducted for errors), but a sentence that repeats the question or lists without saying how it helps earns nothing.

1 · The command words in the syllabus

The syllabus lists these words and says the way each is used relates to the subject context. The right-hand column is what to write.

Command wordWhat the syllabus means by itWhat to write
IdentifyName, select or recogniseThe name only: tick the box, circle it, or write one word. Extra explanation earns no extra mark.
StateExpress in clear termsOne clear statement for each mark, with no reasoning.
GiveProduce an answer from a source or from memoryA recalled fact or an example, kept short.
DefineGive the precise meaningThe exact meaning using the technical term. "An address for a website" is too vague; "a text-based address" is the detail the mark scheme looks for.
OutlineSet out the main pointsUsually a name and a short expansion, for example the type of check and how it works.
DescribeState the points of a topic: its characteristics and main featuresWhat it is made of or what happens, in parts or in order. It says what, not why.
ExplainSet out purposes or reasons; make relationships clear; say why and/or how, with supportA point plus its reason or effect, joined with so, because or which means.
CompareComment on similarities and/or differencesBoth items in every point. "Hexadecimal uses letters" is half a comparison.
SuggestApply knowledge to a situation with a range of valid answers; put forward considerationsA sensible choice that fits the scenario, with a reason. Several answers are accepted, but a generic one is not.
Calculate, Show (that), DemonstrateWork out from facts; give structured evidence leading to a result; show howWorking in the form asked, such as binary addition with the carries shown, then the answer.

4 · One topic, three command words

Take parallel data transmission. The same fact is written three ways, depending on what the question asks.

QuestionA full-mark style answer
State what parallel transmission does [1]It sends several bits at the same time.
Describe parallel full-duplex transmission [3]Several bits are sent at the same time, each along its own wire. Data can travel in both directions at the same time.
Explain why a company used parallel full-duplex between computers in one room [4]Several bits are sent at once along several wires, so data arrives quickly. The computers are in one room, so the data does not travel far and the bits stay in step. Data goes both ways at once, so users can send to each other with no delay.

The examiner report for Oct/Nov 2024 (paper 11) notes that some candidates described how data is transmitted instead of explaining why the company would choose that method. A description of the method scores few marks when the question is "why".

5 · Differences, advantages and drawbacks

  • Both sides in every difference. The report for paper 12 says some candidates gave one difference split across two answer lines, and that "hexadecimal uses letters" alone is not enough because it never mentions binary.
  • An advantage is not a difference. The report for paper 13 says some candidates wrote that Unicode uses more bits than ASCII without saying what the advantage is. The advantage is that more characters, symbols and languages can be represented. The drawback is that each character needs more storage.
  • Say which way something changes. The report for the March 2024 series says "the clock speed increases the performance" does not state whether the clock speed went up or down. Write "a higher clock speed means more instructions are carried out each second".

7 · Writing a 4-mark explanation

  1. Read the command word and the marks. 4 marks for an explanation usually means two points, each with its reason.
  2. Underline the key term and the scenario: "cloud storage", "smartwatch app".
  3. Write a point that uses a technical term, then a link word, then the effect: so, which means, because, this allows.
  4. Apply the "so what?" test. After each sentence ask "so what?" and keep writing until the answer is a consequence for the user, the device or the data.
  5. Check that each pair uses a technical term and fits the context in the question.
Link wordUse it forExample
soResult"It has no moving parts, so the data is less likely to be lost if the phone is dropped."
which meansConsequence for the user"The provider maintains the servers, which means the user does not need to buy or look after hardware."
becauseReason"Serial is more reliable over a long distance because the bits arrive in order."
this allowsPurpose"An IDE has a run-time environment, which allows the programmer to run the program and see the output."

8 · Common ways to lose marks

  • Repeating the question in the answer ("the values do not match so an error has occurred") without saying why a mismatch means an error.
  • Listing without saying how it helps, in any question that says explain.
  • Generic answers that could be about any device, when the question names a smart phone, a smartwatch, a plough or a robot vacuum.
  • One-sided comparisons: only one item mentioned.
  • Brand names: the paper states that no marks are awarded for brand names of software or hardware.
  • Answers on extra pages without saying clearly which question they belong to, as the reports remind candidates.
Exam tipBefore writing, circle the command word and write the number of marks next to it. After writing, put a tick beside each separate point. If you have fewer ticks than marks, find the missing point or the missing reason.

6 · Multiple choice

These come from the Principal Examiner Reports for Cambridge IGCSE Computer Science, which describe what candidates actually wrote. The wording is ours.

A list of features, not an explanation

Oct/Nov 2024, paper 11: asked how the features of an IDE help a programmer, many candidates only listed features. Few went on to describe how each feature helps. The mark scheme caps the stating of features at four of the six marks.

Exam use: any 'explain how' question with a list of items: name the feature, then say what it lets the user do.

A mouse in a smart phone

Oct/Nov 2024, papers 11 and 12: some candidates gave a mouse or keyboard as input devices, and a printer as an output device, for a smart phone or smartwatch. The accepted answers are devices built into the product: touchscreen, microphone, camera, screen, speaker.

Exam use: 'suggest' and 'give' questions set in a scenario: choose items that really fit the device.

Vague about the URL

Oct/Nov 2024, paper 12: many candidates described a URL as 'an address for the website'. The mark scheme asks for a text-based address for a website or web page.

Exam use: define questions: include the technical detail that makes the definition exact.

Describing machine learning instead of using it

Oct/Nov 2024, papers 12 and 13: asked how a robot vacuum and a plough could use machine learning or AI, many candidates only described what AI is. The mark scheme rewards gathering data, adapting the machine's own process, and an example such as obstacles or the route.

Exam use: 'how could X use Y' questions: say what data X gathers, what it changes and what the benefit is.

Encryption does not stop theft

Oct/Nov 2024, paper 13: some candidates believed encryption stops data being stolen. It makes stolen data meaningless to the thief, which is what the mark scheme accepts.

Exam use: avoid statements that are almost true: 'prevents' versus 'makes meaningless'.

Storage versus transmission

Oct/Nov 2024, paper 12: asked for a benefit of compressing a file for storage, some candidates gave a benefit for transmission. Both are true benefits of compression, but only one answers the question.

Exam use: read the last words of the question: for storage, for transmission, for the user, for the programmer.

Based on Oct/Nov 2024 · 0478/11 · Q6(e) [6] A programmer uses an integrated development environment (IDE) to write the assembly language program for an embedded device. Explain how the features of an IDE help the programmer.
What the mark scheme wants
  • Six marks: up to four for naming features, so at least two must come from saying what a feature does
  • Code editor: lets the programmer enter and change the program
  • Run-time environment: lets the program be run so the output can be seen
  • Error diagnostics: show the programmer where the errors are
  • Auto-completion: offers suggestions for commands
  • Auto-correction: fixes a command with a small spelling error
  • Pretty-print: changes the colour of key words so they are easy to spot
Plan

Choose three features and write each as a pair: the name, then 'which allows the programmer to…'. Three pairs make six marks. Six names with no purpose cap at four.

Technical knowledge (K)Applied to the context (A)

An IDE has error diagnostics, which show the programmer the line where each error is, so faults in the program for the device can be found and fixed quickly.

It has a run-time environment, which lets the programmer run the program and see its output without leaving the IDE.

It has a code editor, which lets the programmer type and change the assembly program in one place.

Based on Oct/Nov 2024 · 0478/13 · Q7 [4] Explain the purpose of an integrated development environment (IDE).
What the mark scheme wants
  • Any four from: it is software used to write, develop and edit code
  • It is used to test and debug the code
  • It has features, with a suitable example such as auto-completion
  • It can translate the code into machine code or a low-level language
Plan

'Purpose' means what it is for, not a list of features. State the job (write and edit code), then the other jobs (test, debug, translate), and add a feature as the example.

Technical knowledge (K)Applied to the context (A)

An IDE is a piece of software used to write and edit code in one place. It is also used to test the program and find faults, with features such as auto-completion that suggest commands as the programmer types.

It can translate the code into machine code, so the programmer can run and test the program without a separate tool.

Based on Oct/Nov 2024 · 0478/11 · Q7(a)(ii) [2] Identify one function of an operating system other than handling interrupts, and describe what it does.
What the mark scheme wants
  • One mark for the function, one for a matching description
  • Memory management: deciding what is stored where in memory
  • Managing peripherals and drivers: managing communication with connected input and output devices
  • Multitasking: switching between tasks that are running
  • Platform for running applications: lets application software communicate with the hardware
  • System security: for example a username and password
  • User accounts: allowing several accounts on one computer
Plan

A pair: name, then what it does. The report says many candidates named a function but did not describe its purpose.

Based on Oct/Nov 2024 · 0478/12 · Q3(a)(ii) [2] Give two differences between binary and hexadecimal.
What the mark scheme wants
  • Binary is base 2, whereas hexadecimal is base 16
  • Binary uses only 0 and 1, whereas hexadecimal uses 0 to 9 and A to F
  • Each difference must refer to both number systems
Plan

Write each difference as 'binary… whereas hexadecimal…'. A sentence about hexadecimal only does not earn the mark.

Based on Oct/Nov 2024 · 0478/13 · Q2(d) [3] An email program can use Unicode instead of ASCII. Give two advantages and one drawback of using Unicode.
What the mark scheme wants
  • Advantages, any two: it can represent more characters; it can represent emojis and symbols; it can represent more languages
  • Drawback: each character needs more storage space
  • 'It uses more bits' is a difference, not an advantage or a drawback
Plan

For each answer ask what the extra bits give you (more characters) and what they cost (more storage).

Based on Oct/Nov 2024 · 0478/13 · Q2(c) [3] A report that contains text and pictures is to be compressed before it is emailed. Explain why lossy compression is not suitable.
What the mark scheme wants
  • Data is permanently removed, and that could be important data
  • Lossy compression is not suitable for text files, as it would damage or corrupt the file
  • The pictures in the report would lose quality
Plan

The question is why it is not suitable. Do not define lossy compression. Link to what is in this file: text and pictures.

Based on Oct/Nov 2024 · 0478/13 · Q2(f)(ii) [2] A checksum is calculated from the email data before and after it is sent. Explain why different values show that an error has occurred.
What the mark scheme wants
  • The checksum is calculated from the data
  • It is calculated using the same algorithm each time
  • So if the values are different, the data must be different
Plan

The report says many candidates repeated the question. Explain why: same data and same algorithm give the same value.

Based on Oct/Nov 2024 · 0478/13 · Q2(g) [3] (i) Give one reason why the email data is encrypted. (ii) Give two differences between symmetric and asymmetric encryption.
What the mark scheme wants
  • (i) One from: to keep it secure; the data is sensitive or confidential; to make it meaningless
  • (ii) Two from: symmetric uses one key, asymmetric uses two (public and private)
  • Symmetric can send its key with the data, asymmetric does not
  • Symmetric decrypts with the same key, asymmetric with a different key
  • Symmetric is less secure than asymmetric
Plan

Part (i): 'makes it meaningless' is safe; 'stops it being stolen' is the misconception. Part (ii): refer to both types in each difference.

Based on Oct/Nov 2024 · 0478/12 · Q8(c) [3] A robot vacuum cleaner is controlled by a microprocessor. Explain how the robot vacuum could make use of machine learning.
What the mark scheme wants
  • Any three from: it could gather data while vacuuming, and adapt its own processes
  • For example, learning where obstacles are, where dirtier areas are, the shape of a room or the most efficient route
  • So it knows which areas to avoid or concentrate on, or which cleaning tool to use
Plan

Three links: data gathered, what it changes, what the benefit is. Do not describe machine learning in general.

Technical knowledge (K)Applied to the context (A)

The vacuum could gather data about the room while it cleans, such as where furniture is and which areas are dirtier. It could use this data to adapt its own route, so it avoids obstacles and spends longer on the dirty areas.

Based on Oct/Nov 2024 · 0478/13 · Q5(d) [4] A farmer uses an automated plough that is controlled by a microprocessor. Explain how the plough could make use of artificial intelligence.
What the mark scheme wants
  • Any four from: it could use machine learning and gather data while ploughing
  • It could adapt its own process so it makes fewer mistakes
  • For example, the dimensions or landscape of the field, or where obstacles are
  • It could create a map of the field and develop the most efficient route
  • So it knows what to avoid in future
Plan

Same pattern as the robot vacuum: what it gathers, what it adapts, what improves. Use the field, obstacles and route.

Technical knowledge (K)Applied to the context (A)

The plough could use machine learning, gathering data about the shape of the field and where obstacles such as rocks are while it ploughs. It could build a map of the field and use it to find the most efficient route, so it makes fewer mistakes and knows what to avoid next time.

Based on Oct/Nov 2024 · 0478/11 · Q4(b)(i) [4] Computers in one room of a company send data to each other using parallel full-duplex transmission. Explain why the company chose this method.
What the mark scheme wants
  • Any four from: it sends several bits at the same time, using several wires, so the transmission is fast
  • The devices are in one room, so the data does not travel a long distance
  • It sends data in both directions at the same time, so users can send to each other with no delay
Plan

The question is 'why chosen', so every sentence should be a reason that suits one room. A description of how parallel works scores little.

Based on Oct/Nov 2024 · 0478/12 · Q4(d)(ii) [4] A smartwatch app stores user data in the cloud. Explain the benefits to the user of using cloud storage.
What the mark scheme wants
  • Any four from: no need to maintain the hardware, because the third party maintains the hardware and data security
  • Storage can be increased or decreased on demand, so there is no worry about running out
  • It saves the cost of buying hardware
  • The watch needs less storage, so it can stay small and cost less
  • The data can be accessed from other devices, so it is still available if the watch breaks or is lost
Plan

Two benefits, each with its consequence. Do not repeat what cloud storage is; the report says many candidates did.

Technical knowledge (K)Applied to the context (A)

The data can be reached from other devices, so if the watch breaks or is lost the user's data is still available.

The provider can add storage on demand, so the user will not run out of space for their health data.

Based on Oct/Nov 2024 · 0478/12 · Q4(c) [2] A smartwatch contains ROM. Explain the role of the ROM in the watch.
What the mark scheme wants
  • Any two from: it stores the BIOS, the bootstrap or the firmware
  • It helps start up the watch, because it stores the start-up instructions
  • It provides non-volatile storage, so data is kept permanently
  • It stores data or instructions that should not change
Plan

'Role in the watch' is the job it does here: start-up instructions kept when the power is off. A definition of primary storage does not answer it.

Based on Oct/Nov 2024 · 0478/12 · Q5(a) [4] A barcode scanning system uses a check digit to check for errors in the data it inputs. Explain how the system operates to check for errors.
What the mark scheme wants
  • Any four from: a check digit is calculated from the barcode data, using an algorithm such as modulo 11
  • It is added to the barcode
  • After scanning, the check digit is recalculated using the same algorithm
  • If the check digits do not match an error has occurred; if they match, no error occurred
Plan

Give the check digit steps in order: calculate, add, recalculate, compare. The report says many candidates described how a barcode scanner works instead.

Top tips

  • Circle the command word. Write the marks beside it.
  • One point per mark. Two points with reasons for 4 marks.
  • Use the scenario. Name the device, user or system.
  • Both sides in a comparison. 'whereas' joins them.
  • Say why or how. So, because, which means, this allows.
  • Use the technical term. Less storage space, less bandwidth, non-volatile.
  • Do not repeat the question. Add the reason it leaves out.
