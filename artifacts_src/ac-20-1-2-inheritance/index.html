Inheritance: Parent and Child Classes

Coursebook: Chapter 20 · Further programming, section 20.1 Programming paradigms

What inheritance is, how a child class is written in Python and pseudocode, what it inherits, adds and overrides, and how the parent constructor is called; animations, labs and review questions.

This page in five sentences

Inheritance lets a new class, the child (derived, subclass), take the attributes and methods of an existing parent (base, superclass) instead of rewriting them. The child can add its own attributes and methods, and can override a method by defining one with the same name. It is an "is a" relationship: a Parrot is an Animal. In Python the parent goes in brackets after the child's name, and the child's constructor calls the parent's. The shared code is written once, in the parent.

1 · Parent and child in code

Python

class Animal:    # Name : STRING    # Sound : STRING    def __init__(self, pName, pSound):        self.__Name = pName        self.__Sound = pSound    def GetName(self):        return self.__Name    def Description(self):        return self.__Name + " says " + self.__Sound class Parrot(Animal):    # WingSpan : INTEGER    def __init__(self, pName, pSound, pWingSpan):        super().__init__(pName, pSound)        self.__WingSpan = pWingSpan    def Description(self):        return super().Description() + ", wingspan " + str(self.__WingSpan)

Pseudocode (exam style)

CLASS Animal  PRIVATE Name : STRING  PRIVATE Sound : STRING  PUBLIC PROCEDURE NEW(pName, pSound : STRING)    Name <- pName    Sound <- pSound  ENDPROCEDURE  PUBLIC FUNCTION GetName() RETURNS STRING    RETURN Name  ENDFUNCTION  PUBLIC FUNCTION Description() RETURNS STRING    RETURN Name & " says " & Sound  ENDFUNCTIONENDCLASS CLASS Parrot INHERITS Animal  PRIVATE WingSpan : INTEGER  PUBLIC PROCEDURE NEW(pName, pSound : STRING, pWingSpan : INTEGER)    SUPER.NEW(pName, pSound)    WingSpan <- pWingSpan  ENDPROCEDURE  PUBLIC FUNCTION Description() RETURNS STRING    RETURN SUPER.Description() & ", wingspan " & WingSpan  ENDFUNCTIONENDCLASS

2 · What the child gets

ItemWhere it comes fromIn the example
Inherited attributesParentName, Sound (set by the parent constructor)
Inherited methodsParent, unless overriddenGetName()
New attributeChild onlyWingSpan
Overridden methodChild's own version, same nameDescription()

The parent's attributes are private, so the child cannot use self.__Name directly. It reaches them through the parent's getters, or sets them by calling the parent's constructor.

3 · Writing a child class: the steps

  1. Header with the parent in brackets: class Parrot(Animal):
  2. Attribute comments for the new attributes only.
  3. Constructor taking the parent's values and the new ones.
  4. First line: call the parent's constructor with the inherited values.
  5. Assign the new attributes.
  6. Write the new or overriding methods.

4 · Why inherit?

Write once, reuse many times: Parrot, Dog and Cat all share Name and Sound without repeating them. A fix to Animal fixes every child. New kinds of animal are quick to add.

4 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Types of vehicle

Car, Lorry and Motorbike all have a registration, a speed and a Move() method. They inherit those from Vehicle and add their own, such as a trailer count for a lorry.

Exam use: common features in the parent, differences in the child.

Types of employee

Manager and Engineer inherit name, ID and a method that prints a payslip. A Manager adds a team size and overrides the payslip to include a bonus.

Exam use: child adds an attribute and overrides a method.

Game characters

A Wizard and a Knight inherit position and health from Character. Each adds its own abilities.

Exam use: inheritance saves repeating the shared code.

Shapes in a drawing program

Circle and Rectangle inherit colour and position from Shape and override Draw().

Exam use: same method name, different version in each child.

Top tips

  • Parent first. super().__init__(...) is the first line of the child constructor.
  • List only the new attributes. The inherited ones belong to the parent.
  • Say 'is a'. A Parrot is an Animal. Containment is 'has a'.
  • Override means same name. A different name is a new method, not an override.
  • Don't repeat the parent. The point is to write shared code once.
