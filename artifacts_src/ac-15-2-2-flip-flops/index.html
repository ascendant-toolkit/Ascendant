Flip-flops

Coursebook: Chapter 15 · Hardware and virtual machines, section 15.2 Boolean algebra and logic circuits

SR and JK flip-flops, how they store a bit and how a register is built; animations, labs and the one real Paper 3 flip-flop question (Oct/Nov 2022).

This page in five sentences

A flip-flop is a circuit that stores one bit: its output stays at 0 or 1 after the inputs have gone back to 0, so it is a basic memory element. An SR flip-flop is two NOR (or two NAND) gates with their outputs fed back to each other's inputs; the S (set) input makes Q = 1, the R (reset) input makes Q = 0, and with both inputs at 0 the stored value is kept. Setting S and R to 1 together is not allowed because the outputs are no longer opposites and the result is unpredictable. A JK flip-flop adds a clock and removes that problem: J = K = 1 makes the output toggle (swap) on each clock pulse. Many flip-flops side by side make a register, one flip-flop per bit.

1 · The SR flip-flop

Two NOR gates are cross-coupled: the output of each gate goes to an input of the other. This feedback is what lets the circuit remember. Q and its inverse Q̄ (written ~Q in the exam, and Qb on the diagram below) are the two outputs.

SRQ nextEffect
00no changethe stored bit is kept
101set: store a 1
010reset: store a 0
11not definedinvalid: both outputs become 0, then the final value depends on which gate is faster

Walk through the memory: with S = 0 and R = 0 and Q = 1, the top NOR gate has inputs R = 0 and Q̄ = 0, so its output Q = 1 is kept; the bottom gate has inputs S = 0 and Q = 1 so Q̄ = 0, which keeps the top gate steady. Each gate's output holds the other gate's input at the value that keeps it that way.

The NAND version

The same circuit can be built from two NAND gates. NAND gates are active-low: the inputs are 1 when idle, and a 0 on the S input sets the flip-flop. The mark scheme accepts either NAND or NOR as long as the two gates are the same type, are cross-connected, and the inputs are labelled.

2 · The JK flip-flop

A JK flip-flop has inputs J (like set), K (like reset) and a clock. The inputs are only looked at when the clock pulses, so the circuit changes in step with the rest of the computer. Unlike the SR flip-flop, J = K = 1 is allowed: the output toggles.

JKQ after the clock pulseEffect
00Q (unchanged)keep
010reset
101set
11NOT Qtoggle

The diagram shows the idea: two NAND gates guarded by the clock feed an SR flip-flop. The extra feedback from Q and Q̄ to the guarding gates is what makes J = K = 1 toggle instead of being invalid. (A real device is built so that it toggles once per clock pulse.)

3 · Why flip-flops matter

  • One flip-flop stores one bit. The exam's purpose answer: "to store a binary digit".
  • A group of flip-flops makes a register: eight flip-flops hold a byte.
  • Static RAM (SRAM, used in cache) is built from flip-flop-style cells, so it keeps its contents without refreshing but uses more transistors than DRAM.
  • Flip-flops are sequential logic: the output depends on the inputs and the stored state. A gate circuit with no feedback is combinational: the output depends only on the current inputs.

4 · Common ways to lose marks

  • Using two different gate types, or two gates with no cross-feedback. The two outputs must each go back to the other gate.
  • Forgetting to label the inputs S and R (or Set and Reset). A labelled-inputs mark is separate.
  • Mixing up which input goes to which gate. With NOR gates, R is on the gate that gives Q. With NAND gates, S is on the gate that gives Q.
  • Saying the S = R = 1 case "resets" or "sets" it. It is invalid: the result is not defined.
  • Describing the purpose as "to remember" or "to be a switch". Say it stores one binary digit (bit).

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Registers in the processor

The accumulator and other registers are rows of flip-flops, one for each bit, holding the value in use between clock cycles.

Exam use: a register is a group of flip-flops.

Cache memory

Static RAM uses flip-flop-style cells. It is fast because it needs no refresh, which is why it is used for the cache.

Exam use: a flip-flop stores a bit without refreshing, but uses more transistors than DRAM.

A switch that does not bounce

A mechanical switch can flicker on and off when pressed. An SR latch after the switch settles the signal into one clean change.

Exam use: the SR flip-flop remembers the last input.

A light that toggles each time you press a button

A JK flip-flop with J = K = 1 swaps its output on every clock pulse: on, off, on, off. Chains of them make counters.

Exam use: J = K = 1 toggles the output.

A burglar alarm that stays on

Once a sensor trips the alarm it stays on even if the door is closed again, until a reset button is pressed. That is a set and a reset on a flip-flop.

Exam use: S sets and keeps Q = 1 until R resets it.

State 2 marks State the output Q of an SR flip-flop made from NOR gates when S = 1 and R = 0, and then when S and R both return to 0.
ReminderSet, then hold.

When S = 1 and R = 0, Q = 1 (set) When S and R return to 0, Q stays at 1 (the bit is stored)

Explain 2 marks Explain why S = 1 and R = 1 must be avoided in an SR flip-flop.
ReminderThink about the two outputs.

Both outputs go to 0, so Q and its inverse are no longer opposites When the inputs return to 0 the final state is unpredictable (depends on which gate responds first)

Complete 3 marks A JK flip-flop has Q = 0. J = 1 and K = 1 and the clock pulses three times. State Q after each pulse and name the behaviour.
ReminderToggle.

After pulse 1: Q = 1 After pulse 2: Q = 0 and after pulse 3: Q = 1 J = K = 1 makes the output toggle on each clock pulse

Describe 2 marks Describe how a group of flip-flops can be used to store the byte 10110001.
ReminderOne bit per flip-flop.

Eight flip-flops are used, one for each bit of the byte Each is set (Q = 1) or reset (Q = 0) to match its bit, and keeps that value until changed

Distinguish 2 marks Distinguish between combinational and sequential logic circuits.
ReminderDoes the stored state matter?

In a combinational circuit the output depends only on the current inputs In a sequential circuit (such as a flip-flop) the output depends on the inputs and on the stored previous state

Top tips

  • Two gates, same type. Two NORs or two NANDs, never one of each.
  • Cross the outputs. Each gate's output goes to an input of the other gate.
  • Label S and R. Inputs labelled Set/S and Reset/R, outputs Q and Q-bar.
  • Purpose: store one bit. It stores a single binary digit.
  • S = R = 1 is invalid. Never say it sets or resets.
  • JK: J = K = 1 toggles. Output swaps on each clock pulse.
