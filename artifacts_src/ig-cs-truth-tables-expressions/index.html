Truth Tables and Logic Expressions

Completing truth tables from circuits, expressions and problem statements, and writing logic expressions from circuits, statements and truth tables.

The big idea

A truth table lists every input combination. Complete it with working columns, one per gate, and write an expression from a table by ANDing the rows where X = 1 and ORing them together.

10.3 Truth tables and logic expressions

A truth table shows the output of a circuit for every combination of inputs. A circuit with n inputs has 2n rows: two inputs give 4 rows, three inputs give 8 rows. List the input rows in binary counting order, with A on the left (the most significant column):

Counting in binary: 000, 001, 010, 011, 100, 101, 110, 111. A changes least often (every 4 rows), B every 2 rows, C every row. Listing them this way guarantees none is missed or repeated.

Completing a truth table from a circuit or expression

  1. Write the inputs in all their combinations.
  2. Add a working column for each gate (each bracket or NOT in the expression), working left to right through the circuit.
  3. Fill the output column last, from the final gate.

Work down one column at a time rather than one row at a time: it is faster and has fewer mistakes.

Completing a truth table from a problem statement

Write the statement as an expression (see 10.2), then complete the table as above. Or reason row by row: "the alarm sounds if the door is open and the window is not open" gives 1 only when A = 1 and B = 0.

Writing an expression from a truth table

  1. Look for the rows where the output is 1.
  2. For each of those rows write an AND term using every input: write the input name where it is 1 and NOT the input where it is 0.
  3. OR all the terms together.

Example: an output that is 1 for the rows 01 and 10 only (A, B):

Row where X = 1AND term
A = 0, B = 1NOT A AND B
A = 1, B = 0A AND NOT B

Expression: X = (NOT A AND B) OR (A AND NOT B). This is the XOR gate written out, and a single XOR gate would also be a correct answer.

Spot the simple patterns firstFor two inputs, compare the output column with the gates you know: 0 0 0 1 is AND, 0 1 1 1 is OR, 1 1 1 0 is NAND, 1 0 0 0 is NOR, 0 1 1 0 is XOR. If it matches, the answer is that gate. Otherwise use the AND-then-OR method above. You do not need to simplify.

Writing an expression from a circuit

Work left to right, writing the expression for the output of each gate, and use the earlier results as the inputs of the next gate. Put brackets round each two-input gate that feeds another.

The OR gate gives (A OR B). The AND gate gives (B AND C), and the NOT inverts it: NOT (B AND C). The final AND gives X = (A OR B) AND NOT (B AND C).

Top tips

  • A three-input table has 8 rows. List them in binary order: 000, 001, 010, 011, 100, 101, 110, 111.
  • Use a working column for every gate, then the output last.
  • Do each column all the way down rather than each row across.
  • Expression from a table: AND the inputs for each row with output 1 (NOT where the input is 0), then OR the rows.
  • Check for a known gate first (AND, OR, NAND, NOR, XOR).
  • No need to simplify unless the question asks.
