Character Sets: ASCII, Extended ASCII and Unicode

Coursebook: Chapter 1 · Information representation, section 1.1 Data representation

What a character set is, how a word is stored as codes in sequence, ASCII against extended ASCII against Unicode, text file sizes, and seven questions from the 2021 to 2026 papers.

This page in five sentences

A character set is the list of characters a computer can use, with a unique binary code for each one. ASCII uses 7 bits (128 characters), extended ASCII uses 8 bits (256 characters) and Unicode uses up to 32 bits, enough for every writing system plus symbols and emojis. To store text, each character is replaced by its code and the codes are stored in the same order as the characters in the word. Unicode can represent far more characters but needs more bits per character, so text files are bigger. You are not expected to memorise any codes, but you must be able to work with them once the question gives you a starting value.

1 · What a character set is

A computer only stores binary, so every letter, digit, punctuation mark and symbol needs a number. A character set fixes which number belongs to which character, so the sender and receiver agree. Without agreement the same bits would show different characters.

Character setBits per characterNumber of charactersWhat it covers
ASCII (American Standard Code for Information Interchange)7128 (27)English letters in upper and lower case, digits 0 to 9, punctuation and control codes
Extended ASCII8256 (28)ASCII plus 128 more: accented letters, some symbols and box characters
Unicode16 or 32 (up to 32)Over a million possible codesAlmost every language, mathematical and other symbols, emojis
  • ASCII is a subset of Unicode. The first 128 Unicode codes are the same as ASCII, so plain English text is compatible.
  • Unicode encodings: the syllabus asks about Unicode as a set. In practice UTF-8 uses 8 to 32 bits per character, UTF-16 uses 16 or 32, and UTF-32 always uses 32. Exam answers say "16 or 32 bits" or "up to 32 bits".
  • Other character sets exist, and a question that asks you to "identify one other character set" accepts extended ASCII, or another valid set such as UTF-8 or ISO 8859-1.

2 · How a word is stored

  1. Split the word into characters: C, l, o, c, k.
  2. Replace each character with its unique code: 67, 108, 111, 99, 107.
  3. Write each code in binary using the bits per character: 1000011, 1101100 ...
  4. Store the binary codes in sequence, in the same order as the letters in the word.

  • Codes run in order. If A is 65 then B is 66. If a is 97 then f is 102. A question usually gives you one code and asks for another by counting along.
  • Upper case and lower case differ by 32, which is a single bit (the 32 column): A = 0100 0001 and a = 0110 0001.
  • The character '5' is not the number 5. The digit character '1' has the code 49 (hex 31), so '5' is 53. The numeric value 5 would be stored as 0000 0101.
  • Unicode values are normally written in hexadecimal. To convert, use the hex rules from syllabus 1.1.1: hex 2140 = 2 × 4096 + 1 × 256 + 4 × 16 = 8512.

3 · ASCII or Unicode: the comparison

SimilarityBoth give every character its own unique binary code. Both are character sets that map characters to codes.
Exam tipFor "advantages of Unicode over ASCII" write the range: more characters, so more languages, and symbols such as emojis. Only saying "it uses more bits" is a feature, not an advantage. Add the consequence: it needs more storage.

4 · Text file size

The size of plain text is the number of characters multiplied by the bits per character. 2000 characters in 7-bit ASCII is 14 000 bits (1750 bytes). In 8-bit extended ASCII it is 16 000 bits (2000 bytes). In 16-bit Unicode it is 32 000 bits (4000 bytes). A text file's size is not changed by the language, only by the character set and the number of characters.

5 · Common ways to lose marks

  • Saying "ASCII has fewer characters" without a number or a comparison with Unicode.
  • Writing that each word has one code. Each character has its own code, and the codes are stored in order.
  • Confusing the digit character with the number it names.
  • Quoting the wrong bits: ASCII is 7, extended ASCII is 8.
  • Giving a similarity that is really a difference, for example "both use 8 bits". Ask whether it is true of both.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Text messages that cost more

A standard text message was designed around a small character set, with room for 160 characters. A message that includes a character outside that set, such as an emoji, switches to a 16-bit encoding and the limit falls to 70 characters.

Exam use: a bigger code per character means fewer characters in the same space: the cost of Unicode.

Garbled characters on a web page

A page saved with one character set and opened with another shows strange symbols where accents or quotes should be. Browsers are told which set to use so every code is read the way it was written.

Exam use: the sender and receiver must use the same character set, or the same bits show different characters.

One page, many languages

A single Unicode document can show English, Arabic and Japanese side by side, because each character in all three has its own code. An 8-bit set cannot hold all of them.

Exam use: an advantage of Unicode over ASCII: a much wider range of characters and languages.

Emojis

Every emoji is a Unicode character with its own code, written in hexadecimal. Different phones draw the picture differently, but they send the same code.

Exam use: Unicode includes symbols and emojis; ASCII does not.

Why ASCII is still everywhere

The first 128 Unicode codes match ASCII, so a plain English text file saved in ASCII is also valid Unicode. Programming languages, email headers and many protocols still rely on that.

Exam use: ASCII is a subset of Unicode, so it is compatible.

Based on May/June 2021 · 9618/12 · Q6 [6] A computer uses the ASCII character set. (a) State the number of characters that can be represented by ASCII and by extended ASCII. (b) Explain how the word 'TREE' is represented by ASCII. (c) The Unicode value for the character '3' is denary 51. Write the hexadecimal value for '3', and the denary value for the character '8'.
What the mark scheme wants
  • ASCII 128 (2 to the power 7) and extended ASCII 256 (2 to the power 8).
  • Each character has its own unique code, each letter is replaced by its code, and the codes are stored in the order of the letters.
  • Hexadecimal 33, and denary 56.
Plan

(c) 51 = 3 × 16 + 3, so 33. Characters are in order, so '8' is five above '3': 56.

Technical knowledge (K)Applied to the context (A)

ASCII can represent 128 characters and extended ASCII 256. T, R, E and E each have a unique code (84, 82, 69, 69). Each letter is replaced by its code and the codes are stored in sequence, in the same order as the letters in 'TREE'. '3' is 33 in hexadecimal, and '8' is 56.

Based on May/June 2025 · 9618/13 · Q1(c)(i) [2] Give two characteristics of the Unicode character set.
What the mark scheme wants
  • Any two: it uses 8, 16 or 32 bits per character, up to 2 to the power of those bits different characters, it represents every language and characters such as emojis.
Plan

Characteristics are facts about the set: number of bits, range of characters.

Technical knowledge (K)Applied to the context (A)

Each character is stored using 16 or 32 bits, so a very large number of different characters can be represented, including every language and symbols such as emojis.

Top tips

  • Give the numbers. ASCII is 7 bits and 128 characters, extended ASCII is 8 bits and 256 characters, Unicode is 16 or 32 bits.
  • Both sides in a difference. 'Unicode uses more bits' is half an answer. Add 'than ASCII, which uses 7 or 8'.
  • Code, then order. For 'how is a word represented', say each character has a unique code and the codes are stored in sequence.
  • Count along the table. Given one code, others follow in order: A, B, C are 65, 66, 67 and a is 32 higher than A.
  • Digit characters are not numbers. The character '1' is code 49, not the value 1.
  • Advantage plus cost. Unicode: more characters and languages, but more storage per character.
