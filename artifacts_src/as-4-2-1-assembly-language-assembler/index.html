Assembly Language and the Assembler

Coursebook: Chapter 4 · Processor fundamentals · section 4.2 Assembly language

Machine code against assembly language, opcode and operand, how a two-pass assembler builds a symbol table and translates, and the instruction groups, with animations, an assembler lab and the real Paper 1 questions from 2021 to 2026.

This page in five sentences

Machine code is the binary instructions the processor executes directly; assembly language is a low-level language that uses mnemonics (LDD, ADD, STO) instead of binary, with one assembly instruction for each machine code instruction. Each instruction has an opcode (what to do) and an operand (what to do it to), written with absolute addresses (such as 365) or symbolic addresses (such as Total) using labels. An assembler translates assembly language into machine code (binary). A one-pass assembler translates in one go; a two-pass assembler is needed to deal with labels used before they are defined: the first pass creates a symbol table (each label and its address), and the second pass translates each instruction, replacing every label by its address. The instruction set is arranged into groups: data movement, input and output, arithmetic, compare, and conditional and unconditional jumps.

An instruction is made of an opcode and an operand. For LDD 365 the opcode is LDD (load direct) and the operand is address 365. # marks a denary number, B a binary number and & a hexadecimal number.

2 · The assembler

A program with labels cannot be translated line by line in one go, because an instruction may refer to a label that is defined later. The two-pass assembler solves this:

  1. First pass: read the program, work out the address of every instruction, and create a symbol table of each label and its address (symbolic addresses are noted, nothing is translated yet).
  2. Second pass: translate each instruction: the mnemonic becomes its binary opcode, and each label used as an operand is replaced by its address from the symbol table. The result is the machine code.

A one-pass assembler translates in a single pass and must keep a list of the places where forward-referenced labels were used so they can be filled in later (backpatched).

Common ways to lose marks

  • Saying the first pass "translates the program". It creates the symbol table.
  • Saying an assembler translates to "binary or machine code", but writing "high-level language" instead of assembly code.
  • Giving an example instruction with no operand, for example just LDM. Every example needs a suitable operand.
  • Putting CMP in the conditional group. CMP is a compare instruction; JPE and JPN are the conditional jumps.
  • Mixing up the opcode (the operation) with the operand (the data or address).

Top tips

  • First pass: symbol table. Second pass: machine code.
  • Opcode: what. Operand: on what. Name them in that order.
  • Examples need an operand. 'LDM #2', not 'LDM'.
  • CMP compares; JPE jumps. Two different groups.
  • Assembler: assembly to machine code. Not high-level.
  • One assembly line, one machine instruction. That is why it is low-level.
