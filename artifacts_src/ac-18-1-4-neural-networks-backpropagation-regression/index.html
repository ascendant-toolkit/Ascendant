This page in five sentences

An artificial neural network (ANN) is a system of connected nodes (neurons) arranged in an input layer, one or more hidden layers and an output layer, designed to simulate how a biological brain works. Each connection has a weight; a neuron adds up its weighted inputs and passes the result on, and the network learns by adjusting the weights during training, which is why ANNs are a key part of machine learning. Back propagation of errors is how the weights are adjusted: the network's output is compared with the expected output, the error is fed back through the network (using calculus to find the error gradient), and the weight of each node is adjusted to reduce the error; the process repeats until the results are accurate enough. Regression is a supervised learning method that finds the best-fit line or curve showing how one variable depends on others, so it can forecast trends and predict outcomes. Deep learning uses ANNs with many hidden layers.

1 · The structure of an artificial neural network

  • Input layer: receives the data, one node for each input value.
  • Hidden layers: one or more layers of nodes between input and output, where the data is analysed and characteristics extracted. Each hidden layer feeds the next. Many hidden layers make the network deep, able to learn more complex things and give more accurate results.
  • Output layer: gives the result, for example a category or a value.
  • Every node is connected to nodes in the next layer by a link with a weight, a number saying how strongly the signal counts.

A single neuron multiplies each input by its weight, adds them (and a bias), and passes the total through an activation function that squashes it into a range such as 0 to 1. Example with inputs 1 and 1, weights 0.8 and −0.4, bias 0.1: total = 1 × 0.8 + 1 × (−0.4) + 0.1 = 0.5, and a sigmoid activation gives about 0.62.

2 · How ANNs help machine learning

  • They are intended to replicate the way human brains work, and can solve problems that would be impossible or very hard for humans to program by hand.
  • Weights are assigned to every connection between nodes. Data goes in at the input layer and passes through the hidden layers, where characteristics are extracted and outputs calculated, to the output layer.
  • The training is repeated many times, adjusting the weights, to get the best results. The network is able to make decisions without being specifically programmed, and has self-learning capability: it produces better results as more data becomes available.
  • Back propagation is used to correct the errors.

3 · Back propagation of errors

  1. Training data is fed forward through the network, and the initial output is compared with the expected output.
  2. The error (the difference) is worked out. Calculus is used to find the error gradient: how much each weight contributed to the error.
  3. The results are fed back into the network, from the output layer backwards through the hidden layers.
  4. The weightings of each node are adjusted as a result of the feedback, in the direction that minimises the difference between actual and expected outputs.
  5. The process repeats with more data until the results are accurate enough.

This is how deep learning refines its parameters and improves accuracy. It is a form of supervised learning, since the expected outputs are known.

4 · Regression

Regression is a supervised learning technique. It finds a mathematical function, plots a best-fit line or curve, that shows how the independent variables (causes, inputs) influence a dependent variable (effect, output). It is trained to understand the relationship between the variables, and is used for forecasting trends and predicting outcomes. The goal is to minimise the difference between the predicted values and the actual values. Calculus is used to find the error gradient.

Example: the price of a house depends on its floor area. A regression line through past sales lets a new house's price be predicted from its area.

5 · Common ways to lose marks

  • Describing an ANN as "a network of computers". It is a structure of nodes in layers that simulates the brain.
  • Leaving out the weights, or not saying that they are adjusted through training.
  • Describing back propagation as "going back to the start". The errors are fed back through the network to adjust the weights.
  • Missing that the output is compared with the expected output.
  • For regression, writing only "predicts a number". Say: a best-fit line or function between independent variables and a dependent variable, minimising the difference from actual values.

6 · Multiple choice

Examples are explained in general terms. Check current details before quoting them in an exam answer.

Recognising handwriting

Each pixel is an input. Hidden layers pick out strokes, then loops and lines, and the output layer says which digit it is. Back propagation adjusted the weights using thousands of labelled examples.

Exam use: layers of nodes with trained weights.

Predicting house prices

A regression model fitted to past sales learns how floor area, location and age affect price, then predicts the price of a new house.

Exam use: regression: independent variables and a dependent variable.

Voice assistants

A deep network turns the sound into words. Every time it gets a word wrong during training, the error is propagated back and the weights are tuned.

Exam use: back propagation refines the weights.

Weather and sales forecasting

Regression finds the trend in past data so that the future can be forecast.

Exam use: forecasting trends and predicting outcomes.

Learning a skill

Practising, seeing the error and adjusting is like training a network: each attempt compares the result with the target and corrects a little.

Exam use: compare with expected output, adjust, repeat.

Top tips

  • Layers: input, hidden, output. Many hidden layers make it deep.
  • Weights on connections. Adjusted through training.
  • Back propagation: compare, feed back, adjust. Repeat until accurate.
  • Calculus finds the error gradient. Quote it if asked how.
  • Regression: best-fit line. Independent variables to a dependent variable; minimise the difference.
  • Both are supervised. The expected outputs are known.
