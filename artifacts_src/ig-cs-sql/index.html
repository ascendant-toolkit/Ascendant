Structured Query Language (SQL)

Reading, completing and writing SQL queries on a single table: SELECT, FROM, WHERE, ORDER BY, AND, OR, COUNT and SUM.

The big idea

SQL asks questions of a table. SELECT picks the fields, FROM names the table, WHERE picks the records and ORDER BY sorts them, while COUNT and SUM summarise.

9.3 Structured query language (SQL)

SQL (structured query language) is the language used to ask questions of a database (a query). You must be able to read an SQL statement, complete one, and work out its output for a single table. All the examples use this Products table:

The structure of a query

SELECT  <fields to show>
FROM    <table>
WHERE   <condition>
ORDER BY <field> ASC | DESC;
KeywordPurpose
SELECTChooses which fields (columns) to show, separated by commas. * means all fields.
FROMNames the table to use.
WHEREChooses which records (rows) to show, using a condition.
ORDER BYSorts the results: ASC (ascending, smallest first, A to Z) or DESC (descending, largest first).
AND, ORCombine conditions. AND: both must be true. OR: at least one must be true.
COUNTCounts the number of records that match.
SUMAdds up the values of a numeric field for the records that match.

The comparison operators are = <> < <= > >=. Text values go in quotes ('Electronics'); numbers do not (Price > 5). A statement ends with a semicolon.

How to work out the output

  1. FROM: start with all the records in the table.
  2. WHERE: keep only the records where the condition is true.
  3. ORDER BY: sort what is left.
  4. SELECT: show only the chosen fields (or the COUNT / SUM).
Common mistakesMissing quote marks around text; using AND when OR is needed (or the reverse); putting ORDER BY before WHERE; using SUM on a text field; forgetting that COUNT counts records but SUM adds values.

A school's attendance list

Exam-style questions

  
Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.


  
Q1 State 3 marks State the purpose of the SQL keywords SELECT, FROM and WHERE.

    
ReminderFields, table, records.

    
SELECT: chooses which fields (columns) to display. FROM: names the table that holds the data. WHERE: sets the condition that records must meet.

    
Common mistakeSaying WHERE chooses fields. It chooses records.

  


  
Q2 Write 4 marks Write an SQL statement to display the Name and Stock of all Stationery products, with the smallest stock first.

    
ReminderSELECT, FROM, WHERE with quotes, ORDER BY ASC.

    
SELECT Name, Stock FROM Products WHERE Category = 'Stationery' ORDER BY Stock ASC;

    
Common mistakeMissing quote marks around Stationery.

  


  
Q3 Identify 3 marks State the output of: SELECT Name FROM Products WHERE Category = 'Bags';

    
ReminderWhich records match?

    
Backpack Lunchbox (no other names; only these two records match)

    
Common mistakeListing the Category as well. Only Name is selected.

  


  
Q4 Identify 3 marks State the output of: SELECT Name, Price FROM Products WHERE Price > 5 AND Stock > 20;

    
ReminderBoth conditions.

    
Calculator 9.99 Headphones 19.50 Lunchbox 7.80

    
Common mistakeIncluding Backpack (stock is only 15).

  


  
Q5 Explain 2 marks Explain the difference between AND and OR in a WHERE clause.

    
ReminderBoth against either.

    
AND: both conditions must be true for the record to be selected. OR: only one of the conditions needs to be true.

    
Common mistakeSwapping them over.

  


  
Q6 Write 3 marks Write SQL to find how many products have a Price of more than 5.

    
ReminderCOUNT with WHERE.

    
SELECT COUNT(*) FROM Products WHERE Price > 5;

    
Common mistakeUsing SUM(Price), which adds the prices.

  


  
Q7 Write 3 marks Write SQL to find the total number of items in stock (the total of the Stock field) for Electronics products.

    
ReminderSUM with WHERE.

    
SELECT SUM(Stock) FROM Products WHERE Category = 'Electronics';

    
Common mistakeUsing COUNT, which counts records rather than adding values.

  


  
Q8 Complete 2 marks Complete the SQL to list all product names with the most expensive first: SELECT Name FROM Products ____ Price ____;

    
ReminderTwo keywords.

    
ORDER BY DESC

    
Common mistakeUsing ASC, which gives the cheapest first.

  







  
Top tips

  
    
    
  • Order of clauses: SELECT, FROM, WHERE, ORDER BY.
    • 
    
  • SELECT = fields (columns). WHERE = records (rows).
    • 
    
  • Text in quotes, numbers without quotes.
    • 
    
  • AND = both true. OR = at least one true.
    • 
    
  • COUNT counts records. SUM adds values.
    • 
    
  • To find the output: start with all records, apply WHERE, then ORDER BY, then show only the SELECT fields.
